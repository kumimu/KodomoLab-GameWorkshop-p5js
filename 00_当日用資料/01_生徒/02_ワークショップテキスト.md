# ワークショップテキスト

このページを上から順に進めます。前半は全員で同じ練習をし、後半は好きな機能を1つ追加します。

記録には[改造・発見ノート](03_改造と発見のノート.html)を使います。印刷した用紙に記入し、用紙がなければ手持ちの紙やメモアプリに見出しを書いて記録できます。応用課題を選ぶまでは、ほかの教材を探す必要はありません。

[試遊へ](#t02) ／ [基礎練習へ](#t03) ／ [ゲーム本体へ](#t04) ／ [応用課題へ](#t05) ／ [困ったとき](#help)

## T01　今日使うゲームと2つのフォルダ

使うのはシンプル版避けゲームです。開始前に、次の2つのフォルダが用意されています。

| フォルダ | 使い方 |
|---|---|
| オリジナル | 初めの状態を見比べたり、修正するときの参照用。編集しません |
| ワーク用 | 練習・改造・実行に使います。最後にこのフォルダをUSBへ持ち帰ります |

**編集するのも、ブラウザで動かすのも、ワーク用です。** 課題を追加するたびにフォルダを増やす必要はありません。

| やること | ワーク用の中で開くファイル | 開くアプリ |
|---|---|---|
| ゲームを遊ぶ | index.html | Chrome |
| ゲームを改造する | sketch.js | VS Code |
| 基礎練習の円を見る | JS_15分入門／index.html | Chrome |
| 基礎練習のコードを変える | JS_15分入門／practice.js | VS Code |

### 最初の準備

1. Finder／エクスプローラーで「ワーク用」を開き、その中のindex.htmlをChromeで開きます。黒い背景の開始画面が見えれば準備できています。
2. VS Codeの「ファイル」メニューから「フォルダーを開く」を選び、同じ「ワーク用」を開きます。
3. 左のファイル一覧からsketch.jsを開きます。まだ変更せず、次の試遊へ進みます。

ブラウザでゲームを実行し、VS Codeでコードを編集します。ファイルを探すときは、VS Codeのファイル一覧で右クリックし、Finder／エクスプローラーに表示する項目を選ぶ方法も使えます。

p5.min.jsとlicensesも、ワーク用フォルダに入れたまま使います。

## T02　まず遊んでみよう（5～10分）

上から落ちてくる敵を避け、制限時間を生き残るゲームです。開いたゲームの画面をクリックしてから操作します。日本語入力はオフにします。

| やること               | 操作                       |
| ---------------------- | -------------------------- |
| やさしい難易度で始める | キーボード上段の1を押す    |
| 別の難易度で始める     | 開始画面で2、または3を押す |
| 自機を左右へ動かす     | ←／→キーを押す             |
| 終了後に開始画面へ戻る | Spaceキーを押す            |

まず左右へ動かし、敵が上から下へ落ちてくることを確かめます。確認できたら一度敵に当たり、結果画面からSpaceで戻ります。試遊ではクリアまで待つ必要はありません。

[ノートの「操作とゲームの動き」](03_改造と発見のノート.html#n01)に、確かめた操作や気付いたことを短く記録します。この段階では改造する機能を選びません。

## T03　15分の基礎練習（10～25分）

### 練習の画面を用意する

1. VS Codeで「ワーク用」の中の「JS_15分入門／practice.js」を開きます。
2. Finder／エクスプローラーで「ワーク用」の中の「JS_15分入門／index.html」をChromeで開きます。円とタイトルが見えれば準備できています。
3. これからはpractice.jsを変更し、「ファイル→保存」を選び、Chromeの練習画面を更新します。

**すでにある行の値だけを変更します。** 下の見本をコードの末尾へ追加する必要はありません。見本と今の値が違っていても、playerSizeなどの名前で行を探してください。

コードの記号・数値・色名は半角で入力します。日本語のタイトルを入力した後は、英数入力へ戻しましょう。

### 1．円の大きさを変える

practice.jsのplayerSizeの値を80にします。

```javascript
let playerSize = 80;
```

保存して練習画面を更新し、円の大きさを見ます。次は20に変更して、もう一度保存・更新します。80と20では、どちらが大きいでしょう。

### 2．円の色を変える

playerColorの引用符の内側をyellowにします。

```javascript
let playerColor = "yellow";
```

保存・更新して、円が黄色になることを確かめます。数字は引用符で囲まず、色名やタイトルなどの文字は半角の引用符で囲みます。すでにある引用符が `'` でも `"` でも、左右の形を揃えたまま内側を変更できます。

### 3．タイトルを変える

gameTitleの引用符の内側を、自分がつけたいタイトルに変えます。

```javascript
let gameTitle = "今日のゲーム";
```

半角の引用符は残します。保存・更新して、表示が変わったことを確かめます。

### 4．変数の名前と値を確かめる

playerSizeは値を覚えておく名前です。`let playerSize = 80;`は「playerSizeという名前で80を記録する」という意味です。

```javascript
circle(200, 150, playerSize);
```

200と150は円の中心の横・縦の位置、playerSizeは円の直径です。左上が(0, 0)で、右へ進むと横の値、下へ進むと縦の値が増えます。この行は読むだけで、まだ変更しません。

最後にplayerSizeを100、playerColorをblueにし、保存・更新します。**直径100の青い円**になれば確認完了です。[ノートの「基礎練習で分かったこと」](03_改造と発見のノート.html#n02)を記入しましょう。

タイトルに改行を入れる追加チャレンジは、`"星をよけろ！\n宇宙サバイバル"`を見本にできます。引用符の内側に半角のバックスラッシュとnを入れます。文字列の途中でEnterを押すとエラーになるので、まずは1行のタイトルで進めて構いません。

## T04　ゲームの全体像と最初の改造（25～35分）

### 前半：ゲーム全体の地図（25～32分）

VS Codeで「ワーク用」のsketch.jsを開きます。ここからはゲーム本体を扱います。最初は読むだけです。

| コードの名前                           | 何をするところ？                                   |
| -------------------------------------- | -------------------------------------------------- |
| index.html → p5.min.js → sketch.js     | ブラウザが描画の道具とゲームを読み込む             |
| setup()                                | 最初に1回、画面などを用意する                      |
| draw() / gameState                     | 画面を繰り返し描き、開始・プレイ・終了を切り替える |
| CUSTOM AREA                            | 自機や敵の色・大きさ・速さ、タイトルを設定する     |
| playerX / playerY                      | 自機の横位置・縦位置を記録する                     |
| enemies / enemy                        | 敵の一覧と、その中の1体を表す                      |
| movePlayer() / constrain()             | 自機を動かし、画面の端で止める                     |
| moveEnemy() / respawnEnemy()           | 敵を落とし、画面の上へ戻して再登場させる           |
| isHit()                                | 自機と敵が当たったか、中心同士の距離で調べる       |
| registerWorkshopOption() / runOption() | 追加した機能を記録し、必要な場面で呼び出す         |

左右へ動くときはx、下へ落ちるときはyの値が変わります。例えば`enemy.y += enemy.speed;`は、敵の縦位置に速さの分だけ足す処理です。

追加機能はA・B・G・H・MのIDごとに記録されます。例えばBのthis.bulletsは、Bが使う弾の一覧です。動き始めに弾の一覧を空にし、Spaceで弾を増やし、毎回動かして描きます。実際に追加するときは、選んだ課題のページで手順を確認します。

### 後半：ゲーム本体の色とスピードを変える（32～35分）

先ほどの練習と同じように、変数の値を変えて、実際のゲームもカスタムしてみましょう。まずは自機を好きな色に。さらに今回は、自機のスピードも変えて、操作した感じがどう変わるか試してみましょう。

1. sketch.jsの上の方にある「CUSTOM AREA」を探します。
2. playerColorの引用符の内側を好きな色にします。例はyellowです。引用符は残します。

```javascript
let playerColor = "yellow";
```

3. playerSpeedの値を7から12に変えます。数値には引用符を付けません。

```javascript
let playerSpeed = 12;
```

4. VS Codeで「ファイル→保存」を選びます。
5. Chromeで**ゲーム本体の画面**を更新します。円の練習画面とは別です。
6. 1でゲームを始め、← →で動かします。選んだ色になったか、試遊のときより素早く動くかを確かめます。

速いと避けやすいでしょうか。それとも動きすぎて難しいでしょうか。クリアまで待たず、数秒操作して違いを確かめましょう。

練習のpractice.jsとゲームのsketch.jsは別々のファイルなので、練習で変えた円の大きさ・色・タイトルはゲームへ自動では移りません。すでに色を変えてある場合は、その色のまま速さを試しても構いません。

ここまでは全員で同じ手順を進めます。次に、追加したい機能を選びます。

## T05　好きな応用課題を1つ実装（35～55分）

[応用課題の選択ページ](応用課題/00_課題の選び方.html)を開きます。本日はA・B・G・H・Mから1つ選びます。各ページに、追加するコード・空欄の説明・確認する動きが載っています。

| 選べる課題                | 作るもの                           |
| ------------------------- | ---------------------------------- |
| A　敵の多様化             | 色と速さが異なる敵                 |
| B　射撃機能               | Spaceキーで撃つ弾                  |
| G　BGMの追加              | 音の並びと間隔を変えられるメロディ |
| H　ビジュアルカスタマイズ | 回転する四角い敵と自機の光         |
| M　スコアシステム         | 得点の異なる敵と連続回避コンボ     |

1. 選んだ記号と作るものを[ノートの「自分の改造記録」](03_改造と発見のノート.html#n03)に書きます。
2. 「ワーク用」のsketch.jsを保存します。以降もこのファイルを編集します。
3. 選んだ課題ページを開き、「この機能のコードをコピー」を押します。
4. ワーク用のsketch.jsの一番下にある「応用コード貼り付け欄：ここから」と「ここまで」の間へ貼り付けます。
5. 課題ページの「空欄の意味とヒント」を読み、`__B1__`などの印全体を値へ置き換えます。迷ったら同じページの例で確かめられます。
6. 保存し、Chromeのゲーム本体を更新して、1で始めます。課題ページの「動作確認」を確かめます。
7. 動いたら1つの値だけを変えて試し、予想と結果をノートに残します。

自機の色など、CUSTOM AREAで変更した内容は残ります。貼り付け欄の外のコードはそのまま使います。**共通の登録関数を名前変更したり、let bulletsを別の場所へ追加したりする作業は不要です。**

早く終わったら、同じ5課題から別の機能も追加できます。先のコードを残し、同じ欄の下へ貼ります。同じ課題をやり直す場合は、その課題のコードだけを置き換えます。

55分になったら新しい追加を止め、仕上げへ進みます。

## T06　仕上げ（55～60分）

1. 新しい改造を止め、ワーク用のファイルを保存します。
2. ゲームが動くなら、その状態を保ちます。
3. 動かない場合は、[「困ったとき」](#help)を上から確認し、VS Codeの「編集→元に戻す」で直前の変更を戻して、保存・更新を試します。
4. 直らない場合は講師へ見せ、オリジナルと見比べて必要な箇所を直します。オリジナルは参照するだけで編集しません。

オリジナルは最初の状態です。sketch.jsを丸ごと戻すと、それまでの改造も元に戻ります。ワーク用を削除したり原本で上書きしたりする前に、講師と確認しましょう。

## T07　動作確認（60～70分）

ゲーム本体を更新して、次を確かめます。

- [ ] 開始画面が出る。
- [ ] 1で始め、左右へ動ける。
- [ ] 自機の色と追加した機能が反映される。
- [ ] 敵に当たる、または時間が過ぎると結果画面になる。
- [ ] Spaceで開始画面へ戻り、もう一度1で始められる。
- [ ] 課題ページの「動作確認」に書かれた動きが確かめられる。

[ノートの「遊べるか確認」](03_改造と発見のノート.html#n04)に結果を記録します。まだ確かめていないものはチェックせず、残っていることを書きます。

## T08　入れ替えプレイ（70～80分）

1. 自分のゲームを保存し、開始画面に戻しておきます。
2. 近くの参加者と席を入れ替え、お互いの作品を遊びます。
3. 終了の案内があったら、自分の席へ戻ります。

この時間はプレイだけを行います。感想交換やノート記入はありません。ほかの人の作品のコードは変更しません。

## T09　共有（80～85分）

希望する2～3人が、発見を全体へ紹介します。次の形を使えます。

「私は○○を変えました。△△になると思ったら、実際には□□になりました。」

全員が全体発表をする必要はありません。

## T10　USBへ保存・持ち帰り（85～90分）

1. VS Codeで「ファイル→すべて保存」を選びます。
2. 「ワーク用」フォルダを、USBメモリへ**フォルダごと**コピーします。
3. USB内のワーク用フォルダを開き、そのindex.htmlをChromeで開いて、自分の改造したゲームが動くことを確認します。
4. [ノートの「持ち帰り確認」](03_改造と発見のノート.html#n06)に、USB内の保存場所を書きます。

index.html、sketch.js、p5.min.js、licenses、JS_15分入門を一緒に持ち帰ります。オリジナルではなく、編集してきたワーク用をコピーできたか確認しましょう。

## 困ったとき

<span id="help"></span>

上から1つずつ確認します。直せない場合は、開いているファイル名と、直前に変えた箇所を講師へ見せてください。

| 症状                         | 自分で確かめる手順                                                                                                |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| 変化しない | 編集したファイルとChromeで開いた画面が、どちらもワーク用か確認する。円はpractice.js、ゲームはsketch.js。保存して対応する画面を更新する |
| キーが効かない               | Chromeのゲーム画面をクリックし、日本語入力をオフにする。開始は1、終了後に戻るのはSpace                            |
| 応用を貼ったら動かない       | 貼った課題の中に`__B1__`などの印が残っていないか探す。色の引用符、数値のマイナス、括弧・カンマを見本と比べる      |
| 応用コードの貼り付け欄がない | ワーク用のsketch.jsを開いているか確認する。場所が正しくても欄がなければ講師へ見せる |
| コピーボタンが使えない       | 表示された機能コードの先頭から最後の`});`までを選び、ブラウザの「編集→コピー」を使う。貼るのはその1枠だけ         |
| Gの音が鳴らない              | 音量を小さく設定してから確認し、ゲーム画面をクリックして1で開始する。プレイ中にMキーで切り替える                  |
| エラーで画面が出ない | 直前の変更を元に戻して保存・更新する。直らなければT06に沿って講師とオリジナルを見比べる |

## コードの書き方を調べる

必要なときに、この表へ戻れます。

| 書き方                               | 意味                                                               |
| ------------------------------------ | ------------------------------------------------------------------ |
| let / const                          | 値に名前を付ける。letは入れ直せる。constは同じ名前へ代入し直さない |
| function / 関数名()                  | 処理をまとめる／呼び出す                                           |
| if                                   | 条件が合うときだけ実行する                                         |
| for                                  | 敵や弾の一覧を順に調べるなど、処理を繰り返す                       |
| enemy.y                              | その敵の縦位置                                                     |
| += / -=                              | 今の値に足す／引く                                                 |
| this.bullets.push(...) / splice(...) | 弾の一覧へ追加する／取り除く                                       |
| push() / pop()                       | 描画の設定を一時的に保存する／戻す                                 |
| this.bullets                         | Bの機能が持つ弾の一覧                                              |
| return                               | 処理の結果を呼び出し元へ返す                                       |

ライセンスと配布条件は教材フォルダのlicensesにあります。
