# OPTION B　射撃機能

プレイ中にSpaceを押すと弾を撃ち、敵に当てると点数が入ります。

## 1．ヒントの値で動かしてみよう

1. 「ワーク用」のsketch.jsを保存します。この後も同じワーク用フォルダで作業します。オリジナルは編集しません。
2. 下の「この機能のコードをコピー」を押します。
3. VS Codeで「ワーク用」のsketch.jsを開き、末尾の「応用コード貼り付け欄」を探します。
4. 「ここから」と「ここまで」の間に、この課題のコードを1回貼ります。同じ課題を修正する場合は、その課題のコードを置き換えます。
5. 「空欄の意味とヒント」の表を見て、「最初に入れる値」で空欄をすべて埋め、保存します。
6. Chromeで避けゲームの画面を更新して始め、「動作確認」を見ながら遊びます。

**ゲーム全体を置き換えません。** CUSTOM AREAの色・大きさ・速さ・タイトルはそのまま残ります。プレイヤーをyellowに変えていれば、そのままです。

貼り付け欄が見つからない場合は、「ワーク用」のsketch.jsを開いているか確認します。[困ったときの手順](../02_ワークショップテキスト.html#help)も使えます。

### 貼るコード（この1枠だけ）

```javascript
// ===== このファイルで使う関数・用語の早見表 =====
// p5.jsは、円や文字を画面に描くときに使う道具です。
// 円を描く circle など、p5.jsの道具の使い方はここで調べられます。
// https://v1.p5js.org/reference/
//
// 【p5.jsが用意する関数】
// fill(色)：この後に描く図形や文字の塗り色を決める。
// noStroke()：図形の輪郭線を描かない設定にする。
// circle(x, y, 直径)：中心(x, y)に円を描く。
// dist(x1, y1, x2, y2)：2点の間の距離を求める。
//
// 【JavaScript標準の機能：p5.jsとは別】
// 配列.push(値)：一覧の末尾に値を追加する。描画設定のpush()とは別の機能。
// 配列.splice(位置, 個数)：指定位置から要素を取り除く。この教材では弾の削除に使う。
// ===== 早見表ここまで =====

registerWorkshopOption("B", {
  bullets: [], // この機能の弾をまとめて管理します。
  // 【役割】ゲーム開始時に、この機能の弾の一覧を空にします。
  start() {
    this.bullets = []; // 再開始時に前の弾を残しません。
  },
  // 【役割】プレイ中にSpaceが押されたら、プレイヤーの位置から弾を1発追加します。
  key(k) {
    if (gameState === "play" && k === " ") {
      // ① Spaceが押されたので、弾を1つ作って一覧へ追加します。
      this.bullets.push({
        x: playerX,
        y: playerY - playerSize / 2,
        vy: __B1__
      });
    }
  },
  // 【役割】弾を動かし、画面外の弾の削除と、命中・得点・敵の再登場を処理します。
  update() {
    // ② 毎回、一覧の弾を動かし、画面外や命中の処理をします。
    for (let i = this.bullets.length - 1; i >= 0; i--) {
      this.bullets[i].y += this.bullets[i].vy;
      if (this.bullets[i].y < -3) {
        this.bullets.splice(i, 1);
        continue;
      }
      for (const enemy of enemies) {
        const b = this.bullets[i];
        if (dist(b.x, b.y, enemy.x, enemy.y) < 3 + enemySize / 2) {
          score += __B2__;
          this.bullets.splice(i, 1);
          respawnEnemy(enemy); // 当たった敵を画面上へ戻します。
          break; // 1発で複数の敵を倒さないようにします。
        }
      }
    }
  },
  // 【役割】この機能が持つ弾を、指定した色の小さな円で描きます。
  draw() {
    // ③ 一覧に残っている弾を、この色で画面へ描きます。
    fill("__B3__");
    noStroke();
    for (const b of this.bullets) {
      circle(b.x, b.y, 6);
    }
  }
});
```

### 空欄の意味とヒント

`__B1__`のような**印全体**を置き換えます。アンダースコアも消します。色の外側にある引用符は残し、数値には引用符を追加しません。

| 印 | 何を決める？ | 考えるヒント | 最初に入れる値 |
|---|---|---|---|
| `__B1__` | 弾の縦方向の移動量 | 上へ進むので負の数 | `-8` |
| `__B2__` | 敵に当てたときの得点 | 足したい点数を入れる | `10` |
| `__B3__` | 弾の色 | 色名を入れ、周囲の引用符を残す | `yellow` |

まずは表の値で遊び、どんな変化が起きるか見てみましょう。

- this.bulletsはこの機能の弾の入れ物です。Spaceを押すと増え、移動・命中・画面外で更新されます。

## 2．仕組みを3つでつかもう

スペースキーを押すと、弾はどう動きましたか？

1. **弾が出る**。スペースキーを押すと、プレイヤーから弾が1発出ます。弾の色は `__B3__` で決まります。
2. **弾が上へ進む**。弾は少しずつ上へ進みます。`__B1__` が -8 なら、画面を描き直すたびに8ピクセル上へ動きます。
3. **敵に当たると点が入る**。弾が敵に当たると弾が消え、`__B2__` に入れた点数が加わります。

[もっと知りたい人へ：ゲームのコードと追加機能のつながり](仕組み_本体と追加機能.md)

## 3．自分の好みに変えてみよう

ここからは、自分のルールや見た目を作る時間です。3～5分を目安に進めます。比較する間は得点と弾の色をそのままにし、vyの値だけを変えます。

### 1．予想クイズ：実行する前に考えよう

弾のvyを-8から-4に変えると、どうなるでしょう？ 下で予想を1つ選びます。

<label><input type="radio" name="quiz-b" value="2"><span>イ：弾は上へ進むまま、速さが半分になる。</span></label>
<label><input type="radio" name="quiz-b" value="3"><span>ウ：弾を撃つ回数が2倍になる。</span></label>
</fieldset>

選んだら、vyを-4にして保存・更新し、同じ難易度でSpaceを押して弾の動きを見ます。

<details>
<summary>試した後に、答えと理由を見る</summary>

正解は「イ」です。画面ではyが小さくなる方向が上です。-8も-4も負の数なので上へ進み、1回に動く距離は8から4へ減ります。弾はSpaceを押したときに出るので、vyを変えても発射する回数は変わりません。

</details>

### 2．お題：狙って当てたくなる弾の速さを作ろう

「自分で狙って当てた！」と思える弾の速さを目指します。 正解の数値は1つではありません。

1. vyには負の数を使います。まず-4〜-12程度から、試す値を2つ自分で決めます。
2. 同じ難易度で遊び、弾の動きが見えるか、敵を狙いやすいか比べます。
3. 自分が撃っていて気持ちよい値を採用します。最初の値へ戻しても構いません。

ノートN03へ「試した値・予想・実際の違い」を短く残します。弾を速くしたときと遅くしたときで、狙い方は変わりましたか？

### 3．発見をコメント1行にしよう

ワーク用のsketch.jsで、**Bの弾を追加する処理にあるvyの行のすぐ上**へ、`//`で始まるコメントを1行追加します。どんなゲームにしたくてその値を選んだのか、自分の言葉で書きましょう。

迷ったら、`// 弾のvyを〇〇にした。〇〇な撃ち心地にしたいから。` を書き出しの手がかりにできます。〇〇は自分の数値や言葉に置き換えます。

最後にコーチへ「この値にした理由」と「遊んで分かったこと」を1つ伝えます。予想と違った結果も、発見です。
