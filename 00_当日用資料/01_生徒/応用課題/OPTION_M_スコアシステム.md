# OPTION M　スコアシステム

敵を画面下まで通過させると「回避」になり、続けて回避すると回避得点の倍率が上がります。射撃を先に作る必要はありません。

## 1．ヒントの値で動かしてみよう

1. 「ワーク用」のsketch.jsを保存します。この後も同じワーク用フォルダで作業します。オリジナルは編集しません。
2. 下の「この機能のコードをコピー」を押します。
3. VS Codeで「ワーク用」のsketch.jsを開き、末尾の「応用コード貼り付け欄」を探します。
4. 「ここから」と「ここまで」の間に、この課題のコードを1回貼ります。同じ課題を修正する場合は、その課題のコードを置き換えます。
5. 「空欄の意味とヒント」の表を見て、「最初に入れる値」で空欄をすべて埋め、保存します。
6. Chromeで避けゲームの画面を更新して始め、「動作確認」を見ながら遊びます。

**ゲーム全体を置き換えません。** CUSTOM AREAの色・大きさ・速さ・タイトルはそのまま残ります。プレイヤーをyellowに変えていれば、そのままです。

貼り付け欄が見つからない場合は、「ワーク用」のsketch.jsを開いているか確認します。[困ったときの手順](../02_ワークショップテキスト.html#help)も使えます。

### 貼るコード（この1枠だけ）

```javascript
// ===== このファイルで使う関数・用語の早見表 =====
// p5.jsは、円や文字を画面に描くときに使う道具です。
// 円を描く circle など、p5.jsの道具の使い方はここで調べられます。
// https://v1.p5js.org/reference/
//
// 【p5.jsが用意する関数】
// fill(色)：この後に描く図形や文字の塗り色を決める。
// text(文字, x, y)：指定した位置に文字を描く。
// textSize(大きさ)：文字の大きさを決める。
// millis()：スケッチ開始からの経過時間をミリ秒で得る。1000ミリ秒で1秒。
// floor(数)：その数以下の最大の整数にする。例：1.8 → 1。
// random(下限, 上限)：範囲内の乱数を得る。上限は含まない。引数なしでは0以上1未満。
// max(値1, 値2, ...)：指定した値のうち最大のものを返す。
// ===== 早見表ここまで =====

registerWorkshopOption("M", {
  rareScore: __M1__,
  increment: __M2__,
  duration: __M3__, // コンボを続けられる時間。1000で1秒です。
  combo: 0,
  until: 0,
  // 【役割】ゲーム開始時に、コンボ数とコンボの期限をリセットします。
  start() {
    this.combo = 0;
    this.until = 0;
  },
  // 【役割】敵が登場するたびに、通常かレアかを抽選して回避得点を決めます。
  spawnEnemy(enemy) {
    enemy.value = random() < 0.15 ? this.rareScore : 10;
  },
  // 【役割】コンボの期限が切れていれば、連続回避の数を0に戻します。
  update() {
    if (millis() >= this.until) {
      this.combo = 0;
    }
  },
  // 【役割】敵を避けたときにコンボと倍率を計算し、得点と次の期限を更新します。
  // ① 敵が画面下を通り過ぎると、ゲームのコードがこの敵を渡して呼びます。
  avoid(enemy) {
    if (millis() >= this.until) {
      this.combo = 0;
    }
    // ② コンボを増やし、得点と次のコンボ期限を決めます。
    this.combo += this.increment;
    const multiplier = 1 + floor((this.combo - 1) / 5);
    score += enemy.value * multiplier;
    this.until = millis() + this.duration;
    // ③ ゲームのコードへ「計算済み」と伝え、標準の1点を重ねて足さないようにします。
    return true; // この課題で得点を計算しました。
  },
  // 【役割】レア敵なら黄色を指定します。
  enemyColor(enemy) {
    return enemy.value === this.rareScore ? "yellow" : undefined;
  },
  // 【役割】現在の連続回避の数と得点倍率を、指定された行へ表示します。
  drawInfo(y) {
    fill("white");
    textSize(14);
    const multiplier = 1 + floor(max(this.combo - 1, 0) / 5);
    text("連続回避: " + this.combo + " / 回避倍率: " + multiplier, 20, y);
  }
});
```

### 空欄の意味とヒント

`__M1__`のような**印全体**を置き換えます。アンダースコアも消します。色の外側にある引用符は残し、数値には引用符を追加しません。

| 印 | 何を決める？ | 考えるヒント | 最初に入れる値 |
|---|---|---|---|
| `__M1__` | レア敵を避けたときの点数 | 通常の10点より高くする | `50` |
| `__M2__` | 1回避けると増えるコンボ数 | 1回の成功で1つ増やす | `1` |
| `__M3__` | コンボが続く制限時間 | 1000で1秒。3000なら3秒 | `3000` |

まずは表の値で遊び、どんな変化が起きるか見てみましょう。

- 敵を画面下まで避けると得点が入り、連続回避の1～5回目は1倍、6～10回目は2倍です。射撃を先に作る必要はありません。

### 回避コンボを試す準備

敵が1体だけだと、次の敵を回避するまでにコンボの期限が切れやすくなります。**「かんたん」の速さのまま、敵だけ複数にして試します。**

1. ワーク用のsketch.jsで、`function startGame(level)`を探します。
2. その中の`if (level === 1)`、つまり「かんたん」の設定を見つけます。
3. `enemySpeed = 4;`はそのままにし、同じ設定内の`enemyCount`を、まず`3`にします。ファイル上部の同名変数だけを変えても、開始時にこの設定で上書きされるため、startGameの中を変更します。
4. 保存・更新して、1キーで始めます。敵を画面下まで通過させ、回避した数を確認します。

すでに敵数を増やしている場合は、その数で確認して構いません。比較実験では敵数と難易度を揃え、durationだけを変えます。多すぎて避けにくければ敵数を減らし、確認が終わったら遊びたい数へ調整します。

3体でも配置や再登場のタイミングによってコンボが切れることはあります。画面の「連続回避」と「回避倍率」を見て、続く場合・途切れる場合を比べましょう。

### うまく動かないとき

## 2．仕組みを3つでつかもう

敵を続けて避けると、得点やコンボの表示はどう変わりましたか？

1. **敵を避けると点が入る**。敵が画面の下まで通り過ぎると得点が入ります。黄色いレア敵の得点は `__M1__` で決まります。
2. **続けて避けるとコンボが増える**。1回避けるたびに、`__M2__` に入れた数だけコンボが増えます。コンボが増えると、得点にかかる倍率が上がります。
3. **次の敵まで間が空くとコンボが切れる**。`__M3__` が3000なら、次の敵を避けるまでに3秒を過ぎるとコンボが0に戻ります。

[もっと知りたい人へ：ゲームのコードと追加機能のつながり](仕組み_本体と追加機能.md)

## 3．自分の好みに変えてみよう

ここからは、動いたコードを自分のルールに変える時間です。3～5分を目安に、次の順で試しましょう。比べる間は、incrementを1、rareScoreを50に揃え、durationだけを変えます。

### 1．予想クイズ：実行する前に考えよう

durationを3000から6000に変えると、どうなるでしょう？ 下で予想を1つ選びます。

<label><input type="radio" name="quiz-m" value="1"><span>ア：1回の回避でもらえる点数が2倍になる。</span></label>
<label><input type="radio" name="quiz-m" value="2"><span>イ：次の敵を避けるまで、コンボをつなげられる時間が2倍になる。</span></label>
<label><input type="radio" name="quiz-m" value="3"><span>ウ：敵が落ちる速さが2倍になる。</span></label>
</fieldset>

選んだらdurationを6000にし、保存してゲームを更新します。同じ難易度で遊び、画面の「連続回避」が0へ戻るまでの様子を確かめましょう。敵を避けるたびに期限が更新されるので、**最後に敵を避けてから**の時間に注目します。

<details>
<summary>試した後に、答えと理由を見る</summary>

正解は「イ」です。durationはコンボを続けられる時間で、1000が1秒です。3000は3秒、6000は6秒。期限までに次の敵を避けるとコンボが続きます。得点の基本値や敵の速さは、この変更では変わりません。

コードの `this.until = millis() + this.duration;` は、今の時刻にdurationを足して、次の期限を決めています。

</details>

### 2．お題：つなげたい！ と思えるコンボにしよう

**「コンボが続くとうれしい。でも、油断すると切れる」**。そんなゲームになるよう、durationを調整してください。正解の数値は1つではありません。

1. 今の値より短い時間を、自分で決めて試します。durationには0より大きい数値を入れます。
2. 短い場合と長い場合を、同じ難易度で遊び比べます。値を変えたら保存・更新し、ゲームを始め直します。
3. どちらが面白いか考え、最後に自分の採用する値を決めます。最初の値へ戻しても構いません。

ノートN03へ「試した値・予想・実際の違い」を短く残します。コンボが切れにくいほど、必ず面白くなるでしょうか？

### 3．発見をコメント1行にしよう

ワーク用のsketch.jsで、**Mのdurationの行のすぐ上**へ、`//`で始まるコメントを1行追加します。「どんな遊び心地にしたくて、その値を選んだか」を、自分の言葉で書きましょう。

書き出しに迷ったら、`// durationを〇〇にした。〇〇なゲームにしたいから。` を手がかりにできます。〇〇は自分の数値や言葉に置き換えます。コメントはゲームの動作を変えず、工夫の理由を残すものです。

最後にコーチへ「この値にした理由」と「遊んで分かったこと」を1つ伝えてください。予想と違った結果も、発見です。
