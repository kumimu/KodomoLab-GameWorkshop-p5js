# OPTION H　ビジュアルカスタマイズ

敵を回転する四角形にし、プレイヤーの周りに光を描きます。プレイヤーの色の設定は引き継ぎます。

## 1．ヒントの値で動かしてみよう

1. 「ワーク用」のsketch.jsを保存します。この後も同じワーク用フォルダで作業します。オリジナルは編集しません。
2. 下の「この機能のコードをコピー」を押します。
3. VS Codeで「ワーク用」のsketch.jsを開き、末尾の「応用コード貼り付け欄」を探します。
4. 「ここから」と「ここまで」の間に、この課題のコードを1回貼ります。同じ課題を修正する場合は、その課題のコードを置き換えます。
5. 「空欄の意味とヒント」の表を見て、「最初に入れる値」で空欄をすべて埋め、保存します。
6. Chromeで避けゲームの画面を更新して始め、「動作確認」を見ながら遊びます。

**ゲーム全体を置き換えません。** CUSTOM AREAの色・大きさ・速さ・タイトルはそのまま残ります。プレイヤーをyellowに変えていれば、そのままです。

貼り付け欄が見つからない場合は、「ワーク用」のsketch.jsを開いているか確認します。[困ったときの手順](../02_ワークショップテキスト.html#help)も使えます。

### 貼るコード（この1枠だけ）

```javascript
// ===== このファイルで使う関数・用語の早見表 =====
// p5.jsは、円や文字を画面に描くときに使う道具です。
// 円を描く circle など、p5.jsの道具の使い方はここで調べられます。
// https://v1.p5js.org/reference/
//
// 【p5.jsが用意する関数】
// fill(色)：この後に描く図形や文字の塗り色を決める。
// noStroke()：図形の輪郭線を描かない設定にする。
// circle(x, y, 直径)：中心(x, y)に円を描く。
// rect(x, y, 幅, 高さ)：四角形を描く。位置の基準はrectModeで決まる。
// rectMode(CENTER)：四角形の位置を中心座標で指定する設定にする。
// push()：現在の描画設定や座標の変換を保存する。pop()と組にして使う。
// pop()：直前のpush()で保存した描画設定や座標の変換へ戻す。
// translate(x, y)：この後に描く図形の原点を移動する。
// rotate(角度)：この後に描く図形の座標を回転する。この教材では角度はラジアン。
// color(色)：透明度などを変更できる色の情報を作る。
//
// 【p5.jsが用意する値：関数ではないので()を付けない】
// frameCount：draw()が呼ばれた回数。
// CENTER：四角形の中心を位置の基準にする定数。
// 色.setAlpha(濃さ)：色の透明度を変更する。標準では0が透明、255が不透明。
// ===== 早見表ここまで =====

registerWorkshopOption("H", {
  // 【役割】敵の位置で四角形を回転させて描き、標準の円の描画に代えます。
  // ① ゲームのコードが敵を描くとき、この敵1体を受け取ります。
  drawEnemy(enemy) {
    // ② この敵の位置で、回転した四角を描きます。
    push();
    translate(enemy.x, enemy.y);
    rotate(frameCount * __H1__);
    fill(optionEnemyColor(enemy));
    noStroke();
    rectMode(CENTER);
    rect(0, 0, enemySize * 0.7, enemySize * 0.7);
    pop(); // 座標や描画設定を元に戻します。
    // ③ ゲームのコードへ「描画済み」と伝え、通常の円を重ねないようにします。
    return true;
  },
  // 【役割】プレイヤーを描く前に、プレイヤーと同じ色の半透明の光を周りに描きます。
  beforePlayer() {
    const glow = color(playerColor); // 自分で決めたプレイヤーの色を使います。
    glow.setAlpha(__H2__);
    fill(glow);
    noStroke();
    circle(playerX, playerY, playerSize + 20);
  }
});
```

### 空欄の意味とヒント

`__H1__`のような**印全体**を置き換えます。アンダースコアも消します。色の外側にある引用符は残し、数値には引用符を追加しません。

| 印 | 何を決める？ | 考えるヒント | 最初に入れる値 |
|---|---|---|---|
| `__H1__` | 敵の回転の速さ | 小さい数でゆっくり。負なら逆向き | `0.05` |
| `__H2__` | プレイヤーの光の濃さ | 0は透明、255は不透明 | `80` |

まずは表の値で遊び、どんな変化が起きるか見てみましょう。

- 回転が見える四角形を使い、pushとpopで文字まで回らないようにします。光の色はplayerColorから引き継ぎます。

## 2．仕組みを3つでつかもう

敵の形と、プレイヤーのまわりに注目してみましょう。

1. **敵が四角になる**。落ちてくる敵を四角で描きます。
2. **四角が回る**。画面を描き直すたびに四角の向きが少しずつ変わり、回って見えます。`__H1__` で回る速さが変わります。
3. **プレイヤーのまわりが光る**。プレイヤーのまわりに光を描きます。`__H2__` を大きくすると、光が濃くなります。

[もっと知りたい人へ：ゲームのコードと追加機能のつながり](仕組み_本体と追加機能.md)

## 3．自分の好みに変えてみよう

ここからは、自分のルールや見た目を作る時間です。3～5分を目安に進めます。比較する間は光の濃さを80に揃え、rotate(frameCount * …)の数値だけを変えます。

### 1．予想クイズ：実行する前に考えよう

回転の数値を0.05から-0.05に変えると、どうなるでしょう？ 下で予想を1つ選びます。

<fieldset class="prediction-quiz">
<legend>予想を1つ選ぶ</legend>
<label><input type="radio" name="quiz-h" value="1"><span>ア：回転が逆向きになり、回る速さは同じになる。</span></label>
<label><input type="radio" name="quiz-h" value="2"><span>イ：敵が上へ進むようになる。</span></label>
<label><input type="radio" name="quiz-h" value="3"><span>ウ：回る速さが2倍になる。</span></label>
</fieldset>

選んだら、数値を-0.05にして保存・更新し、敵の回転を見ます。必要なら0.05へ戻して向きを見比べましょう。

<details>
<summary>試した後に、答えと理由を見る</summary>

正解は「ア」です。rotateへ渡す角度は、frameCountに数値を掛けて決まります。0.05と-0.05は大きさが同じで符号が逆なので、回転の向きが逆になります。敵が落ちる処理は別なので、落ちる方向は変わりません。

</details>

### 2．お題：自分のゲームらしい回転を作ろう

「落ち着いた雰囲気」や「にぎやかな雰囲気」など、自分のゲームらしい回転を目指します。 正解の数値は1つではありません。

1. 回転の数値を2つ決めます。まず0.01〜0.15程度を使い、逆向きにしたければ負の数にします。
2. 同じ難易度で遊び、回転の向きや速さで印象がどう変わるか比べます。
3. 見た目と遊びやすさから採用する値を決めます。最初の値へ戻しても構いません。

ノートN03へ「試した値・予想・実際の違い」を短く残します。見た目が派手になるほど、遊びやすくなるでしょうか？

### 3．発見をコメント1行にしよう

ワーク用のsketch.jsで、**HのdrawEnemy(enemy)の中にあるrotateの行のすぐ上**へ、`//`で始まるコメントを1行追加します。どんなゲームにしたくてその値を選んだのか、自分の言葉で書きましょう。

迷ったら、`// 回転の数値を〇〇にした。〇〇な見た目にしたいから。` を書き出しの手がかりにできます。〇〇は自分の数値や言葉に置き換えます。

最後にコーチへ「この値にした理由」と「遊んで分かったこと」を1つ伝えます。予想と違った結果も、発見です。
