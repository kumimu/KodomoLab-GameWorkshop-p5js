# OPTION A　敵の多様化

速い敵と通常の敵を出し分けます。敵の色で、どちらのタイプか見分けられます。

## 1．ヒントの値で動かしてみよう

1. 「ワーク用」のsketch.jsを保存します。この後も同じワーク用フォルダで作業します。オリジナルは編集しません。
2. 下の「この機能のコードをコピー」を押します。
3. VS Codeで「ワーク用」のsketch.jsを開き、末尾の「応用コード貼り付け欄」を探します。
4. 「ここから」と「ここまで」の間に、この課題のコードを1回貼ります。同じ課題を修正する場合は、その課題のコードを置き換えます。
5. 「空欄の意味とヒント」の表を見て、「最初に入れる値」で空欄をすべて埋め、保存します。
6. Chromeで避けゲームの画面を更新して始め、「動作確認」を見ながら遊びます。

**ゲーム全体を置き換えません。** CUSTOM AREAの色・大きさ・速さ・タイトルはそのまま残ります。プレイヤーをyellowに変えていれば、そのままです。

貼り付け欄が見つからない場合は、「ワーク用」のsketch.jsを開いているか確認します。[困ったときの手順](../02_ワークショップテキスト.html#help)も使えます。

### 貼るコード（この1枠だけ）

```javascript
// ===== このファイルで使う関数・用語の早見表 =====
// p5.jsは、円や文字を画面に描くときに使う道具です。
// 円を描く circle など、p5.jsの道具の使い方はここで調べられます。
// https://v1.p5js.org/reference/
//
// 【p5.jsが用意する関数】
// random(下限, 上限)：範囲内の乱数を得る。上限は含まない。引数なしでは0以上1未満。
// ===== 早見表ここまで =====

registerWorkshopOption("A", {
  // 【役割】敵が登場するたびに、通常の敵か速い敵かを抽選します。
  spawnEnemy(enemy) {
    // 登場するたびに、通常敵か速い敵かを決めます。
    enemy.type = random() < 0.3 ? "fast" : "normal";
  },
  // 【役割】受け取った敵1体を調べ、その敵の速さに掛ける倍率をゲームのコードへ返します。
  // speedは速さ、Multiplierは倍率。Aで定義する関数で、p5.jsの関数ではありません。
  // sketch.jsのmoveEnemyが、この関数の返した倍率をenemy.speedに掛けて敵を動かします。
  // ① ゲームのコードが「この敵は何倍？」と聞くと、ここが呼ばれます。
  speedMultiplier(enemy) {
    // ② fastか調べ、速い敵なら__A1__、通常敵なら1を選びます。
    // ③ 選んだ倍率をゲームのコードへ返します。ゲームのコードが元の速さに掛けて動かします。
    return enemy.type === "fast" ? __A1__ : 1;
  },
  // 【役割】速い敵の色を返します。通常の敵は基本の色を使います。
  enemyColor(enemy) {
    return enemy.type === "fast" ? "__A2__" : undefined;
  }
});
```

<details>
<summary>もっと知りたい人へ：speedMultiplierの読み方</summary>

**敵1体を受け取り、「この敵の速さを何倍にするか」をゲームのコードに返す関数**です。speedは「速さ」、multiplierは「倍率」という意味です。p5.jsの標準関数ではなく、課題Aで用意する追加機能です。

敵を動かすとき、sketch.jsのmoveEnemyがrunOptionを通じて、このspeedMultiplierへ敵1体を渡します。返ってきた倍率を、ゲームのコードがその敵の元の速さenemy.speedに掛けます。speedMultiplier自体は敵の位置を動かしません。

| コードの部分 | 読み方 |
|---|---|
| `speedMultiplier(enemy)` | 敵1体の情報をenemyという名前で受け取る |
| `enemy.type === "fast"` | その敵のタイプがfast（速い敵）か調べる |
| `条件 ? __A1__ : 1` | 条件が当てはまれば__A1__、それ以外なら1を選ぶ |
| `return` | 選んだ倍率を、呼び出したゲームのコードへ返す |

例えば元の速さが2なら、倍率1で2のまま、倍率1.5で3、倍率3で6になります。**通常敵は1倍、速い敵だけを指定の倍率にする**仕組みです。

すぐ下のenemyColor(enemy)も、同じように敵1体を調べます。こちらは倍率ではなく色を返します。速い敵なら指定の色、通常敵ならundefined（この機能では色を指定しない）を返し、ゲームのコードが基本設定などから色を決めます。


</details>

### 空欄の意味とヒント

`__A1__`のような**印全体**を置き換えます。アンダースコアも消します。色の外側にある引用符は残し、数値には引用符を追加しません。

| 印 | 何を決める？ | 考えるヒント | 最初に入れる値 |
|---|---|---|---|
| `__A1__` | 速い敵の移動倍率 | 1より大きい数なら速くなる | `1.5` |
| `__A2__` | 速い敵の色 | 色名を入れ、周囲の引用符を残す | `orange` |

まずは表の値で遊び、どんな変化が起きるか見てみましょう。

- 確率0.3は約30％。通常敵の色は自分のenemyColorを使います。

## 2．仕組みを3つでつかもう

オレンジ色の敵は、いつもの敵より速く落ちてきましたか？

1. **敵が出てくる**。敵が出てくるたびに、いつもの敵か、速い敵かがくじ引きで決まります。
2. **色で見分ける**。速い敵には、空欄 `__A2__` に入れた色が付きます。ヒントの値ならオレンジ色です。
3. **落ちる速さを比べる**。速い敵だけ、空欄 `__A1__` に入れた数字で、落ちる速さが変わります。1.5なら、いつもの速さの1.5倍です。

## 3．自分の好みに変えてみよう

ここからは、自分のルールや見た目を作る時間です。3～5分を目安に進めます。比較する間は速い敵の色をorangeに揃え、速い敵の倍率だけを変えます。

正解は「ア」です。speedMultiplierは、速い敵なら指定した倍率、通常敵なら1を返します。1.5から3は倍率が2倍です。敵のタイプを抽選する確率0.3は変わりません。

### 2．お題：速い敵との、ちょうどよい勝負を作ろう

「速い敵が来るとドキッとする。でも、避けられる！」という遊び心地を目指します。 正解の数値は1つではありません。

1. 1より大きい倍率を自分で2つ決め、1つずつ試します。
2. 同じ難易度で、速い敵を見つけてから避ける余裕を比べます。
3. 自分が面白いと思った倍率を採用します。最初の値へ戻しても構いません。

ノートN03へ「試した値・予想・実際の違い」を短く残します。速いほど、必ず面白くなるでしょうか？

### 3．発見をコメント1行にしよう

ワーク用のsketch.jsで、**AのspeedMultiplier(enemy)の中にあるreturnの行のすぐ上**へ、`//`で始まるコメントを1行追加します。どんなゲームにしたくてその値を選んだのか、自分の言葉で書きましょう。

迷ったら、`// 速い敵の倍率を〇〇にした。〇〇な勝負にしたいから。` を書き出しの手がかりにできます。〇〇は自分の数値や言葉に置き換えます。

最後にコーチへ「この値にした理由」と「遊んで分かったこと」を1つ伝えます。予想と違った結果も、発見です。
