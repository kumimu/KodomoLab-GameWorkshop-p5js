OPTION H　ビジュアルカスタマイズ

敵を回転する四角形にし、自機の周りに光を描きます。自機の色の設定は引き継ぎます。

まず、仕組みを3つでつかもう

本体「敵を描いて」 → Hが回る四角を描く → 本体「描いてくれたので、通常の円は描かない」。

① 本体が敵を描くとき、HのdrawEnemyへ敵1体を渡します。

② Hが敵の位置へ移動し、回転させた四角を描きます。

③ Hがtrue（描画済み）を返すと、本体は通常の円を重ねて描きません。

自機を描く直前には、beforePlayerが周りの光を描きます。pushとpopは、回転などの描画設定をこの処理の中だけに留めるための組です。

虫食い どこに効く？
__H1__ ②で四角を回転させる速さと向き
__H2__ beforePlayerで描く、自機の光の濃さ

まずは①②③の流れと、自分が変える値を追えれば大丈夫です。コード内にも同じ番号のコメントがあります。

もっと知りたい人へ：本体と追加機能のつながり

選んだ機能だけを1か所へ貼る

  1. 「ワーク用」のsketch.jsを保存します。この後も同じワーク用フォルダで作業します。オリジナルは編集しません。
  2. 下の「この機能のコードをコピー」を押します。
  3. VS Codeで「ワーク用」のsketch.jsを開き、末尾の「応用コード貼り付け欄」を探します。
  4. 「ここから」と「ここまで」の間に、この課題のコードを1回貼ります。別の機能を追加するときは、先のコードを残したまま、その下へ貼ります。同じ課題を修正する場合は、その課題のコードを置き換えます。
  5. このページの「空欄の意味とヒント」を読み、虫食いを全て埋め、保存します。迷ったら表の例を使えます。
  6. Chromeでゲーム本体を更新して始め、機能の動作を確認します。

ゲーム全体を置き換えません。 CUSTOM AREAの色・大きさ・速さ・タイトルはそのまま残ります。自機をyellowに変えていれば、そのままです。

貼り付け欄が見つからない場合は、「ワーク用」のsketch.jsを開いているか確認します。困ったときの手順も使えます。

貼るコード（この1枠だけ）

// ===== このファイルで使う関数・用語の早見表 =====
// 必要な名前を探し、次の行のURLから詳しい説明を確認できます。
// p5.js 1.x 公式リファレンス：https://v1.p5js.org/reference/
//
// 【p5.jsが用意する関数】
// fill(色)：この後に描く図形や文字の塗り色を決める。
// https://v1.p5js.org/reference/p5/fill/
// noStroke()：図形の輪郭線を描かない設定にする。
// https://v1.p5js.org/reference/p5/noStroke/
// circle(x, y, 直径)：中心(x, y)に円を描く。
// https://v1.p5js.org/reference/p5/circle/
// rect(x, y, 幅, 高さ)：四角形を描く。位置の基準はrectModeで決まる。
// https://v1.p5js.org/reference/p5/rect/
// rectMode(CENTER)：四角形の位置を中心座標で指定する設定にする。
// https://v1.p5js.org/reference/p5/rectMode/
// push()：現在の描画設定や座標の変換を保存する。pop()と組にして使う。
// https://v1.p5js.org/reference/p5/push/
// pop()：直前のpush()で保存した描画設定や座標の変換へ戻す。
// https://v1.p5js.org/reference/p5/pop/
// translate(x, y)：この後に描く図形の原点を移動する。
// https://v1.p5js.org/reference/p5/translate/
// rotate(角度)：この後に描く図形の座標を回転する。この教材では角度はラジアン。
// https://v1.p5js.org/reference/p5/rotate/
// color(色)：透明度などを変更できる色の情報を作る。
// https://v1.p5js.org/reference/p5/color/
//
// 【p5.jsが用意する値：関数ではないので()を付けない】
// frameCount：draw()が呼ばれた回数。
// https://v1.p5js.org/reference/p5/frameCount/
// CENTER：四角形の中心を位置の基準にする定数。
// https://v1.p5js.org/reference/p5/rectMode/
// 色.setAlpha(濃さ)：色の透明度を変更する。標準では0が透明、255が不透明。
// https://v1.p5js.org/reference/p5.Color/setAlpha/
//
// 【ゲーム本体にある自作関数】
// registerWorkshopOption(ID, 機能)：本体の共通関数へ、課題IDごとに機能を登録する。
// optionEnemyColor(敵)：基本設定と追加機能から敵の色を選ぶ。本体に定義がある。
// 定義と【役割】の説明は、同じ教材フォルダのsketch.jsで確認できます。
// ===== 早見表ここまで =====

registerWorkshopOption("H", {
  // 【役割】敵の位置で四角形を回転させて描き、標準の円の描画に代えます。
  // ① 本体が敵を描くとき、この敵1体を受け取ります。
  drawEnemy(enemy) {
    // ② この敵の位置で、回転した四角を描きます。
    push();
    translate(enemy.x, enemy.y);
    rotate(frameCount * __H1__);
    fill(optionEnemyColor(enemy));
    noStroke();
    rectMode(CENTER);
    rect(0, 0, enemySize * 0.7, enemySize * 0.7);
    pop(); // 座標や描画設定を元に戻します。
    // ③ 本体へ「描画済み」と伝え、通常の円を重ねないようにします。
    return true;
  },
  // 【役割】自機を描く前に、自機と同じ色の半透明の光を周りに描きます。
  beforePlayer() {
    const glow = color(playerColor); // 自分で決めた自機の色を使います。
    glow.setAlpha(__H2__);
    fill(glow);
    noStroke();
    circle(playerX, playerY, playerSize + 20);
  }
});

空欄の意味とヒント

__H1__のような印全体を置き換えます。アンダースコアも消します。色の外側にある引用符は残し、数値には引用符を追加しません。

印 何を決める？ 考えるヒント 迷ったときの例
__H1__ 敵の回転の速さ 小さい数でゆっくり。負なら逆向き 0.05
__H2__ 自機の光の濃さ 0は透明、255は不透明 80

まず自分で考え、迷ったら例の値を使って動きを確かめます。動いた後に1つずつ変えて試せます。空欄が残っている間は、まだ動かない場合があります。

  • 回転が見える四角形を使い、pushとpopで文字まで回らないようにします。光の色はplayerColorから引き継ぎます。

動作確認

うまく動かないとき

  • この課題の__H1__などの印が残っていないか探します。
  • 保存後、円の練習画面ではなくゲーム本体を更新し、1で始めます。
  • 別の機能も入っている場合、そのコードを残したまま追加したか確かめます。同じ課題は1つだけにします。
  • それでも直らなければテキストの対処手順へ進みます。

動いたら挑戦！ 自分のゲームらしい回転を作ろう

ここからは、自分のルールや見た目を作る時間です。3～5分を目安に進めます。比較する間は光の濃さを80に揃え、rotate(frameCount * …)の数値だけを変えます。

1．予想クイズ：実行する前に考えよう

回転の数値を0.05から-0.05に変えると、どうなるでしょう？ 下で予想を1つ選びます。

予想を1つ選ぶ

選んだら、数値を-0.05にして保存・更新し、敵の回転を見ます。必要なら0.05へ戻して向きを見比べましょう。

試した後に、答えと理由を見る

正解は「ア」です。rotateへ渡す角度は、frameCountに数値を掛けて決まります。0.05と-0.05は大きさが同じで符号が逆なので、回転の向きが逆になります。敵が落ちる処理は別なので、落ちる方向は変わりません。

2．お題：自分のゲームらしい回転を作ろう

「落ち着いた雰囲気」や「にぎやかな雰囲気」など、自分のゲームらしい回転を目指します。 正解の数値は1つではありません。

  1. 回転の数値を2つ決めます。まず0.01〜0.15程度を使い、逆向きにしたければ負の数にします。
  2. 同じ難易度で遊び、回転の向きや速さで印象がどう変わるか比べます。
  3. 見た目と遊びやすさから採用する値を決めます。最初の値へ戻しても構いません。

ノートN03へ「試した値・予想・実際の違い」を短く残します。見た目が派手になるほど、遊びやすくなるでしょうか？

3．発見をコメント1行にしよう

ワーク用のsketch.jsで、HのdrawEnemy(enemy)の中にあるrotateの行のすぐ上へ、//で始まるコメントを1行追加します。どんなゲームにしたくてその値を選んだのか、自分の言葉で書きましょう。

迷ったら、// 回転の数値を〇〇にした。〇〇な見た目にしたいから。 を書き出しの手がかりにできます。〇〇は自分の数値や言葉に置き換えます。

最後にコーチへ「この値にした理由」と「遊んで分かったこと」を1つ伝えます。予想と違った結果も、発見です。

できたら次へ

自分の採用値を決め、コメントを残せたら挑戦は完了です。時間があれば、別の課題のコードも同じ欄へ追加できます。追加するたびに前の機能も動くか確認し、55分になったら新しい追加を止めます。
