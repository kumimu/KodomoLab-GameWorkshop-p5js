S10　ゲームが動くまで（0:25–0:26）

対応：生徒テキストT04前半（資料対応表）

index.html：ブラウザが開く入口。 p5.min.js：描画と入力を助ける道具。 sketch.js：自分のゲームの動き。 HTMLはp5.js→ゲーム本体の順に読み込む。

S11　準備と、画面を描く繰り返し（0:26–0:27）

対応：生徒テキストT04前半（資料対応表）

setup()は最初に1回、画面を用意。 draw()は繰り返し、背景を描き直す。 gameStateでstart・play・endを切り替える。 playGame()が移動・描画・判定を進める。

S12　変数・敵の一覧・1体の情報（0:27–0:28:30）

対応：生徒テキストT04前半（資料対応表）

変数は今の値を記録します。 enemiesは敵の一覧、enemyはその中の1体。 forで一覧を順に調べ、x・y・speedを使う。

let enemies = [];
const enemy = { x: 200, y: 100, speed: 4 };

対応：生徒テキストT04前半（資料対応表）

左右はx、落下はyの値を変えます。 constrainは画面の端で止める処理。 isHitは距離を調べ、当たればendへ。

playerX += playerSpeed;
enemy.y += enemy.speed;

S14　IDごとに機能を登録する（0:30–0:32）

対応：生徒テキストT04前半（資料対応表）

registerWorkshopOption("B", {...})で登録。 A・B・G・H・MはIDごとに別々に保存。 次の機能は、同じ欄の下へ追加します。 this.bulletsはB専用の弾の一覧。 本体が登録済みの各機能を順に呼びます。
