T01　今日使うゲームと2つのフォルダ

当日は、用意されている「オリジナル」と「ワーク用」の2つのフォルダを使います。

フォルダ 使い方
オリジナル 初めの状態を見比べたり、修正するときの参照用。編集しません
ワーク用 練習・改造・実行に使います。最後にこのフォルダをUSBへ持ち帰ります

シンプル版のゲームを遊んだり改造したりするときは、「ワーク用」を開きます。

JavaScriptの練習をするときは、「ワーク用」の中の「JS_15分入門」を開きます。

やること ワーク用の中で開くファイル 開くアプリ

基礎練習の円を見る JS_15分入門／index.html Chrome
基礎練習のコードを変える JS_15分入門／practice.js VS Code
ゲームを改造する sketch.js VS Code

最初の準備

  1. Finder／エクスプローラーで「ワーク用」を開き、その中のindex.htmlをChromeで開きます。黒い背景の開始画面が見えれば準備できています。

上から落ちてくる敵を避け、制限時間を生き残るゲームです。開いたゲームの画面をクリックしてから操作します。

終了後に開始画面へ戻る Spaceキーを押す

まずは「かんたん」から始めましょう。プレイヤーを左右へ動かし、敵が上から下へ落ちてくることを確かめます。確認できたら別の難易度も試しましょう。

T03　15分の基礎練習（10～25分）

JavaScriptって何？

JavaScript（ジャバスクリプト）は、コンピューターへの指示を書くための言葉です。このような言葉を「プログラミング言語」、書いた指示を「コード」と呼びます。

JavaScriptで書いたゲームは、Chromeなどのブラウザで動かせます。今回のゲームでも、「右の矢印キーを押したらプレイヤーを右へ動かす」などの指示をJavaScriptで書いています。

まずは、円の大きさや色、タイトルを変えてみましょう。VS Codeでコードを変えて保存し、Chromeで画面を更新すると、結果をすぐに確かめられます。

練習の画面を用意する

  1. VS Codeの「ファイル」メニューから「フォルダーを開く」を選び、「ワーク用」を開きます。左の一覧で「JS_15分入門」の中の practice.js を開きます。
  2. Finder／エクスプローラーで「ワーク用」の中の「JS_15分入門／index.html」をChromeで開きます。円とタイトルが見えれば準備できています。
  3. これからはpractice.jsを変更し、「ファイル→保存」を選び、Chromeの練習画面を更新します。

この練習では、数字、引用符などの記号、色名（yellowなど）を半角で入力します。日本語のタイトルを入力した後は、英数入力へ戻しましょう。

1．円の大きさを変える

practice.jsのplayerSizeの値を80にします。

let playerSize = 80;

保存して練習画面を更新し、変更前の40と変更後の80で円の大きさを比べます。

2．円の色を変える

playerColorの引用符の内側をyellowにします。

let playerColor = "yellow";

保存・更新して、円が黄色になることを確かめます。色名やタイトルなどの文字は半角の引用符 " で囲みます。色名は "yellow" のように書きます。数字は引用符で囲みません。

3．タイトルを変える

gameTitleの引用符の内側を、自分がつけたいタイトルに変えます。

let gameTitle = "今日のゲーム";

半角の引用符は残します。保存・更新して、表示が変わったことを確かめます。

4．変数の名前と値を確かめる

playerSizeは値を覚えておく名前です。let playerSize = 80;は「playerSizeという名前で80を記録する」という意味です。

circle(200, 150, playerSize);

200と150は円の中心の横・縦の位置、playerSizeは円の直径です。画面の左上が(0, 0)です。円の中心が右にあるほど横の値が大きく、下にあるほど縦の値が大きくなります。

最後に直径100の黄色い円になるように改造できれば確認完了です。

後半：プレイヤーの色とスピードを変える（32～35分）

VS Codeで「ワーク用」のsketch.jsを開きます。先ほどの練習と同じように、変数の値を変えて、実際のゲームもカスタムしてみましょう。まずはプレイヤーを好きな色に。さらに今回は、プレイヤーのスピードも変えて、操作した感じがどう変わるか試してみましょう。

  1. sketch.jsの上の方にある「CUSTOM AREA」を探します。
  2. playerColorの引用符の内側を好きな色にします。例はyellowです。引用符は残します。
let playerColor = "yellow";
  1. playerSpeedの値を7から12に変えます。数値には引用符を付けません。
let playerSpeed = 12;
  1. VS Codeで「ファイル→保存」を選びます。
  2. Chromeで「ワーク用」の index.html で開いた避けゲームの画面を更新します。
  3. 1でゲームを始め、← →で動かします。選んだ色になったか、最初に遊んだときより素早く動くかを確かめます。

速いと避けやすいでしょうか。それとも動きすぎて難しいでしょうか。クリアまで待たず、数秒操作して違いを確かめましょう。

T05　好きな応用課題を1つ実装（35～55分）

応用課題の選択ページを開きます。本日はA・B・G・H・Mから1つ選びます。各ページに、追加するコード・空欄の説明・確認する動きが載っています。

選べる課題 作るもの
A　敵の多様化 色と速さが異なる敵
B　射撃機能 Spaceキーで撃つ弾
G　BGMの追加 音の並びと間隔を変えられるメロディ
H　ビジュアルカスタマイズ 回転する四角い敵とプレイヤーの光
M　スコアシステム 得点の異なる敵と連続回避コンボ
  1. 選んだ記号と作るものをノートの「自分の改造記録」に書きます。
  2. 「ワーク用」のsketch.jsを保存します。以降もこのファイルを編集します。
  3. 選んだ課題ページを開き、「この機能のコードをコピー」を押します。
  4. ワーク用のsketch.jsの一番下にある「応用コード貼り付け欄：ここから」と「ここまで」の間へ貼り付けます。
  5. 課題ページの「空欄の意味とヒント」を読み、__B1__などの印全体を値へ置き換えます。まずは表の「最初に入れる値」を使い、ゲームを動かして確かめます。
  6. 保存し、Chromeの避けゲームの画面を更新して、1で始めます。課題ページの「動作確認」を確かめます。
  7. 動いたら1つの値だけを変えて試し、予想と結果をノートに残します。

プレイヤーの色など、CUSTOM AREAで変更した内容は残ります。貼り付け欄の外のコードはそのまま使います。共通の登録関数を名前変更したり、let bulletsを別の場所へ追加したりする作業は不要です。

同じ課題をやり直すときは、貼ったコードを置き換えます。

55分になったら新しい追加を止め、仕上げへ進みます。

T06　仕上げ（55～60分）

  1. 新しい改造を止め、ワーク用のファイルを保存します。
  2. ゲームが動くなら、その状態を保ちます。
  3. 動かない場合は、「困ったとき」を上から確認し、VS Codeの「編集→元に戻す」で直前の変更を戻して、保存・更新を試します。
  4. 直らない場合は講師へ見せ、オリジナルと見比べて必要な箇所を直します。オリジナルは参照するだけで編集しません。

オリジナルは最初の状態です。sketch.jsを丸ごと戻すと、それまでの改造も元に戻ります。ワーク用を削除したり原本で上書きしたりする前に、講師と確認しましょう。

T07　動作確認（60～70分）

避けゲームの画面を更新して、次を確かめます。

  • 開始画面が出る。
  • 1で始め、左右へ動ける。
  • プレイヤーの色と追加した機能が反映される。
  • 敵に当たる、または時間が過ぎると結果画面になる。
  • Spaceで開始画面へ戻り、もう一度1で始められる。
  • 課題ページの「動作確認」に書かれた動きが確かめられる。

ノートの「ゲームの動作確認」に結果を記録します。まだ確かめていないものはチェックせず、残っていることを書きます。

T08　作品プレイと意見交換（70～80分）

生徒2人とコーチ1人の3人で、1つずつゲームを見ます。講師の合図で始め、コーチが進行します。

  1. 作った人は、ワークシートのN03にゲームのタイトルと変えたところを書き、2人に紹介します。
  2. もう1人の生徒がゲームで遊び、作った人とコーチも画面を一緒に見ます。
  3. 遊んだ人は、よかったところや気づいたことを伝えます。作った人は、もらった感想をN03に書きます。
  4. 役割を交代し、もう1人のゲームも同じように見ます。

T10　USBへ保存・持ち帰り（80～90分）

  1. VS Codeで「ファイル→すべて保存」を選びます。
  2. 「ワーク用」フォルダを、USBメモリへフォルダごとコピーします。
  3. USB内のワーク用フォルダを開き、そのindex.htmlをChromeで開いて、自分の改造したゲームが動くことを確認します。
  4. ノートの「持ち帰り確認」で、完了した項目にチェックを付けます。

index.html、sketch.js、p5.min.js、licenses、JS_15分入門を一緒に持ち帰ります。オリジナルではなく、編集してきたワーク用をコピーできたか確認しましょう。

困ったとき

上から1つずつ確認します。直せない場合は、開いているファイル名と、直前に変えた箇所を講師へ見せてください。

キーが効かない Chromeのゲーム画面をクリックし、日本語入力をオフにする。開始は1、終了後に戻るのはSpace

コードの書き方を調べる

必要なときに、この表へ戻れます。

書き方 意味
let / const 値に名前を付ける。letは入れ直せる。constは同じ名前へ代入し直さない
function / 関数名() 処理をまとめる／呼び出す
if 条件が合うときだけ実行する
for 敵や弾の一覧を順に調べるなど、処理を繰り返す
enemy.y その敵の縦位置
+= / -= 今の値に足す／引く
this.bullets.push(...) / splice(...) 弾の一覧へ追加する／取り除く
push() / pop() 描画の設定を一時的に保存する／戻す
this.bullets Bの機能が持つ弾の一覧
return 処理の結果を呼び出し元へ返す
