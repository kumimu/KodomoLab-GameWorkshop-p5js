## コードと解説（5画面）

### 1 最初の準備

画面を作る準備は、最初に1回。

sketch.js：setup() 全体

```javascript
function setup() {
  createCanvas(600, 400);
  textFont("sans-serif");
}
```


① 最初の準備をします（`setup()`）

ゲームを開いたときに1度だけ動きます。

② ゲームの画面を作ります（`createCanvas()`）

横600・縦400の大きさのゲーム画面を作ります。

③ 文字のスタイルを決めます（`textFont()`）

画面に表示する文字の書体を決めます。

準備が終わったら、`draw()` でゲームの画面をくり返し描きます。

### 2 画面を描き直す

p5.js が draw() を何度も呼び、画面を描き直します。

sketch.js：draw() 全体

```javascript
function draw() {
  background(backgroundColor);

  if (gameState === "start") {
    showStartScreen();
  } else if (gameState === "play") {
    playGame();
  } else if (gameState === "end") {
    showEndScreen();
  }
}
```


① 背景を塗り直します（`background()`）

ゲーム画面の絵1枚が「フレーム」です。背景を塗ると、1フレーム前の絵が消えます。

② ゲームの状態に合わせて処理を選びます（`gameState`）


start
：開始画面を描く

play
：プレイ中の処理を呼ぶ

end
：結果画面を描く

③ プレイ中の動きを処理します（`playGame()`）

プレイヤーと敵を動かす・描く・当たりを調べる処理へ進みます。次の描画でも draw() が呼ばれます。

ひとつ前の絵を消す → 新しい位置で描く。これをくり返すと、パラパラ漫画のように動いて見えます。


### 3 プレイヤーと敵の移動

位置の数値を変えてから描くと、動いて見える。

sketch.js：movePlayer() 全体

```javascript
function movePlayer() {
  if (keyIsDown(LEFT_ARROW)) {
    playerX -= playerSpeed;
  }
  if (keyIsDown(RIGHT_ARROW)) {
    playerX += playerSpeed;
  }

  playerX = constrain(playerX, playerSize / 2, width - playerSize / 2);
}
```

sketch.js：moveEnemy() 前半（次ページへ続く）

```javascript
function moveEnemy(enemy) {
  const multiplier = runOption("speedMultiplier", enemy);
  enemy.y += enemy.speed * (multiplier === undefined ? 1 : multiplier);
  // ↓ 続き（得点・再登場）は次のページへ
```


① プレイヤーを左右に動かします（`playerX`）


keyIsDown()
で、キーが押されているか調べます。

←：
playerSpeed
を引く → 左へ
→：
playerSpeed
を足す → 右へ

② プレイヤーを画面の端で止めます（`constrain()`）

画面の端まで来たら、それ以上は進みません。

③ 敵を下に動かします（`enemy.y`）


xは横、yは縦。
敵の縦位置に速さを足すと、下へ動きます。

実コードは残し、移動部分を強調します。灰色の応用用コードは今回の説明対象外です。

位置を更新 → 描く。次の描画でまた更新。


### 4 得点と敵の再登場

下まで避けた敵を、画面の上へ戻して再利用する。

sketch.js：moveEnemy() 後半（前ページの続き・コメントを除く）

```javascript
  if (enemy.y > height + enemySize) {
    if (runOption("avoid", enemy) !== true) {
      score += 1;
    }
    respawnEnemy(enemy);
  }
}
```

sketch.js：respawnEnemy() 全体

```javascript
function respawnEnemy(enemy) {
  enemy.y = random(-300, -50);
  enemy.x = random(enemySize, width - enemySize);
  enemy.speed = enemySpeed + random(0, 2);
  runOption("spawnEnemy", enemy);
}
```


① 敵が画面の下を通ったか調べます


enemy.y &gt; height + enemySize
で、敵が画面の下まで進んだかを調べます。

② 敵を避けたら得点を加えます（`score`）

基本は
score += 1
は「今の得点に1を足す」という意味です。

③ 敵を画面の上に戻します（`respawnEnemy()`）


y
は画面より上の位置へ。

x
と速さもランダムに決め直します。

同じ敵を上へ戻す → また落ちてくる。


### 5 当たり判定

プレイヤーが敵に当たったら、ゲームオーバー！

sketch.js：isHit() 全体

```javascript
function isHit(enemy) {
  const distance = dist(playerX, playerY, enemy.x, enemy.y);
  return distance < playerSize / 2 + enemySize / 2;
}
```

sketch.js：playGame() の当たり判定部分

```javascript
if (isHit(enemy)) {
  resultText = "GAME OVER";
  gameState = "end";
  return;
}
```


① プレイヤーと敵の中心の距離を測ります（`dist()`）

プレイヤーの位置と、敵の位置の間がどれだけ離れているかを求めます。

② 近ければ当たったと判定します（`isHit()`）

距離が「プレイヤーのサイズの半分＋敵のサイズの半分」より小さいと、当たりとします。プレイヤーも円の範囲で近さを判定する簡単な方法です。

③ 当たったらゲームを終えます


true
なら結果をGAME OVERにし、状態を
end
へ。
return
で今の処理を終えます。

次の draw() では結果画面を描く。
当たらなければプレイを続ける。
