# コードを変えて、動きを確かめよう

10～35分に使う1枚の投影資料です。画面には同名のHTMLを開きます。詳しい手順は生徒用テキスト、詳しい解説はLESSON_1～5を参照します。

## ① 円で練習する（10～25分）

編集：`practice.js`

```javascript
let playerSize = 80;
let playerColor = "yellow";
let gameTitle = "今日のゲーム";
```

- 大きさ：80 → 20で比べる。
- 色・タイトル：引用符の中を変える。
- `playerSize`は名前、`80`は値。

```javascript
circle(200, 150, playerSize);
```

横の位置・縦の位置・直径の順。この行は読むだけ。最後は直径100の青い円にします。

## ② ゲームの流れを知る（25～32分）

[コードと解説を開く（5画面）](06_コードと解説.html)

最初の準備：`setup()`で最初に1回、画面を用意します。

以降は`draw()`で次の処理をくり返します。

1. 前の絵を消す：背景を描いて、前の絵を消します。
2. 自機と敵の位置を変えて描く：自機は← →キーで横へ、敵は下へ動かします。
3. 当たり判定：自機と敵が重なったか調べます。当たれば終了、避ければ続行します。

続行なら次の描画へ進み、もう一度「消す → 動かして描く → 当たりを調べる」をくり返します。

## ③ ゲームをカスタム（32～35分）

先ほどの練習と同じように、変数の値を変えて、実際のゲームもカスタムしてみましょう。まずは自機を好きな色に。さらに今回は、自機のスピードも変えて、操作した感じがどう変わるか試してみましょう。

編集：`sketch.js`

1. CUSTOM AREAの`playerColor`を好きな色にする（例：`"yellow"`）。
2. `playerSpeed`を7から12へ変える。
3. 保存し、ゲーム本体の画面を更新して`1`で始める。
4. ← →で操作し、色と動く速さを確かめる。「速いと避けやすい？ 動きすぎて難しい？」

練習とゲームは別のファイル。円の練習で変えた値はゲームへ自動では移りません。

編集・実行は「ワーク用」。既存の値を変更 → 保存 → Chromeの対応する画面を更新。
