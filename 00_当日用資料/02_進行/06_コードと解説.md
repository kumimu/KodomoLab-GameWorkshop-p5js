# ゲームの仕組み：コードと解説

投影には同名HTMLを開きます。25～32分の7分枠：まとめを30秒、この5画面を計6分、切り替え等に30秒。コードは教材sketch.jsの抜粋で、変更・追加する指示ではありません。

## 1 最初の準備（1分）

画面を作る準備は、最初に1回。

sketch.js：setup() 全体

```javascript
function setup() {
  createCanvas(600, 400);
  textFont("sans-serif");
}
```


① setup() はいつ動く？

p5.jsが、読み込み後に
最初に1回
呼び出します。

② createCanvas(600, 400)

横600・縦400のゲーム画面を作ります。
2つの数値は、画面の大きさです。

③ textFont("sans-serif")

画面に表示する文字の書体を決めます。

ここでは準備。動きは次の draw() へ。


## 2 繰り返し描画（1分）

同じ画面を何度も描き直す。

sketch.js：draw() 全体

```javascript
function draw() {
  background(backgroundColor);

  if (gameState === "start") {
    showStartScreen();
  } else if (gameState === "play") {
    playGame();
  } else if (gameState === "end") {
    showEndScreen();
  }
}
```


① background(backgroundColor)

背景の色で塗り直し、前に描いた絵を消します。消さないと、移動前の絵が残ります。

② gameState で処理を選ぶ


start
：開始画面を描く

play
：プレイ中の処理を呼ぶ

end
：結果画面を描く

③ プレイ中は playGame() へ

自機と敵を動かす・描く・当たりを調べる処理へ進みます。次の描画でも draw() が呼ばれます。

「繰り返し描く」が、動きの土台。


## 3 自機と敵の移動（1分30秒）

位置の数値を変えてから描くと、動いて見える。

sketch.js：movePlayer() 全体

```javascript
function movePlayer() {
  if (keyIsDown(LEFT_ARROW)) {
    playerX -= playerSpeed;
  }
  if (keyIsDown(RIGHT_ARROW)) {
    playerX += playerSpeed;
  }

  playerX = constrain(playerX, playerSize / 2, width - playerSize / 2);
}
```

sketch.js：moveEnemy() 前半（次ページへ続く）

```javascript
function moveEnemy(enemy) {
  const multiplier = runOption("speedMultiplier", enemy);
  enemy.y += enemy.speed * (multiplier === undefined ? 1 : multiplier);
  // ↓ 続き（得点・再登場）は次のページへ
```


① 自機は playerX を変える


keyIsDown()
で、キーが押されているか調べます。

←：
playerSpeed
を引く → 左へ
→：
playerSpeed
を足す → 右へ

② constrain() で端に止める

横位置を画面内に収め、自機が外へ出るのを防ぎます。

③ 敵は enemy.y を増やす


xは横、yは縦。
敵の縦位置に速さを足すと、下へ動きます。

1倍の場合の意味（説明用・書き換え不要）：

```javascript
enemy.y += enemy.speed;
```

実コードは残し、移動部分を強調します。灰色の応用用コードは今回の説明対象外です。

位置を更新 → 描く。次の描画でまた更新。


## 4 得点と敵の再登場（1分）

下まで避けた敵を、画面の上へ戻して再利用する。

sketch.js：moveEnemy() 後半（前ページの続き・コメントを除く）

```javascript
  if (enemy.y > height + enemySize) {
    if (runOption("avoid", enemy) !== true) {
      score += 1;
    }
    respawnEnemy(enemy);
  }
}
```

sketch.js：respawnEnemy() 全体

```javascript
function respawnEnemy(enemy) {
  enemy.y = random(-300, -50);
  enemy.x = random(enemySize, width - enemySize);
  enemy.speed = enemySpeed + random(0, 2);
  runOption("spawnEnemy", enemy);
}
```


① 画面の下を通過した？


enemy.y &gt; height + enemySize
で、敵が画面の下まで進んだかを調べます。

② 避けたら得点を加える

基本は
score += 1
は「今の得点に1を足す」という意味です。

③ respawnEnemy(enemy) で上へ戻す


y
は画面より上の位置へ。

x
と速さもランダムに決め直します。

同じ敵を上へ戻す → また落ちてくる。


## 5 当たり判定（1分30秒）

「当たった？」を調べ、終了するか決める。

sketch.js：isHit() 全体

```javascript
function isHit(enemy) {
  const distance = dist(playerX, playerY, enemy.x, enemy.y);
  return distance < playerSize / 2 + enemySize / 2;
}
```

sketch.js：playGame() の当たり判定部分

```javascript
if (isHit(enemy)) {
  resultText = "GAME OVER";
  gameState = "end";
  return;
}
```


① dist() で中心同士の距離を測る

自機の位置と、敵の位置の間がどれだけ離れているかを求めます。

② 近すぎたら true を返す

距離が「自機のサイズの半分＋敵のサイズの半分」より小さいと、当たりとします。自機も円の範囲で近さを判定する簡単な方法です。

③ if (isHit(enemy)) で判断する


true
なら結果をGAME OVERにし、状態を
end
へ。
return
で今の処理を終えます。

次の draw() では結果画面を描く。
当たらなければプレイを続ける。
