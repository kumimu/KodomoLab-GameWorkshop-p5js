ブラウザ用の資料一覧からも開けます。HTMLはブラウザで閲覧・印刷するためのもの、MDは文章を編集するための原稿です。両方を修正する場合は内容を揃えます。

授業の流れ

  • 前半　オープニングから共通ハンズオンまで。シンプル版で遊び、JavaScriptの基礎練習とゲームの仕組みの解説を経て、プレイヤーの色と速さを変えます。
  • 後半　オプション実装から持ち帰りまで。A・B・G・H・Mから1つ選んで機能を追加し、仕上げと動作確認、作品レビュー、USBへの保存へ進みます。

全体は90分です。当日は参加者の進み具合を見ながら、前半・後半それぞれの中で説明や実習にかける時間を調整します。

応用課題では、選んだ機能だけのコードをsketch.js末尾の共通欄へ貼り、虫食いを全て埋めます。自分の設定は残したまま、予想クイズ・比較実験・コメント1行を通して改造を確かめます。早く進んだ人は、別の機能を同じ欄へ追加できます。

投影と実演の進め方

  1. 投影用テキストのT02から、シンプル版と発展版ゲームを開いて紹介します。
  2. T03でJavaScriptの基礎練習を案内し、practice.jsの変更、保存、Chromeでの画面更新を示します。
  3. T04前半の「ゲームの仕組みを見る」から、投影用まとめとコード解説へ進みます。全体への解説では基本の動作を扱います。
  4. コード解説の「ワークショップテキストに戻る」からT04後半に戻り、sketch.jsで色と速さを変える手順を案内します。
  5. 後半は「課題の選び方」を開き、選んだ課題の手順へ進みます。

開始前の配置

配布元のシンプル版から、同じ初期内容の2フォルダを用意します。

フォルダ 用途
オリジナル 初期状態の参照・復旧用。編集しない
ワーク用 基礎練習・改造・ブラウザ実行に使う

参加者はワーク用のindex.htmlとsketch.jsを開きます。基礎練習もワーク用のJS_15分入門を使います。途中で保存用フォルダを増やす作業は挟みません。

下記はスタッフが配布元を確認するためのリンクです。

  • シンプル版
  • 15分の基礎練習
  • 発展版ゲーム（完成見本）

発展版ゲームは、講師が短く紹介し、持ち帰り後に改造を楽しむための完成見本です。当日用の虫食いコードは、シンプル版へ貼ります。

配布・持ち帰り

この資料フォルダだけではゲームは動きません。資料と02_教材の構成を保って配布し、ゲーム側はp5.min.js・licenses・基礎練習を含むフォルダ全体を揃えます。教材だけを別にコピーする場合も、生徒用資料を開けるよう別途用意してください。

開始前に、持ち帰り用USBに「オリジナル」と「発展版ゲーム」をフォルダごとコピーします。終了時は、編集した「ワーク用」フォルダ全体を追加し、USB内のワーク用のindex.htmlから起動を確認します。

ライブラリの同梱物はライセンス・配布案内を参照してください。
