## 3　各PCのフォルダとソフト

配布元は`02_教材／01_配布テンプレート`です。開始前に同じ初期内容の「オリジナル」「ワーク用」を用意します。どちらもindex.html、sketch.js、p5.min.js、licenses、JS_15分入門を含むフォルダ全体を揃えます。

| フォルダ   | 使い方                                                     |
| ---------- | ---------------------------------------------------------- |
| オリジナル | 初期状態の参照・復旧用。編集しない                         |
| ワーク用   | 生徒が練習・改造・実行する。最後にUSBへコピーする          |
| 完成見本   | 発展版ゲーム。シンプル版の試遊直後（9〜10分）に講師が実演。ワーク用と区別して持ち帰る |

- [ ] 各PCでVS CodeとChromeを起動でき、実際の配布フォルダを開けた。
- [ ] オリジナルとワーク用は開始時に同じ内容で、練習・改造の試行が残っていない。
- [ ] 準備担当が各PCの「ワーク用」をGitで初期化し、練習・改造前の状態を初期コミットした。
- [ ] VS Codeでワーク用を開き、練習のpractice.jsとゲームのsketch.jsを探せる。
- [ ] Chromeでワーク用のゲーム本体と基礎練習を開き、どちらの画面か見分けられる。
- [ ] 保存→対応するChrome画面の更新で変更が反映されることを確認した。
- [ ] キーボード上段の1・2・3、左右キー、Spaceが使える。画面へのフォーカスと日本語入力オフも確認した。
- [ ] ファイルを探す際の、VS CodeからFinder／エクスプローラーに表示する操作を確認した。
- [ ] 通信を切ってもローカル教材を起動・操作できた。

事前の動作確認が済んだら「ワーク用」を初期状態に戻し、そのフォルダ内で準備担当が次のコマンドを実行します。

```sh
git init
git add .
git commit -m "ワークショップ開始時の教材"
```

授業中に保存用フォルダを増やす作業は挟みません。生徒のGitHubアカウント・Git・Node.js・npm・Live Server・Web Editorの登録やログインは必須にしません。

### VS Codeで引用符を揃える

教材のJavaScriptでは、文字を半角の二重引用符で囲みます（例：`"yellow"`）。事前に練習ファイルを保存し、引用符の形を確認します。

Prettierで保存時に整形しているPCでは、VS Codeの設定で「prettier.singleQuote」を検索し、オフにします。プロジェクトにPrettierの設定ファイルがある場合は、そちらの「singleQuote」をfalseにします。保存時に引用符が変わる場合は、JavaScriptの「Editor: Format On Save」をオフにして、教材の引用符を保ちます。 [Prettierの引用符設定](https://prettier.io/docs/options#quotes)
