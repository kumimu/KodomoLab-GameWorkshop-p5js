## 3　各PCのフォルダとソフト

配布元は`02_教材／01_配布テンプレート`です。開始前に同じ初期内容の「オリジナル」「ワーク用」を用意します。どちらもindex.html、sketch.js、p5.min.js、licenses、JS_15分入門を含むフォルダ全体を揃えます。

| フォルダ   | 使い方                                                     |
| ---------- | ---------------------------------------------------------- |
| オリジナル | 初期状態の参照・復旧用。編集しない                         |
| ワーク用   | 生徒が練習・改造・実行する。最後にUSBへコピーする          |
| 完成見本   | 発展版ゲーム。シンプル版で遊んだ直後（9〜10分）に講師が実演。ワーク用と区別して持ち帰る |

### 当日の確認（開始前）

- [ ] 開始前に、持ち帰り用USBへ「オリジナル」と「発展版ゲーム（完成版）」をフォルダごとコピーした。
- [ ] オリジナルとワーク用は開始時に同じ内容で、練習・改造の試行が残っていない。
- [ ] 準備担当が各PCの「ワーク用」をGitで初期化し、練習・改造前の状態を初期コミットした。

  ```sh
  git add .

  ```
