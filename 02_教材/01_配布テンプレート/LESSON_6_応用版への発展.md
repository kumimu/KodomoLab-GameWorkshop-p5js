# LESSON_6：基礎版から応用版への発展

## 概要
「避けゲー」から「NEON DODGE」へ。基礎版と応用版の大きな違いを理解し、プログラムの成長段階を学びます。

### このレッスンのポイント
- **技術的な進化**：p5.js から Canvas 2D API への移行
- **ゲーム設計の工夫**：ステージシステム、難易度調整の仕組み
- **コード規模の違い**：基礎版と応用版の構造比較
- **パフォーマンス**：Canvas API の効率性

| 項目 | 基礎版 | 応用版 |

## 第2部：技術的な違い

### 1. 描画システムの比較

#### 基礎版：p5.js を使う
```javascript
// p5.js は関数をシンプルに呼び出すだけ
function draw() {
  background(backgroundColor);          // 背景を塗る
  circle(playerX, playerY, playerSize); // 円を描く
  fill(enemyColor);                     // 色を設定
  rect(x, y, w, h);                    // 四角形を描く
}
```

**メリット**
- コードがシンプル
- 初心者向け
- 多くの関数が用意されている

**デメリット**
- 外部ライブラリが必要
- 大きなファイルサイズ
- 複雑な効果は手間

---

#### 応用版：Canvas 2D API を使う
```javascript
// Canvas は「文脈」を通じて細かく制御
const ctx = canvas.getContext('2d');

function draw() {
  ctx.fillStyle = backgroundColor;           // 色を設定
  ctx.fillRect(0, 0, W, H);                 // 矩形で背景を埋める
  
  ctx.fillStyle = playerColor;
  ctx.beginPath();
  ctx.arc(playerX, playerY, playerSize, 0, TAU);  // 円のパス作成
  ctx.fill();                                       // 塗りつぶし
}
```

**メリット**
- ブラウザ標準 API（外部ライブラリ不要）
- より細かく制御可能
- パフォーマンス重視の設計に向く

**デメリット**
- コードがやや複雑
- 状態管理が必要
- エラーが見えにくい場合がある

---

### 2. ゲームループの改善

#### 基礎版：p5.js 自動ループ
```javascript
// p5.js は自動的に draw() を呼び出す（1フレーム/60fps）
let gameState = "start";

function draw() {
  if (gameState === "start") {
    // スタート画面
  } else if (gameState === "play") {
    // ゲーム中
  }
  // p5.js が自動でループ
}
```

#### 応用版：requestAnimationFrame
```javascript
// Canvas API では自分で制御
let lastTime = 0;
let elapsed = 0;

function gameLoop(now) {
  let dt = (now - lastTime) / 1000;  // デルタタイム（経過時間）
  lastTime = now;
  
  if (mode === 'play') {
    elapsed += dt;  // 累積時間を追跡
    // 時間ベースでゲーム更新
  }
  
  requestAnimationFrame(gameLoop);  // 次フレームをリクエスト
}
```

**応用版の工夫**
- `deltaTime`（前フレームからの経過時間）を計算
- 時間経過に基づいて敵を生成・判定
- より正確なタイミング制御が可能

const STAGES = [

**ステージシステムのメリット**

3. **スケーラビリティ**：新ステージ追加が簡単
4. **プログレッション**：段階的な難易度上昇

## 第5部：敵の多様性

### 基礎版：敵の種類は 1 種
```javascript
// 敵は常に「上から落ちてくる」
enemies.push({
  x: random(enemySize, width - enemySize),
  y: random(-300, -50),
  speed: enemySpeed + random(0, 2)
});
```

### 応用版：敵の種類は 3 種以上

```javascript
// 敵タイプを文字列で管理
const type = Math.random() < .17 ? 'zig'      // 17% ジグザグ
           : Math.random() < .12 ? 'tank'     // 12% タンク
           : 'normal';                         // 71% 通常

enemies.push({
  type: type,
  x: rand(14, 27),
  y: -30,
  r: rand(14, 27),
  speed: difficultySetting * rand(0.9, 1.1),
  vx: type === 'zig' ? rand(-50, 50) : 0,     // ジグザグの横速度
  health: type === 'tank' ? 3 : 1              // タンクは3回被弾で破壊
});
```

**新しい敵タイプ**

| タイプ | 動き | 対策 |
|--------|------|------|
| **normal** | 下へ一直線 | 左右に移動して避ける |
| **zig** | 下りながら左右に揺れる | タイミングを計る |
| **tank** | 遅いが3回被弾に耐える | 射撃して複数回攻撃 |

## 第6部：シューティング機能

### 基礎版：避けるだけ
```javascript
// 基礎版にはシューティング機能なし
```

### 応用版：プレイヤーも反撃可能
```javascript
// プレイヤーが自動射撃（スペースキーで連続射撃可能）
let shotTimer = 0;
let bullets = [];

// 毎フレーム
shotTimer += dt;
if (shotTimer > shootInterval) {
  bullets.push({
    x: player.x,
    y: player.y - 10,
    vy: -bulletSpeed
  });
  shotTimer = 0;
  sound(880, .1);  // 射撃音
}

// 敵への当たり判定
for (let bullet of bullets) {
  for (let enemy of enemies) {
    if (dist(bullet.x, bullet.y, enemy.x, enemy.y) < bullet.r + enemy.r) {
      // 敵を破壊
      burst(enemy.x, enemy.y, 'yellow', 8);
      score += 10;
    }
  }
}
```

**シューティングのメリット**
1. **プレイヤーの選択肢が増える**：避けるだけでなく攻撃も可能
2. **戦略性**：スコア稼ぎの方法が多様化
3. **爽快感**：敵を破壊する快感

## 第11部：講師向けポイント

### 基礎版を学んだ生徒に「応用版の仕組み」を説明する順序

1. **「p5.js」と「Canvas API」の違い**を視覚的に説明
   - 「どちらも図形を描く道具」
   - 「基本原理は同じだけど、細かい操作方法が違う」

2. **ステージシステムを「難易度の工夫」として説明**
   - 「ゲームをおもしろくするために、数字を変えるだけで難易度が変わる工夫」

3. **敵の種類を「分岐処理の応用」として説明**
   - 「if 文で敵のタイプを決めて、動き方を変える」

4. **シューティング機能を「配列の応用」として説明**
   - 「敵の配列と同じように、弾の配列を管理する」

5. **パワーアップを「時間制御の応用」として説明**
   - 「時間経過でパワーアップの効果が消える仕組み」

### よくある質問への回答例

**Q: 「なぜ p5.js ではなく Canvas を使うのか」**
- A: 「p5.js は初心者向けで便利ですが、ファイルサイズが大きく、複雑な効果は作りにくい。Canvas API はブラウザに最初からついている基本機能で、より細かく制御できます」

**Q: 「敵の種類を増やしたら、別関数で管理しないといけないのか」**
- A: 「基礎では敵の配列を1つで管理しましたが、応用版は『配列の中のオブジェクト』に『type』という情報を持たせる工夫をしています。1つの配列で複数タイプを管理できます」

**Q: 「ボスバトルを作るには」**
- A: 「ボスは『敵の強化版』と考えます。『体力が複数ある』『複数の攻撃パターンを持つ』などの工夫をするだけです」

## まとめ

| 段階 | 学び方 | 次のステップ |
|------|--------|-----------|
| **基礎版** | 「ゲームの基本」 (p5.js) | 「応用版への扉を開く」 |
| **応用版** | 「プロゲーム的な工夫」 (Canvas API) | 「自分だけのゲーム開発へ」 |

基礎版で学んだプログラムの概念は、応用版でも変わりません。

- 「敵の配列」→ 複数タイプ管理へ進化
- 「当たり判定」→ より複雑な判定へ進化
- 「状態管理」→ ステージシステムへ進化

**「プログラムは、基本から応用へと自然に成長していく」** という理解が重要です。
