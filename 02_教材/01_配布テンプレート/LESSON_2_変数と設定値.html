レッスン2：変数と設定値

コードを全部覚える必要はありません。

仕事でプログラムを書く人も、分からないことは調べながら書いています。このレッスンも、気になるところから読んで、試したいところを一つ試してみましょう。

この資料の使い方

色・大きさ・速さなどの設定値が、ゲームのどこで使われるか調べるときに参照します。

当日の進行と投影手順は当日用資料の使い方を参照してください。

「現在のコード」と示す例はシンプル版sketch.jsの対応する関数です。「抜粋」「考え方の例」は説明用で、そのままsketch.jsへ追加するコードではありません。改造では既存の値を変更し、応用機能は当日用の課題ページからコピーします。

変更例で複数の値を並べている場合は候補の比較です。使う値を1つ選び、既存の設定行を書き換えます。新しい設定行を末尾へ追加しません。

🎯 学習目標

CUSTOM AREA（カスタムエリア）にある7つの設定値を理解し、これらを変更するとゲームがどう変わるかを体験する。

  • 変数とは何か
  • CUSTOM AREA にある7つの設定値
  • 色の指定方法
  • 数値を変更した時の効果
  • 参加者が最初に試すべき改造

🔧 CUSTOM AREA とは

sketch.js の冒頭に、参加者が自由に改造できる領域があります。

sketch.js の対応箇所（関数名で検索）：

// =====================================
// 自分だけの避けゲー
// 開始画面・難易度選択・終了画面つき
// =====================================

// ===== CUSTOM AREA：まずはここを改造しよう！ =====
let playerColor = "cyan";
let enemyColor = "red";
let backgroundColor = "black";

let playerSize = 40;
let enemySize = 35;
let playerSpeed = 7;

let gameTitle = "隕石をよけろ！";
// ================================================

この領域には、ゲームの見た目や速度に関わる7つの設定値があります。

ここを変更するだけで、生徒は「自分のゲーム」を作ることができます。

📦 変数とは何か

変数 は、「データを保存する箱」です。

let playerColor = "cyan";

この1行を分解すると：

部分 意味
let 「新しい箱を作る」という命令
playerColor 箱の名前
= 「中身を入れる」という意味
"cyan" 箱の中身（この場合、色を表す文字列）
; 文の終わり

変数が大事な理由

もし変数がなければ、コードはこんなになります：

// 悪い例：色を書きまくる
// 【役割】自機を画面へ描きます。
function drawPlayer() {
  fill("cyan");
  // 三角形を描く座標の指定は、この説明例では省略しています。
}

// 【役割】開始画面のタイトルと案内を表示します。
function showStartScreen() {
  fill("white");
  text("プレイヤーの色は、青です", width / 2, 100);
}

// 【役割】得点などのゲーム情報を描きます。
function drawGameInfo() {
  fill("white");
  text("プレイヤーの色", 20, 28);  // ← またプレイヤーの色について書いてる
}

プレイヤーの色を変えたいときに、ファイル全体から「cyan」を探して変更しなければなりません。大変です！

でも、変数を使えば：

// 良い例：最初に1回だけ決める
let playerColor = "cyan";

// あとはこの変数を使うだけ
// 【役割】自機を画面へ描きます。
function drawPlayer() {
  fill(playerColor);
  // 三角形を描く座標の指定は、この説明例では省略しています。
}

// 色を変えたいときは、1行目だけを変更する
// let playerColor = "lime";  ← ここだけ変えば全部変わる

1行変更するだけで、ゲーム全体に反映されます。

🎨 CUSTOM AREA の7つの設定値

1. playerColor — プレイヤーの色

let playerColor = "cyan";

役割： プレイヤー（三角形）の色を指定します。

使われている場所： sketch.js の対応箇所（関数名で検索）

// 【役割】自機を画面へ描きます。
function drawPlayer() {
  // Hなどへ「自機を描く直前です」と伝え、光を先に描きます。
  runOption("beforePlayer");
  fill(playerColor);
  noStroke();
  triangle(
    playerX,
    playerY - playerSize / 2,
    playerX - playerSize / 2,
    playerY + playerSize / 2,
    playerX + playerSize / 2,
    playerY + playerSize / 2,
  );
}

変更例：

let playerColor = "lime";      // 緑色
playerColor = "pink";   // ピンク色
playerColor = "yellow";    // 黄色

2. enemyColor — 敵の色

let enemyColor = "red";

役割： 基本の敵（円）の色を指定します。現在のdrawEnemyは、追加機能が描画済みなら戻り、そうでなければoptionEnemyColorで色を決めて描きます。追加機能の色指定がなければ、このenemyColorを使います。

使われている場所： sketch.js の対応箇所（関数名で検索）

// 【役割】敵の色と形を決めて描きます。
function drawEnemy(enemy) {
  // Hがtrue（描画済み）を返したら、下にある通常の円は描きません。
  if (runOption("drawEnemy", enemy) === true) {
    return;
  }
  fill(optionEnemyColor(enemy));
  noStroke();
  circle(enemy.x, enemy.y, enemySize);
}

変更例：

let enemyColor = "orange";     // オレンジ
enemyColor = "cyan";    // シアン色
enemyColor = "purple";     // 紫

3. backgroundColor — 背景色

let backgroundColor = "black";

役割： ゲーム画面全体の背景色を指定します。

使われている場所： sketch.js の対応箇所（関数名で検索）（毎フレーム）

// 【役割】画面を描き直し、現在の状態に応じた処理を呼びます。
function draw() {
  background(backgroundColor);  // ← ここで使われている

  if (gameState === "start") {
    showStartScreen();
  }
  // ...
}

変更例：

let backgroundColor = "navy";   // 濃い青
backgroundColor = "midnightblue"; // 濃い青
backgroundColor = "white";   // 白（見えにくくなる可能性）

4. playerSize — プレイヤーの大きさ

let playerSize = 40;

役割： プレイヤー（三角形）のサイズをピクセル単位で指定します。

使われている場所： sketch.js の対応箇所（関数名で検索）の drawPlayer() と movePlayer()

// 【役割】キーに応じて自機を動かします。
function movePlayer() {
  if (keyIsDown(LEFT_ARROW)) {
    playerX -= playerSpeed;
  }
  if (keyIsDown(RIGHT_ARROW)) {
    playerX += playerSpeed;
  }

  playerX = constrain(playerX, playerSize / 2, width - playerSize / 2);
}

プレイヤーが画面からはみ出さないように、左右の端をコントロールしています。

変更例：

let playerSize = 60;  // 大きくなる（当たりやすくなる）
playerSize = 20;  // 小さくなる（当たりにくくなる）

5. enemySize — 敵の大きさ

let enemySize = 35;

役割： 敵（円）のサイズをピクセル単位で指定します。

使われている場所： sketch.js の対応箇所（関数名で検索）の drawEnemy() と、当たり判定

// 【役割】自機と敵の距離で衝突を調べます。
function isHit(enemy) {
  const distance = dist(playerX, playerY, enemy.x, enemy.y);
  return distance < playerSize / 2 + enemySize / 2;  // ← ここで使われている
}

当たり判定も enemySize の値に基づいて計算されます。

敵が大きいと、当たりやすくなります。

変更例：

let enemySize = 50;  // 大きくなる（当たりやすくなる、難しくなる）
enemySize = 20;  // 小さくなる（当たりにくくなる、簡単になる）

6. playerSpeed — プレイヤーの移動速度

let playerSpeed = 7;

役割： キー入力でプレイヤーがどれくらい速く移動するかを指定します。

使われている場所： sketch.js の対応箇所（関数名で検索）

// 【役割】キーに応じて自機を動かします。
function movePlayer() {
  if (keyIsDown(LEFT_ARROW)) {
    playerX -= playerSpeed;
  }
  if (keyIsDown(RIGHT_ARROW)) {
    playerX += playerSpeed;
  }

  playerX = constrain(playerX, playerSize / 2, width - playerSize / 2);
}

毎フレーム、左矢印キーが押されていれば playerX から playerSpeed 分だけ左に移動します。

playerSpeed が大きいほど、プレイヤーが速く動きます。

変更例：

let playerSpeed = 10;  // 速くなる（移動が楽になる、簡単）
playerSpeed = 3;   // 遅くなる（難しくなる）

重要： このゲームでは、敵の速度（enemySpeed）は難易度ごとに異なります。レッスン4で詳しく説明します。

7. gameTitle — ゲームのタイトル

let gameTitle = "隕石をよけろ！";

役割： 開始画面に表示されるゲームのタイトルです。

使われている場所： sketch.js の対応箇所（関数名で検索）

// 【役割】開始画面のタイトルと案内を表示します。
function showStartScreen() {
  fill("white");
  textAlign(CENTER);

  textSize(36);
  text(gameTitle, width / 2, 75);  // ← ここで使われている

  textSize(22);
  text("難易度を選んでスタート！", width / 2, 135);
  // ...
}

変更例：

let gameTitle = "宇宙を守れ！";
gameTitle = "敵戦闘機を避けろ！";
gameTitle = "My Game";

🎨 色を指定する方法

色は英語の名前で指定します。

let playerColor = "red";
let enemyColor = "cyan";
let backgroundColor = "black";

使える色名の例：

英語 日本語
"red" 赤
"blue" 青
"green" 緑
"yellow" 黄
"purple" 紫
"orange" オレンジ
"pink" ピンク
"cyan" シアン（水色）
"lime" ライム（黄緑）
"navy" ネイビー（濃い青）
"gray" または "grey" グレー
"white" 白
"black" 黒

全ての色名は、p5.js公式ドキュメント（Color Reference）に載っています。

https://v1.p5js.org/reference/#/p5/color

📝 実際の変更を試す（シミュレーション）

例1：プレイヤーとタイトルを変更

元のコード：

let playerColor = "cyan";
let enemyColor = "red";
let backgroundColor = "black";
let playerSize = 40;
let enemySize = 35;
let playerSpeed = 7;
let gameTitle = "隕石をよけろ！";

変更後：

let playerColor = "lime";         // プレイヤーを緑色に
let enemyColor = "red";
let backgroundColor = "black";
let playerSize = 40;
let enemySize = 35;
let playerSpeed = 7;
let gameTitle = "敵を避けまくれ！";  // タイトル変更

ゲームはこう変わる：

  • 開始画面のタイトルが「敵を避けまくれ！」に変わる
  • プレイヤーが緑色の三角形になる
  • 敵は赤いままなので、背景（黒）の中で目立ちやすくなる

例2：サイズと速さを比べる（考え方の例）

変更後：

let playerColor = "cyan";
let enemyColor = "red";
let backgroundColor = "black";
let playerSize = 60;        // 大きくなる
let enemySize = 20;         // 小さくなる（避けやすい）
let playerSpeed = 10;       // 速くなる（移動が楽）
let gameTitle = "隕石をよけろ！";

ゲームはこう変わる：

  • プレイヤーが大きくなり、移動も速くなる。大きさは当たりやすさにも影響するため、遊んで確認する
  • 敵が小さくなり、当たりにくくなる（避けやすい）
  • どの変更が遊びやすさに影響したか、1つずつ比べる

例3：見た目を大きく変える

変更後：

let playerColor = "deeppink";    // 深いピンク
let enemyColor = "lime";     // ネオン緑
let backgroundColor = "midnightblue"; // 濃い青
let playerSize = 40;
let enemySize = 35;
let playerSpeed = 7;
let gameTitle = "NEONバトル";

ゲームはこう変わる：

  • 背景が暗い紫になり、より近未来的な雰囲気
  • プレイヤーがピンク、敵がネオン緑で、コントラストが強い
  • タイトルが「NEONバトル」に変わり、テーマが統一される

🔄 座標と移動の仕組み

ゲーム画面は、左上を (0, 0) とする座標系を使っています。

プレイヤーの位置

let playerX;
let playerY;

ゲーム開始時、sketch.js の対応箇所（関数名で検索）：

playerX = width / 2;      // 画面の中央 = 300
playerY = height - 55;    // 画面の下から少し上 = 345

プレイヤーは、画面中央の下に表示されます。

移動の仕組み

movePlayer() 関数：

// 【役割】キーに応じて自機を動かします。
function movePlayer() {
  if (keyIsDown(LEFT_ARROW)) {
    playerX -= playerSpeed;
  }
  if (keyIsDown(RIGHT_ARROW)) {
    playerX += playerSpeed;
  }

  playerX = constrain(playerX, playerSize / 2, width - playerSize / 2);
}

毎フレーム、以下が起こります：

  1. 左矢印キーが押されていれば：playerX = playerX - 7（左に移動）
  2. 右矢印キーが押されていれば：playerX = playerX + 7（右に移動）
  3. プレイヤーが画面外に出ないように制限：constrain() で左右の端を制御

もし playerSpeed = 10 に変更したら：

毎フレーム、10ピクセル分動きます。7ピクセルより速い。

📝 重要な用語のまとめ

用語 意味 例
変数 データを保存する箱 let playerColor = "cyan";
プロパティ（設定値） 変数に保存される値 playerColor の値は "cyan"
色名 英語の色の名前 "red"、"blue"
ピクセル 画面の最小単位 プレイヤーのサイズは 40 ピクセル
座標 画面上の位置 (300, 345) は画面中央の下
constrain() 値を指定の範囲内に制限する関数 プレイヤーが画面外に出ないようにする
