## ⚙️ 5つの設定値（CUSTOM AREA）

```javascript
// 色
const playerColor = color(0, 255, 255);     // プレイヤー（シアン）
const enemyColor = color(255, 0, 0);        // 敵（赤）
const backgroundColor = color(20, 20, 30);  // 背景（濃紺）

// サイズ・速度
const playerSize = 15;          // プレイヤーの大きさ
const enemySpeed = 3;           // 敵の落下速度
```

**変更例：** `enemySpeed = 5` にすると、敵が速く落ちてくる！

## 🔑 重要な3つの関数

### (1) `draw()` — ゲームループ（1秒間に60回実行）

```javascript
function draw() {
  background(backgroundColor);  // 前のフレームを消す
  
  if (gameState === "start") {
    showStartScreen();          // 開始画面を描く
  } else if (gameState === "play") {
    playGame();                 // ゲーム中の処理
  } else if (gameState === "end") {
    showEndScreen();            // 終了画面を描く
  }
}
```

**ポイント：** 毎フレーム背景が消されて、新しい画像が描き直される。これで敵が落ちているように見える。

---

### (2) プレイヤーの移動 — `keyIsDown()` でキー入力を検出

```javascript
function movePlayer() {
  if (keyIsDown(LEFT_ARROW)) {          // ← キーが押されている
    playerX -= playerSpeed;
  }
  if (keyIsDown(RIGHT_ARROW)) {         // → キーが押されている
    playerX += playerSpeed;
  }
  // playerX が画面外に出ないように制限
  playerX = constrain(playerX, playerSize, W - playerSize);
}
```

**ポイント：** `keyIsDown()` で**今、このキーが押されているか** を毎フレーム確認。

---

### (3) 敵との当たり判定 — `dist()` で距離を計算

```javascript
function isHit(enemy) {
  const d = dist(playerX, playerY, enemy.x, enemy.y);
  // プレイヤーと敵の半径の合計より距離が小さい = 当たっている
  return d < playerSize + enemy.size;
}
```

**ポイント：** 敵と敵が近いほど小さくなる。敵半径 + プレイヤー半径より小さい = 衝突！

## 🐛 よくあるバグと対応

| バグ | 原因 | 対応方法 |
|-----|------|---------|
| **プレイヤーが動かない** | キー入力の受け取り忘れ | `keyIsDown()` が正しいか確認 |
| **敵が見えない** | 敵の色が背景と同じ | `enemyColor` を変える |
| **敵が速すぎ / 遅すぎ** | `enemySpeed` が大きすぎる | 小さい値（1〜5）を試す |
| **画面がカクカク** | フレームレート低下 | ブラウザを再起動 |
| **全く改造できない** | ブラウザのキャッシュ | `Ctrl + Shift + R` で強制更新 |

## 💡 JavaScript の基本概念

| 概念 | 説明 | このゲームでの例 |
|------|------|-----------------|
| **変数** | 値を保存する箱 | `let playerX = 300;` |
| **関数** | やることをまとめたもの | `function movePlayer() { ... }` |
| **if 文** | 条件によって処理を分ける | `if (gameState === "play") { ... }` |
| **ループ** | 同じ処理を繰り返す | `for (const enemy of enemies) { ... }` |
| **配列** | 複数のデータをまとめる | `const enemies = [敵1, 敵2, 敵3];` |
| **オブジェクト** | 関連するデータをまとめる | `const enemy = { x: 100, y: 50, type: 'fast' };` |
