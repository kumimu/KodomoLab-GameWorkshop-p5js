# 15分で体験するJavaScript — ゲーム改造の準備

さっき遊んだゲームの色、大きさ、タイトルは、コードの中の値で決まっています。小さな練習で書き方に慣れてから、自分のゲームを変えましょう。

**今日のゴール：数値・文字・変数を使い、画面を自分で変える。**

## 1　練習を始めよう（講師と一緒に）

練習には [p5.js Web Editor](https://editor.p5js.org/) を使います。講師が用意したコードをsketch.jsに入れ、▶（実行）を押してください。白いタイトルと水色の円が出れば準備完了です。

- 練習中は変更するたびに▶を押します。ブラウザのページ全体は更新しません。
- 編集画面の初期コードは練習コードに置き換えます。避けゲーム本体のsketch.jsに貼らないでください。
- 準備が間に合わないときは、講師が案内するローカル練習版を使います。

### 最初にバージョンを確認しよう

講師と一緒に、画面右上の表示が **p5.js 1.11.13** になっているか確認します。違う場合は、歯車 →「Library Management」→「p5.js Version」で1.11.13を選びます。追加ライブラリはすべてオフのままで構いません。

「Not Maintained」と出ても、入力ミスのエラーではありません。今日は講師が指定する1.11.13を使います。ローカル練習版の場合、この設定操作は不要です。

### 練習コード（講師が開始前に準備）

```javascript
// まずは上の3行だけ変えてみよう！
let playerSize = 40;
let playerColor = "cyan";
let gameTitle = "わたしのゲーム";

function setup() {
  createCanvas(400, 260);
  textFont("sans-serif");
}

function draw() {
  background("black");
  noStroke();
  fill("white");
  textAlign(CENTER);
  textSize(24);
  text(gameTitle, 200, 55);
  fill(playerColor);
  circle(200, 150, playerSize);
}
```

## 2　数値を変える（最初の5分）

上から2行目を探します。

```javascript
let playerSize = 40;
```

1. 40を80にすると、円はどうなるか予想しましょう。
2. **40だけを80に変えて**、▶を押しましょう。
3. 20にも変えて、もう一度▶を押しましょう。

**発見：** 数値を変えると、円の大きさが変わります。この数値は円の直径です。大きい数字ほど大きな円になります。

- [ ] 円を大きくできた
- [ ] 円を小さくできた

ゲームでは、同じ名前のplayerSizeでプレイヤーの大きさを変えられます。練習では円、ゲームでは三角形が変わります。

## 3　文字を変える（次の5分）

次の行を探します。

```javascript
let playerColor = "cyan";
```

cyanだけをyellowに変え、▶を押しましょう。円が黄色になれば成功です。redやlimeでも試せます。

次に、タイトルも変えてみましょう。

```javascript
let gameTitle = "わたしのゲーム";
```

**引用符の内側だけ**を、好きなタイトルに変えます。日本語も使えます。

**発見：** `"yellow"`や`"わたしのゲーム"`のように、引用符で囲んだ文字を「文字列」と呼びます。色の名前も文字列として渡しています。

| 書くもの | 例 | 今日の書き方 |
|---|---|---|
| 大きさの数値 | 80 | 引用符なし |
| 色の名前 | "yellow" | 半角の引用符で囲む |
| タイトル | "星をよけろ！" | 半角の引用符で囲む |

- [ ] 円の色を変えられた
- [ ] 自分のタイトルを表示できた

## 4　変数の意味を知る（最後の5分）

```javascript
let playerSize = 80;
```

これは「playerSizeという名前の変数を用意し、80という値を入れる」という意味です。

| 部分 | 意味 |
|---|---|
| let | 変数を用意するための言葉 |
| playerSize | 変数の名前 |
| = | 右側の値を左の変数に入れる |
| 80 | 今回入れる値 |
| ; | 文の終わりにつける記号 |

下の方には、こんな行があります。

```javascript
circle(200, 150, playerSize);
```

「円を描くとき、大きさにはplayerSizeの値を使ってね」という指示です。最初の200と150は円の中心の位置です。今日はそのままで構いません。

**確認クイズ：円を大きくして青くしたいとき、上の3行のどこを変えますか？**

予想してから、playerSizeを100、playerColorを"blue"に変え、▶で確かめましょう。

変数の名前や下の処理は、今日は変更しません。setupやdraw、括弧の意味を全部覚えなくても、上の値を変える体験はできます。

## 5　避けゲームに戻ろう

講師の案内でVS Codeの**ゲーム本体のsketch.js**を開き、CUSTOM AREAを探します。

```javascript
let playerColor = "cyan";
let playerSize = 40;
let playerSpeed = 7;
let gameTitle = "隕石をよけろ！";
```

※本体では、これらの行の間にほかの設定もあります。この抜粋を貼り付けず、すでにある行を探してください。

まず1か所だけ変更し、保存して、ゲームを開いているブラウザを更新しましょう。

| 環境 | 変更の反映 |
|---|---|
| Web Editorでの練習 | ▶を押す |
| Windowsのゲーム／ローカル練習 | Ctrl+Sで保存 → ブラウザでF5 |
| Macのゲーム／ローカル練習 | Cmd+Sで保存 → ブラウザでCmd+R |

## 困ったとき

- **色が変わらない：** yellowのつづりと、▶を押したかを確認。
- **エラーが出た：** 引用符、=、;を消していないか確認。引用符や記号は半角を使います。困ったら手を挙げてください。
- **文字は日本語でよい？：** タイトルの引用符の内側は日本語でOKです。
- **ゲームが変わらない：** 練習用とゲーム本体のファイルを取り違えていないか、保存・更新したかを確認。
- **戻したい：** 直前の変更をCtrl+Z（MacはCmd+Z）で戻し、もう一度反映します。

## ローカル練習版を使う場合

同じフォルダのindex.htmlを開き、VS Codeでpractice.jsを編集します。親フォルダのp5.min.jsを使うため、この練習フォルダだけを移動しないでください。ゲーム本体のファイルは変更しません。
