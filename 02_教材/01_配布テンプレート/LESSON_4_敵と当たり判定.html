レッスン4：敵と当たり判定

コードを全部覚える必要はありません。

仕事でプログラムを書く人も、分からないことは調べながら書いています。このレッスンも、気になるところから読んで、試したいところを一つ試してみましょう。

この資料の使い方

敵が落ちて再登場する仕組みや、当たり判定の計算を詳しく知りたいときに参照します。

当日の進行と投影手順は当日用資料の使い方を参照してください。

「現在のコード」と示す例はシンプル版sketch.jsの対応する関数です。「抜粋」「考え方の例」は説明用で、そのままsketch.jsへ追加するコードではありません。改造では既存の値を変更し、応用機能は当日用の課題ページからコピーします。

🎯 学習目標

敵がどのように生成・移動し、プレイヤーとの衝突がどのように判定されるのかを理解する。

  • 敵の配列管理
  • 敵の生成（スポーン）と再利用
  • 敵の落下（移動）の仕組み
  • 当たり判定の計算方法（dist() 関数）
  • ゲームオーバーの流れ

👾 敵とは何か

ゲームでは、敵は 配列 で管理されています。

let enemies = []; // 敵の配列（最初は空）

配列とは — 複数の値をまとめて保存する「箱」です。

敵が1個、2個、3個と増えても、enemies という1つの変数で管理できます。

🎲 敵の生成と初期化

ゲーム開始時に敵を作る

sketch.js の対応箇所（関数名で検索）（startGame() 関数）：

// 【役割】選んだ難易度でゲームを初期化して開始します。
function startGame(level) {
  if (level === 1) {
    difficultyName = "かんたん";
    enemySpeed = 4;
    enemyCount = 1;
    clearTime = 30;
  } else if (level === 2) {
    difficultyName = "ふつう";
    enemySpeed = 6;
    enemyCount = 2;
    clearTime = 45;
  } else {
    difficultyName = "むずかしい";
    enemySpeed = 8;
    enemyCount = 3;
    clearTime = 60;
  }

  playerX = width / 2;
  playerY = height - 55;
  score = 0;
  startTime = millis();
  resultText = "";
  enemies = [];

  for (let i = 0; i < enemyCount; i++) {
    enemies.push({
      x: random(enemySize, width - enemySize),
      y: random(-300, -50),
      speed: enemySpeed + random(0, 2),
    });
  }

  runOption("start");
  for (const enemy of enemies) {
    runOption("spawnEnemy", enemy);
  }
  gameState = "play";
}

難易度による敵の数の違い

難易度 enemyCount 敵の数
かんたん 1 1個
ふつう 2 2個
むずかしい 3 3個

敵の初期データ

各敵は、以下のデータを持ちます：

const sampleEnemy = {
  x: random(enemySize, width - enemySize),  // 敵のX座標（ランダム）
  y: random(-300, -50),                     // 敵のY座標（画面上の外から出現）
  speed: enemySpeed + random(0, 2)          // 敵の速度（基本速度 + ランダム値）
};

random() 関数とは

random(a, b) は、a から b の間のランダムな数を返します。

例：

x: random(enemySize, width - enemySize);

enemySize = 35 の場合：

x: random(35, 565); // 35〜565の間でランダムに選ばれる

敵がランダムな位置から落ちてくるため、毎回異なるゲームになります。

敵のY座標がマイナス？

y: random(-300, -50);

なぜマイナスなのか？

敵は画面の上の外から出現します。

Y = -300  ← 敵の初期位置（画面の外）
Y = -200
Y = -100
Y = -50
Y = 0     ← 画面の上端
Y = 100
Y = 200
...
Y = 400   ← 画面の下端

敵は毎フレーム下へ移動するので、やがて画面に見えるようになります。

🔄 敵の移動（落下）

moveEnemy() と respawnEnemy()（現在のコード）

sketch.js の対応箇所（関数名で検索）：

// 【役割】敵を動かし、通過したときの得点と再登場を処理します。
function moveEnemy(enemy) {
  // Aの① ゲームのコードから追加機能へ「この敵は何倍の速さ？」と聞きます。
  const multiplier = runOption("speedMultiplier", enemy);
  // Aの③ 返ってきた倍率を元の速さに掛けます。返事がなければ1倍です。
  enemy.y += enemy.speed * (multiplier === undefined ? 1 : multiplier);
  if (enemy.y > height + enemySize) {
    // 応用側で得点を計算した場合は、標準の1点を重ねて加えません。
    // Mがtrue（計算済み）を返したら、標準の1点は重ねて足しません。
    if (runOption("avoid", enemy) !== true) {
      score += 1;
    }
    respawnEnemy(enemy);
  }
}

// 【役割】敵の位置・速さ・追加機能の情報を決め直します。
function respawnEnemy(enemy) {
  enemy.y = random(-300, -50);
  enemy.x = random(enemySize, width - enemySize);
  enemy.speed = enemySpeed + random(0, 2);
  runOption("spawnEnemy", enemy);
}

敵が下へ移動

enemy.y += enemy.speed;

これは追加機能がない場合の考え方を示す1行です。現在のゲームのコードは、元の速さに追加機能から返された倍率（未指定なら1）を掛け、毎フレーム敵のY座標を増やします。

敵のY座標が増える = 画面の下へ移動する

例： enemy.speed = 6 の場合

フレーム1：enemy.y = -50 + 6 = -44
フレーム2：enemy.y = -44 + 6 = -38
フレーム3：enemy.y = -38 + 6 = -32
...
フレーム80：enemy.y = 430
フレーム81：enemy.y = 436になり、435を超えるので再登場の処理へ

敵が画面に見えるようになり、下へ落ちていきます。

敵が画面の下を通り過ぎた場合

現在のmoveEnemyの該当部分です。

if (enemy.y > height + enemySize) {
  if (runOption("avoid", enemy) !== true) {
    score += 1;
  }
  respawnEnemy(enemy);
}

敵が画面の下を完全に通り過ぎると（enemy.y > 400 + 35、つまり435）、追加機能が得点を計算していなければ1点を足します。その後、respawnEnemyが敵の位置と速さを決め直し、追加機能へ登場を知らせます。

新しい敵へ入れ替えるのではなく、同じ敵の情報を書き換えて再利用します。追加機能がない初期状態では、画面下を通過するたびに1点です。

敵の速度のランダム化

enemy.speed = enemySpeed + random(0, 2);

敵の速度を毎回ランダムに変えることで、ゲームのバリエーションが増えます。

例： enemySpeed = 6 の難易度で：

1回目：speed = 6 + 0.5 = 6.5
2回目：speed = 6 + 1.8 = 7.8
3回目：speed = 6 + 0.1 = 6.1

全ての敵が同じ速度ではなく、少しずつ異なります。

📏 当たり判定の計算

isHit() 関数

sketch.js の対応箇所（関数名で検索）：

// 【役割】自機と敵の距離で衝突を調べます。
function isHit(enemy) {
  const distance = dist(playerX, playerY, enemy.x, enemy.y);
  return distance < playerSize / 2 + enemySize / 2;
}

dist() 関数とは

dist(x1, y1, x2, y2) は、2点間の距離を計算する関数です。

数学の公式：

距離 = √((x2 - x1)² + (y2 - y1)²)

ピタゴラスの定理を使った計算です。

ピタゴラスの定理とは？

簡単に言うと：「直角三角形の3辺の関係を表す公式」

ゲーム画面で、2つのオブジェクト（プレイヤーと敵）の距離を計算するときに使います。

図解：

  • 横の差 = playerX − enemy.x
  • 縦の差 = playerY − enemy.y
  • 距離 = √(横の差² + 縦の差²)

具体例：

プレイヤーが (300, 345) にいて、敵が (200, 400) にいる場合：

横の差 = 300 - 200 = 100
縦の差 = 345 - 400 = -55

距離 = √(100² + (-55)²)
     = √(10000 + 3025)
     = √13025
     ≈ 36.1

重要： dist() 関数が自動的にこの計算をしてくれるので、私たちは複雑な数学を考える必要はありません。

結果の距離が 37.5 より小さいなら、衝突しています。

プレイヤーと敵の衝突判定

const distance = dist(playerX, playerY, enemy.x, enemy.y);
return distance < playerSize / 2 + enemySize / 2;

条件を読む：

  • distance — プレイヤーの中心から敵の中心までの距離
  • playerSize / 2 + enemySize / 2 — プレイヤーと敵が接触する距離

例： playerSize = 40、enemySize = 35 の場合

playerSize / 2 + enemySize / 2 = 20 + 17.5 = 37.5

プレイヤーの中心から敵の中心までの距離が 37.5より小さい = 衝突している

図解

プレイヤーは三角形で描きますが、当たり判定では中心とサイズを使って円として扱います。

🎮 ゲーム中の敵の処理フロー

sketch.js の対応箇所（関数名で検索）（playGame() 関数）：

// 【役割】プレイ中の移動・描画・判定を進めます。
function playGame() {
  const elapsed = floor((millis() - startTime) / 1000);
  const remaining = clearTime - elapsed;
  if (remaining <= 0) {
    resultText = "CLEAR!";
    gameState = "end";
    return;
  }

  movePlayer();
  // Bの弾移動、Gの音の時刻、Mのコンボ期限などを、各update関数で確かめます。
  runOption("update"); // 選んだ機能を更新します。未選択なら何もしません。
  drawGameInfo(remaining);
  drawPlayer();
  // Bなどのdraw関数を呼び、追加した弾を画面へ描きます。
  runOption("draw");
  for (const enemy of enemies) {
    moveEnemy(enemy);
    drawEnemy(enemy);
    if (isHit(enemy)) {
      resultText = "GAME OVER";
      gameState = "end";
      return;
    }
  }
}

毎フレーム、この順序で敵処理が起こります

  1. 敵を移動 — moveEnemy(enemy) で敵のY座標を更新
  2. 敵を描く — drawEnemy(enemy) で新しい位置に敵を描く
  3. 衝突判定 — isHit(enemy) でプレイヤーとの距離を計算
  4. 敵ごとにループ — 敵が複数個いるので、全ての敵について1〜3を繰り返す

もし衝突が検出されたら：

resultText = 'GAME OVER';
gameState = 'end';
return;

ゲーム終了画面へ移ります。

📊 具体的な流れ（条件を揃えたシミュレーション）

追加機能なし、キーを押さず、自機は(300, 345)のまま、playerSize = 40、enemySize = 35とします。敵1体の初期位置を(300, -100)、速さを5に固定して考えます。これは計算を追うための例で、実際の登場位置と速さは抽選されます。

進んだフレーム 敵のy 自機との距離 判定
0 -100 445 当たらない
1 -95 440 当たらない
80 300 45 当たらない
81 305 40 当たらない
82 310 35 当たる

横の位置が同じなので、距離は縦の差だけです。衝突のしきい値は40 / 2 + 35 / 2 = 37.5。82フレーム目に35 < 37.5となり、ゲームが終了します。その先のフレームを計算し続ける例ではありません。

横にも差がある場合はdistで距離を調べます。例えば自機(300, 345)、敵(200, 400)なら、距離は約114.13です。37.5より大きいので、この座標では衝突しません。

当たり判定は中心とサイズから円で近似するため、三角形の輪郭と完全に一致する判定ではありません。

📝 重要な用語のまとめ

用語 意味 このゲームでの例
配列 複数の値をまとめて保存する仕組み enemies = []
要素 配列の中の1つの値 enemies[0] — 最初の敵
ループ 複数の値に同じ処理を繰り返す for (const enemy of enemies)
random(a, b) a〜bの間のランダムな値 敵の位置や速度
距離計算 2点間の距離を計算する dist() 関数
当たり判定 2つのオブジェクトが衝突しているか判定する プレイヤーと敵の距離
スコア ゲーム中の得点 敵が画面を通り過ぎるたびに+1
