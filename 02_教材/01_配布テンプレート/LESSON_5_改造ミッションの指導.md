# レッスン5：改造ミッションの指導

> **コードを全部覚える必要はありません。**
>
> 仕事でプログラムを書く人も、分からないことは調べながら書いています。このレッスンも、気になるところから読んで、試したいところを一つ試してみましょう。

## この資料の使い方

設定値や難易度の変更例を、授業後の改造やコーチの補足に使えます。

当日の進行と投影手順は[当日用資料の使い方](../../00_当日用資料/README.html)を参照してください。

「現在のコード」と示す例はシンプル版sketch.jsの対応する関数です。「抜粋」「考え方の例」は説明用で、そのままsketch.jsへ追加するコードではありません。改造では既存の値を変更し、応用機能は[当日用の課題ページ](../../00_当日用資料/01_生徒/応用課題/00_課題の選び方.html)からコピーします。

変更例で複数の値を並べている場合は候補の比較です。使う値を1つ選び、既存の設定行を書き換えます。新しい設定行を末尾へ追加しません。

## 🎯 学習目標

ワークショップで参加者が行う改造ミッションを、難易度ごとに分析する。

- 各ミッションの内容と実装方法
- 難易度別のサポート方法
- よくあるエラーと対応
- コーチが生徒を導くためのヒント
- 時間内に完成させるための工夫

## 🎨 レベル1：基本の色・テーマ変更

### ミッション1-1：プレイヤーの色を変える

**難易度：** ⭐ 最も簡単

**変更ファイル：** `sketch.js` の対応箇所（関数名で検索）

```javascript
// 元
let playerColor = "cyan";

// 変更例
playerColor = "lime";
playerColor = "pink";
```

**実装時間：** 1分

**生徒がつまずく可能性：**
- 色名のスペルが違う（`"gren"`ではなく`"green"`など）
- 保存忘れ、またはブラウザの更新忘れ

**コーチが出すヒント：**
1. 「p5.jsの色名で、好きな色を探してみて」
2. 「'lime', 'yellow', 'pink' などの色名が使えます」
3. 「保存してから、Chromeの避けゲームの画面を更新してね」

**コーチが教える前に確認すること：**
- 生徒が、CUSTOM AREA のどこを変更するのか理解しているか
- 正しい色名を入力しているか
- 保存と更新のステップを忘れていないか

**代替案（完成できなかった場合）：**
色名リストを提示して、その中から選ばせる：

```javascript
// 用意した色名
"cyan"     // シアン（水色）
"lime"     // ライム（黄緑）
"yellow"   // 黄
"orange"   // オレンジ
"pink"     // ピンク
"purple"   // 紫
```

## ⚙️ レベル2：数値調整

### ミッション2-1：プレイヤーの速さを変える

**難易度：** ⭐⭐ 簡単

**変更ファイル：** `sketch.js` の対応箇所（関数名で検索）

```javascript
// 元
let playerSpeed = 7;

// 変更例
playerSpeed = 10;  // 速くなる
playerSpeed = 3;   // 遅くなる
```

**実装時間：** 2分

**生徒がつまずく可能性：**
- 数値を文字列 `"10"` で入力してしまう
- どの程度変更すればいいか分からない

**コーチが出すヒント：**
1. 「元の値は 7 です。10 か 5 に変えてみて」
2. 「実際にゲームをプレイして、動きを確認してみて」
3. 「速すぎたら、また調整すればいいんですよ」

**実装のコツ：**
生徒に「試行錯誤」を促す。

- 最初は 10 に変更
- ゲームをプレイ
- 「速すぎたから 8 に変更」
- またプレイ
- 「ちょうどいい」

このプロセスが大事です。

**代替案（完成できなかった場合）：**
選択肢を提示：

```javascript
// 遅い
let playerSpeed = 3;

// ふつう
playerSpeed = 7;

// 速い
playerSpeed = 12;
```

**難易度：** ⭐⭐ 簡単

**変更ファイル：** `sketch.js` の対応箇所（関数名で検索）

```javascript
// 元

```

**実装時間：** 2分

**生徒がつまずく可能性：** ミッション2-1と同じ

**コーチが出すヒント：**
1. 「大きくなると、当たりやすくなります」
2. 「小さくなると、避けやすくなります」
3. 「自分にちょうどいい大きさを見つけてみて」

**実装のコツ：**
難易度と直結している。

- `playerSize` を大きくすると、敵に当たりやすくなる
- `playerSize` を小さくする = 避けにくい = 難しい

### ミッション2-4：遊びやすい難易度に調整する

**難易度：** ⭐⭐⭐ やや難しい（複数要素の組み合わせ）

**変更ファイル：** `sketch.js` の対応箇所（関数名で検索）の複数

```javascript
// 元（デフォルト）
let playerSize = 40;
let enemySize = 35;
let playerSpeed = 7;

// 例1：難しくしたい
playerSize = 60;   // プレイヤーを大きく（当たりやすく、難しい）
enemySize = 50;    // 敵を大きく
playerSpeed = 5;   // プレイヤーを遅く

// 例2：簡単にしたい
playerSize = 20;   // プレイヤーを小さく（当たりにくく、簡単）
enemySize = 20;    // 敵を小さく
playerSpeed = 10;  // プレイヤーを速く
```

**実装時間：** 5分

**生徒がつまずく可能性：**
- 複数の値を同時に変更するので、どれを変更すればいいか分からない
- 「遊びやすい」の定義が曖昧

**コーチが出すヒント：**
1. 「ゲームが難しすぎたら、プレイヤーを小さくしてみて」
2. 「敵も小さくしたり、プレイヤーを速くしたりして、自分にちょうどいい難易度を見つけてみて」
3. 「複数の値を組み合わせて、自分にちょうどいい難易度を作ってみて」

**実装のコツ：**
生徒が複数の値を試行錯誤できるようにサポート。

**代替案（完成できなかった場合）：**
テンプレートを提示：

```javascript
// ★簡単モード
let playerSize = 60;
let enemySize = 20;
let playerSpeed = 10;

// ★ふつう（デフォルト）
playerSize = 40;
enemySize = 35;
playerSpeed = 7;

// ★難しいモード
playerSize = 20;
enemySize = 50;
playerSpeed = 5;
```

## 🔧 レベル3：難易度ロジックの変更

### ミッション3-1：難易度ごとの敵の速さを変える

**難易度：** ⭐⭐⭐ やや難しい（複数箇所の編集）

**変更ファイル：** `sketch.js` の対応箇所（関数名で検索）（`startGame()` 関数内）

```javascript
// 【役割】選んだ難易度でゲームを初期化して開始します。
function startGame(level) {
  if (level === 1) {
    difficultyName = "かんたん";
    enemySpeed = 4;    // ← ここを変更
    enemyCount = 1;
    clearTime = 30;
  } else if (level === 2) {
    difficultyName = "ふつう";
    enemySpeed = 6;    // ← ここを変更
    enemyCount = 2;
    clearTime = 45;
  } else {
    difficultyName = "むずかしい";
    enemySpeed = 8;    // ← ここを変更
    enemyCount = 3;
    clearTime = 60;
  }
  // ...
}
```

**変更例：**

```javascript
// 敵が速くなるように調整
if (level === 1) {
  enemySpeed = 5;   // 元の 4 から 5 に
} else if (level === 2) {
  enemySpeed = 7;   // 元の 6 から 7 に
} else {
  enemySpeed = 9;   // 元の 8 から 9 に
}
```

**実装時間：** 5分

**生徒がつまずく可能性：**
- `if` 文の構造が複雑に見える
- どこを変更すればいいか分からない
- 3つの場所すべてを変更する必要があることに気づかない

**コーチが出すヒント：**
1. 「難易度『かんたん』の敵の速さは、`startGame()` 内の `enemySpeed = 4` で決まります」
2. 「3つの難易度すべてを同じルールで変更してね」
3. 「『ふつう』は『かんたん』より速く、『むずかしい』が一番速いようにしましょう」

**実装のコツ：**
コーチが、変更すべき3行をハイライトして示す。

生徒に直接変更させず、まずコードを読ませてから変更させる。

**代替案（完成できなかった場合）：**
虫食いコード形式で提供：

```javascript
// 【役割】選んだ難易度でゲームを初期化して開始します。
function startGame(level) {
  if (level === 1) {
    enemySpeed = ____;   // ここに好きな数字を入れてね
  } else if (level === 2) {
    enemySpeed = ____;   // ふつうは、かんたんより大きい数字
  } else {
    enemySpeed = ____;   // むずかしいが一番大きい数字
  }
}
```

### ミッション3-4：自分だけのテーマを考える

**実装のコツ：**

**テーマの例：**
- 「宇宙戦闘」— 派手な色、速い敵、シアンと赤
- 「深海」— 暗い青と緑、ゆっくりとした敵
- 「ジャングル」— 緑と茶色、大きな敵
- 「雪の世界」— 白と水色、遅い敵

**代替案（完成できなかった場合）：**


## 🛠️ コーチが用意すべきもの

### 資料
- 最新の生徒用テキストと、当日用の応用課題ページ
- コーチ用の虫食い課題の解答と確認
- よくあるエラーと対応方法のリスト

### サポート方法
1. **進捗確認** — 5分ごとに生徒の画面を確認
2. **つまずき対応** — 早期に手を挙げさせる
3. **試行錯誤を促す** — 答えをすぐに教えない
4. **成功体験** — 完成したら褒める

### よくあるエラーと対応

| エラー | 原因 | 対応 |
|--------|------|------|
| 色が変わらない | 保存忘れ・更新忘れ | 「VS Codeで保存してから、Chromeの避けゲームの画面を更新してね」 |
| スペルエラー | 色名の入力ミス | 色名リストを提示 |
| `if` 文の構造が分からない | 複雑に見える | 「3つの難易度ごとに、値が異なるんです」 |
| 複数の値をどう組み合わせればいいか分からない | 試行錯誤の方法が分からない | 「1つずつ試してみましょう」 |
