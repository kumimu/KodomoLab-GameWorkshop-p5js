# 自分だけの避けゲーを作ろう！

## 起動

1. `index.html` をダブルクリック
2. `1`・`2`・`3` のどれかを押して難易度を選択
3. `←`・`→` キーで隕石を避ける

## 改造

`sketch.js` の上部にある `CUSTOM AREA` を変更します。

変更したら次の操作をします。

1. VS Codeの「ファイル→保存」を選ぶ
2. Chromeの更新ボタンをクリックする

## 注意

`p5.min.js` は削除・改名しないでください。

## 応用課題を追加する

sketch.js末尾の「応用コード貼り付け欄」へ、A/B/G/H/Mの機能コードを貼ります。各機能はID別に登録され、先に貼ったコードを残して次の課題を同じ欄の下へ追加できます。色・大きさ・速さ・タイトルはCUSTOM AREAの値をそのまま使います。

まず1つを動かし、余裕があれば次を追加します。5つを全て同時に使えます。同じ課題を修正する場合はそのブロックを置き換えます。同じIDが重複した場合は最後の登録を使います。

当日用課題は00_当日用資料/01_生徒/応用課題にあります。この教材フォルダだけをZIPで配る場合は、当日用の生徒資料も別途配ってください。
