# 自分だけの避けゲーを作ろう！

## 起動

1. 授業では「ワーク用」フォルダの`index.html`をChromeで開く
2. `1`・`2`・`3` のどれかを押して難易度を選択
3. `←`・`→` キーで隕石を避ける
4. 終了後はSpaceキーで開始画面へ戻る

## 改造

`sketch.js` の上部にある `CUSTOM AREA` を変更します。

変更したら次の操作をします。

1. VS Codeの「ファイル→保存」を選ぶ
2. Chromeの更新ボタンをクリックする

## 注意

`p5.min.js` は削除・改名しないでください。

## 応用課題を追加する

[当日用の課題一覧](../../00_当日用資料/01_生徒/応用課題/00_課題の選び方.html)からA/B/G/H/Mを選び、ワーク用のsketch.js末尾の「応用コード貼り付け欄」へ、その機能のコードだけを貼ります。

課題ページのヒントを読み、`__A1__`などの虫食いの印全体を置き換えます。**その課題の印が全てなくなったことを確認してから、保存・ブラウザ更新・実行を行います。** 空欄によっては、開始直後ではなく、その処理が呼ばれた途中でエラーになることがあります。各機能はID別に登録され、先に貼ったコードを残して次の課題を同じ欄の下へ追加できます。色・大きさ・速さ・タイトルはCUSTOM AREAの値をそのまま使います。

まず1つを動かし、余裕があれば次を追加します。5つを全て同時に使えます。同じ課題を修正する場合はそのブロックを置き換えます。同じIDが重複した場合は最後の登録を使います。

授業全体の手順は[生徒用テキスト](../../00_当日用資料/01_生徒/02_ワークショップテキスト.html)を参照してください。この教材フォルダだけをZIPで配る場合は、当日用の生徒資料も別途配ってください。

円の練習はJS_15分入門/index.htmlを開き、同じフォルダのpractice.jsを編集します。ゲーム本体のsketch.jsとは別です。LESSON_1～5はコードを詳しく読む参考教材で、授業では生徒用テキストの手順を優先します。
