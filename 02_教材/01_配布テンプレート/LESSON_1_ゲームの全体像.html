📂 ファイルの構成

実行の中心は次の3ファイルです。配布時はlicensesフォルダや基礎練習も含め、教材フォルダごと渡します。

ファイル名 役割
index.html ブラウザが最初に読み込むファイル。ゲーム画面の枠を作る
sketch.js ゲームの動きを書いたJavaScriptコード
p5.min.js p5.jsというライブラリ。図形を描いたり、キー入力を受け取ったりする機能を提供

🔗 HTMLとJavaScriptの関係

index.html の重要な部分

<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <title>自分だけの避けゲー</title>
  <script src="p5.min.js"></script>  <!-- ① p5.jsを読み込む -->
</head>
<body>
  <h1>自分だけの避けゲーを作ろう！</h1>
  <p>1・2・3で難易度選択／← → で移動</p>
  <script src="sketch.js"></script>  <!-- ② ゲームコードを読み込む -->
</body>
</html>

ファイル読み込みの順番が大事

ブラウザは、HTMLファイルを上から順に読みます。

  1. 最初に： <script src="p5.min.js"></script> で p5.jsライブラリ を読み込む
  2. その後： <script src="sketch.js"></script> で 避けゲームのコード を読み込む

なぜ順番が大事？

p5.jsの中には、図形を描く関数（circle()、triangle()など）がたくさん定義されています。

sketch.js でこれらの関数を使いたいときに、p5.jsが先に読み込まれていないと、「そんな関数は知らない」とエラーになります。

順番を間違えると：

エラー：circle is not defined（circleという関数は定義されていません）

📊 p5.jsとは何か

p5.js は、JavaScriptで図形を描いたり、キーボード入力を受け取ったりするのを簡単にしてくれるライブラリです。

このゲームで使われているp5.jsの機能：

機能 役割 使用例
描画 図形や文字を画面に描く circle(x, y, size) — 円を描く
triangle(x1, y1, x2, y2, x3, y3) — 三角形を描く
text(文字列, x, y) — 文字を表示
キャンバス ゲーム画面を作る createCanvas(600, 400) — 600×400ピクセルの画面を作る
キー入力 キーボード入力を受け取る keyIsDown(LEFT_ARROW) — 左矢印キーが押されているか確認
keyPressed() — キーが押されたときの処理
時間 フレームごとに自動実行 draw() — 1秒間に約60回自動で呼ばれる関数
計算・補助 計算や制限 dist(x1, y1, x2, y2) — 2点間の距離を計算
constrain(値, 最小, 最大) — 値を範囲内に制限

p5.jsがなければ、ブラウザの低レベルなCanvasコマンドを使う必要があり、はるかに複雑になります。

🎮 ゲームの3つの状態

このゲームは、3つの画面状態を行き来します。

sketch.js の対応箇所（関数名で検索）：

let gameState = "start"; // start / play / end

gameState という変数が、今、ゲームがどの状態にあるのか を管理しています。

状態1：gameState = "start" — 開始画面・難易度選択

ユーザーが 1、2、3 のキーのいずれかを押すと、ゲーム開始。

状態2：gameState = "play" — ゲーム中

プレイヤーが敵に触れるまで、またはカウントダウンが0になるまで、この画面が表示されます。

敵が上から下に移動して、プレイヤーが左右に動いて避けます。

状態3：gameState = "end" — 終了画面

ゲームが終わった結果を表示します。

スペースキーを押すと、開始画面に戻ります。

🔄 ゲームループとは

ゲームループが何か

ゲームループ は、ゲーム全体の心臓です。

毎フレーム（通常1秒間に60回）、同じ処理が自動で繰り返されます。

sketch.js の対応箇所（関数名で検索）：

// 【役割】画面を描き直し、現在の状態に応じた処理を呼びます。
function draw() {
  background(backgroundColor);

  if (gameState === "start") {
    showStartScreen();
  } else if (gameState === "play") {
    playGame();
  } else if (gameState === "end") {
    showEndScreen();
  }
}

この draw() 関数が、1秒間に約60回呼ばれます

毎フレーム、以下のことが起こります：

  1. 背景を描き直す — background(backgroundColor) で前のフレームの画像を完全に消す
  2. ゲーム状態をチェック — if 文で現在の gameState がどの値か判定
  3. 対応する画面を描く — 状態に応じて、関数を呼び出す

例えば gameState = "play" なら、playGame() 関数が呼ばれます。

なぜ60回も繰り返すの？

人間の目は、1秒間に30フレーム以上の画像が高速に切り替わると、滑らかなアニメーション に見えます。

映画は24フレーム/秒、ゲームは通常60フレーム/秒です。

60回繰り返すことで、敵がスムーズに落ちてくるように見え、プレイヤーもなめらかに動くのです。

もし1秒間に5回だけなら、ぎこちないアニメーションになります。

🎬 ゲーム中（play）の詳しい流れ

playGame() 関数の全体像（現在のコード）

sketch.js の対応箇所（関数名で検索）：

// 【役割】プレイ中の移動・描画・判定を進めます。
function playGame() {
  const elapsed = floor((millis() - startTime) / 1000);
  const remaining = clearTime - elapsed;
  if (remaining <= 0) {
    resultText = "CLEAR!";
    gameState = "end";
    return;
  }

  movePlayer();
  // Bの弾移動、Gの音の時刻、Mのコンボ期限などを、各update関数で確かめます。
  runOption("update"); // 選んだ機能を更新します。未選択なら何もしません。
  drawGameInfo(remaining);
  drawPlayer();
  // Bなどのdraw関数を呼び、追加した弾を画面へ描きます。
  runOption("draw");
  for (const enemy of enemies) {
    moveEnemy(enemy);
    drawEnemy(enemy);
    if (isHit(enemy)) {
      resultText = "GAME OVER";
      gameState = "end";
      return;
    }
  }
}

毎フレーム、この順序で処理が進む

  1. 時間計測とクリア判定 — 残り時間が0なら終了する。
  2. 自機の移動 — キー入力で位置を変える。
  3. 追加機能の更新 — runOption("update")が、登録済みの機能を更新する。未登録なら何もしない。
  4. 情報・自機・追加の描画 — スコアなど、自機、追加機能の順に描く。
  5. 敵の処理 — 敵1体ずつ移動・描画・衝突判定を行い、当たれば終了する。

約60フレーム/秒で進むのが目安です。実際の回数はPCやブラウザの負荷で変わります。まずは「位置を変えて、描いて、当たったか調べる」の流れを追い、追加機能の内部は選んだ課題で確認します。

🎯 なぜこんなに複雑？

一見、複雑に見えるかもしれません。

でも、考え方は単純です：

「毎フレーム、前の画像を消して、新しい画像を描き直す」

これだけです。

敵が画面に表示される位置が毎フレーム少しずつ下がっていくので、敵が落ちてくるように見えるのです。

プレイヤーの位置が毎フレーム左または右に少しずつ動くので、プレイヤーが移動するように見えるのです。

📝 重要な用語のまとめ

用語 意味 このゲームでの例
フレーム ゲーム画面の1コマ 1フレーム = 1/60秒
ゲームループ draw() 関数が繰り返し呼ばれる仕組み 毎フレーム、敵を下に移動し、プレイヤーを描く
キャンバス ゲームが描かれる仮想の画面 600ピクセル × 400ピクセル
座標 画面上の位置。左上が (0, 0) プレイヤーが画面の中央なら (300, 345)
変数 ゲーム中の状態や数値を保存する箱 gameState = "play" など
関数 決まった処理をまとめたもの movePlayer() — プレイヤーを移動させる処理
イベント ユーザーの操作（キー入力など）に反応すること キーが押されたら keyPressed() が実行される

✅ 理解度確認クイズ

クイズ1：ファイルの読み込み順序

HTMLで、なぜ p5.min.js を先に読んで、その後に sketch.js を読むのでしょう？

ヒント： sketch.js の中では、p5.jsの関数（circle() など）を使っています。

答え：

p5.jsのコードが先にメモリに用意されていないと、sketch.jsでそれらの関数を使えないからです。

もし順番を逆にしたら、ブラウザは「circle って何ですか？知りません」とエラーを出します。

クイズ2：ゲームループの頻度

draw() 関数は、1秒間に何回呼ばれていますか？

答え： 約60回です。

フレームレートが60 FPS（frames per second）だからです。

1秒間に60フレーム = 1秒間に60回。

クイズ3：ゲーム状態の遷移

プレイヤーが難易度1を選んでから、敵に当たるまで、gameState の値はどのように変わりますか？

答え： start → play → end

  1. 最初：gameState = "start"（開始画面）
  2. キー 1 を押す：gameState = "play"（ゲーム開始）
  3. 敵に当たる：gameState = "end"（終了画面）
