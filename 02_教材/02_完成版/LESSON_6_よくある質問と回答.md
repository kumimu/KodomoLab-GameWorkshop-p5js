## ゲーム側の質問

### Q1：複数のオプションを同時にやることはできますか？

**A：** はい、できます。ただし、実装に時間がかかります。

LESSON_6_オプション一覧.md で、「複数のオプションを組み合わせた場合の対応」を参照してください。

**例：**
- 「敵の多様化（A）」だけなら 30-45分
- 「敵の多様化（A）」+ 「スコアシステム（M）」なら 65-95分

時間に余裕があれば、複数のオプションに挑戦してみてください！

---

### Q2：敵の多様化（A）と射撃機能（B）の両方やりたいことはできますか？

**A：** はい、できます。実装順序が重要です。

**推奨される実装順序：**
1. 敵の多様化（A）を先に完成させる
2. その後、射撃機能（B）を追加する

なぜなら、敵の HP（生存判定）を「敵の多様化」で設定するため、「射撃機能」の当たり判定に使われるからです。

---

### Q3：ゲームが重くなった（フレームレートが低下した）

**A：** 敵や弾が増えすぎているかもしれません。

**確認項目：**
1. 敵の数を確認：`console.log('敵の数:', enemies.length);`
2. 弾の数を確認：`console.log('弾の数:', bullets.length);`

**対応方法：**
- 敵の生成間隔を長くする（`spawnTimer` を大きくする）
- 弾の上限を決める（敵撃破時に古い弾を削除）

---

### Q4：敵が画面の一部に集中している

**A：** 敵の生成位置がランダムになっていないかもしれません。

```javascript
// 敵を生成するときに、X座標がランダムか確認
x: Math.random() * (W - r * 2) + r
```

この計算で、敵が画面全体に散らばります。

## 実装側の質問

### Q5：「敵の多様化」で、敵が全て同じタイプになっている

**A：** 敵の type を決定する確率計算が間違っているかもしれません。

```javascript
// 確認：この code が実行されていますか？
const type = Math.random() < 0.17 ? 'zig' : Math.random() < 0.12 ? 'tank' : 'normal';
```

**デバッグ方法：**
```javascript
console.log('敵のタイプ:', type);
// コンソールに敵のタイプが表示されるか確認
```

---

### Q6：「射撃機能」で、敵に当たらない

**A：** 当たり判定の計算が間違っているかもしれません。

**確認項目：**
1. `circle()` 関数が定義されているか
2. 敵に `hp` プロパティがあるか
3. 当たり判定の距離計算が正しいか

```javascript
// circle() 関数の確認
function circle(a, b) {
  return Math.hypot(a.x - b.x, a.y - b.y) < a.r + b.r;
}
```

**デバッグ方法：**
```javascript
console.log('敵の座標:', e.x, e.y);
console.log('弾の座標:', b.x, b.y);
console.log('距離:', Math.hypot(b.x - e.x, b.y - e.y));
console.log('当たり判定距離:', b.r + e.r);
```

### Q7：「BGMのカスタマイズ」で、音が出ない

**A：** いくつかの原因が考えられます。

**確認項目：**
1. ブラウザの音量が ON になっているか
2. `sound()` 関数が呼ばれているか
3. Web Audio API が初期化されているか

**デバッグ方法：**
```javascript
console.log('BGM タイマー:', bgmTimer);
console.log('BGM インデックス:', bgmIndex);

// sound() 関数が呼ばれているか確認

```

---

### Q8：「ビジュアルカスタマイズ」で、色が反映されない

**A：** Canvas の色設定が間違っているかもしれません。

**確認項目：**
1. `ctx.fillStyle` に 16進数カラーコード（`'#rrggbb'`）を設定しているか
2. `ctx.fill()` が呼ばれているか

```javascript
// 正しい例
ctx.fillStyle = '#ff6464';  // 赤
ctx.fill();

// 間違った例
fill([255, 100, 100]);  // p5.js の書き方（NG）
```

---

### Q9：「スコアシステム」で、スコアが加算されない

**A：** 敵を撃破したときに `destroyEnemy()` が呼ばれていないかもしれません。

**確認項目：**
1. 敵に `value` プロパティがあるか
2. 敵撃破時に `destroyEnemy()` が呼ばれているか
3. スコア計算が実行されているか

```javascript
function destroyEnemy(e) {
  console.log('敵撃破：value =', e.value);
  score += e.value;
  console.log('現在のスコア:', score);
}
```

## 概念的な質問

### Q10：「type」とは何ですか？

**A：** 敵オブジェクトが持つ「種類」を示す情報です。

```javascript
// 敵1：type = 'fast'（速い敵）
const enemy1 = { type: 'fast', ... };

// 敵2：type = 'slow'（遅い敵）
const enemy2 = { type: 'slow', ... };
```

敵の `type` によって、敵の動き・見た目・得点を変えることができます。

---

### Q11：周波数シーケンス配列とは何ですか？

**A：** 複数の周波数（音の高さ）を配列で並べたもの。この配列を順番に再生すると、メロディになります。

```javascript
// ドレミファソラシド
const melody = [262, 330, 392, 349, 392, 440, 493, 523];

// この配列を順番に再生すると、「ドレミファソラシド」になる
```

**周波数の目安：**
- 低い音：100-200Hz
- 中程度：300-500Hz
- 高い音：800-1000Hz以上

---

### Q12：コンボが途中で途切れる

**A：** `comboTimer` の設定時間内に敵を倒していないかもしれません。

```javascript
// comboTimer の設定
comboTimer = 3;  // 3秒以内に次の敵を倒さないと途切れる
```

**対応方法：**
- 敵を倒す速度を上げる
- `comboTimer` の時間を長くする（`comboTimer = 5` など）

## 技術的な質問

### Q14：`push()` と `pop()` が何をしているかわからない

**A：** Canvas API では `ctx.save()` と `ctx.restore()` を使います。

```javascript
// 描画状態を保存
ctx.save();

// 色を変える、回転させるなど
ctx.fillStyle = '#ff6464';
ctx.rotate(Math.PI / 4);

// 描画
ctx.fill();

// 描画状態を復元（元に戻す）
ctx.restore();

// この時点で fillStyle と回転は元に戻っている
```

この `save()` / `restore()` で、描画状態を一時的に変更できます。

---

### Q15：`rotate()` で回転がおかしい

**A：** `rotate()` の前に `translate()` で中心を移動する必要があります。

```javascript
// 正しい例
ctx.save();
ctx.translate(e.x, e.y);  // 敵の中心に移動
ctx.rotate(Math.PI / 4);  // 45度回転
ctx.arc(0, 0, e.r, 0, Math.PI * 2);  // 中心(0,0)に敵を描画
ctx.fill();
ctx.restore();
```

**理由：** Canvas の回転は、常に原点 (0,0) を中心に回転するため、先に `translate()` で敵の位置に原点を移動する必要があります。

---

### Q16：`filter()` が何をしているかわからない

**A：** 配列から特定の条件を満たす要素だけを残すメソッドです。

```javascript
// 画面外に出た弾を削除
bullets = bullets.filter(b => b.y > -20);

// これは以下と同じ意味
// 「b.y > -20 を満たす弾だけを残す」
```

**例：**
```javascript
const numbers = [1, 5, 3, 8, 2, 9];

// 5 より大きい数だけ残す
const filtered = numbers.filter(n => n > 5);
// 結果：[8, 9]
```

---

### Q17：`Math.hypot()` が何をしているかわからない

**A：** 2点間の距離を計算します。当たり判定で使われます。

```javascript
// 弾 (bx, by) と 敵 (ex, ey) の距離
const distance = Math.hypot(bx - ex, by - ey);

// 距離が半径の和より小さい = 衝突している
if (distance < bRadius + eRadius) {
  // 当たり判定！
}
```

**計算式：** 距離 = √((x2-x1)² + (y2-y1)²)

---

### Q18：モジロ演算子（`%`）が何をしているかわかりません

**A：** 割り算の余りを計算します。配列をループさせるときに使われます。

```javascript
// BGM のインデックスが配列の長さを超えたら、最初に戻す
const freq = melody[bgmIndex % melody.length];

// 例：melody の長さが 8 の場合
bgmIndex = 0：0 % 8 = 0 → melody[0]
bgmIndex = 7：7 % 8 = 7 → melody[7]
bgmIndex = 8：8 % 8 = 0 → melody[0]（最初に戻った）
bgmIndex = 9：9 % 8 = 1 → melody[1]
```

---

### Q19：`Math.floor()` が何をしているかわかりません

**A：** 小数点以下を切り捨てて、整数にします。

```javascript
// コンボ倍率の計算
const multiplier = 1 + Math.floor(combo / 5);

// 例：
combo = 4：1 + floor(4 / 5) = 1 + floor(0.8) = 1 + 0 = 1倍
combo = 5：1 + floor(5 / 5) = 1 + floor(1) = 1 + 1 = 2倍
combo = 9：1 + floor(9 / 5) = 1 + floor(1.8) = 1 + 1 = 2倍
combo = 10：1 + floor(10 / 5) = 1 + floor(2) = 1 + 2 = 3倍
```

### Q27：パフォーマンスを改善したい

**A：** ゲームが重いときの対策です。

**確認項目：**
1. 敵や弾の数が多すぎないか
2. 描画処理が効率的か
3. イベントリスナーが重複登録されていないか

**改善方法：**
```javascript
// 敵の生成頻度を下げる
spawnTimer = 1.0;  // 1秒ごと（デフォルトより遅い）

// 不要なオブジェクトを削除
bullets = bullets.filter(b => b.y > -20 && b.x > 0 && b.x < W);
```
