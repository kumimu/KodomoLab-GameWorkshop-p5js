# 完成版：NEON DODGE（p5.js版）

## 概要
基礎版「避けゲー」から段階的に成長させた応用ゲーム。
p5.js のみを使用し、以下の要素を実装しています。

## 搭載機能

### 1. 敵の多様性
- **通常敵**：上から落ちてくる
- **ジグザグ敵**：左右に揺れながら落下
- **タンク敵**：耐久力が高い（3回被弾で破壊）

### 2. シューティング機能
- スペースキーで射撃
- 連続射撃で複数の弾を発射

### 3. パワーアップアイテム
- **♥ ハート**：ライフ +1
- **★ スター**：7秒間無敵
- **◆ シールド**：次の1回の被弾を無効化
- **⚡ ラピッドファイア**：12秒間連続射撃

### 4. スコアシステム
- 敵撃破で得点
- コンボで倍率上昇
- スター中は全得点が 2倍

### 5. ステージシステム
4つのステージがあり、各ステージで難易度が上昇
- **NEON CITY**：初心者向け（45秒）
- **LAVA CORE**：中級（55秒）
- **VOID GALAXY**：上級（65秒）
- **SECRET MATRIX**：秘密ステージ（75秒）

### 6. 難易度選択
- **EASY**：敵速度 0.75 倍
- **NORMAL**：通常速度
- **HARD**：敵速度 1.45 倍

### 7. ボスバトル
ステージの目標時間に達するとボス出現
- 複数の方向から射撃
- 難易度によって射撃速度変更
- 撃破でステージクリア

### 8. 隠しコマンド
コナミコマンド（↑ ↑ ↓ ↓ ← → ← → B A）を入力すると SECRET STAGE が解禁

## ゲームの流れ

1. **タイトル画面**：ENTER で進む
2. **難易度選択画面**
   - ← → で ステージ選択
   - 1/2/3 キーで難易度を選択して開始
3. **ゲーム中**
   - ← → で移動
   - SPACE で射撃
   - 敵を避けて、できれば撃破
   - 目標時間に達するとボス出現
   - ボスを撃破するとクリア
4. **リザルト画面**
   - ENTER で同じステージをもう一度
   - S キーで ステージ選択に戻る
   - ESC でタイトルに戻る

## 操作方法

| キー | 操作 |
|------|------|
| ← → | 移動 |
| SPACE / Z | 射撃 |
| 1 / 2 / 3 | 難易度選択（SELECT画面） |
| ← → | ステージ選択（SELECT画面） |
| ENTER | ゲーム開始 / リザルトに進む |
| S | ステージ選択に戻る |
| ESC | タイトルに戻る |
| M | BGM ON / OFF |

## 隠しコマンド

コナミコマンド（↑ ↑ ↓ ↓ ← → ← → B A）を入力すると SECRET STAGE が解禁される

## ファイル構成

- `index.html`：ゲームを実行するための HTML ファイル
- `sketch.js`：ゲームの全ロジック（p5.js）
- `p5.min.js`：p5.js ライブラリ

## このゲームから学べること

- **敵の種類分け**：if 文で異なる挙動を実装
- **配列の応用**：敵・弾・パワーアップを配列で管理
- **当たり判定**：dist 関数で複数オブジェクト間の判定
- **時間管理**：deltaTime で時間ベースの制御
- **ゲームシステム**：ステージ・難易度・スコア管理
- **パーティクル効果**：エフェクトで視覚的フィードバック
