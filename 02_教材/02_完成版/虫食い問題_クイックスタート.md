# 虫食い問題 — クイックスタートガイド

LESSON_5 完了後、LESSON_6 を「虫食い問題」で実装するガイド

---

## 🎯 虫食い問題とは

「空いている部分を埋める問題」です。

**メリット：**
- 何を追加すべきか明確に示している
- 「どこに何を追加するか」がわかる
- ヒント付きで段階的に実装できる

---

## 🚀 5 つのオプションから選ぼう

| オプション | 説明 | 難易度 | 時間 | 推奨 |
|-----------|------|--------|------|-----|
| **A** | 敵の多様化 | ★★★ | 30～45分 | 最初に |
| **B** | 射撃機能 | ★★★★ | 45～60分 | 上級者向け |
| **G** | BGM | ★★☆ | 20～30分 | 簡単 |
| **H** | ビジュアル | ★★☆ | 20～30分 | 簡単 |
| **M** | スコアシステム | ★★★ | 30～45分 | 中級 |

---

## 💡 選び方のヒント

### 「とにかく完成させたい」
→ **G（BGM）** または **H（ビジュアル）**  
20～30分で完成できます

### 「ゲームを工夫したい」
→ **A（敵の多様化）**  
敵のメカニクスを工夫できます

### 「難しいプログラミングに挑戦したい」
→ **B（射撃機能）** または **M（スコア）**  
45～60分で本格的な機能を実装

### 「複数のオプションをやりたい」
→ 推奨順序：**A → G → H → M → B**

---

## 📝 虫食い問題の流れ

### ステップ1：ファイルを開く

各オプション用のファイルを開きます：

```
虫食い問題_OPTION_A_敵の多様化.md
虫食い問題_OPTION_B_射撃機能.md
虫食い問題_OPTION_G_BGMカスタマイズ.md
虫食い問題_OPTION_H_ビジュアルカスタマイズ.md
虫食い問題_OPTION_M_スコアシステム.md
```

### ステップ2：段階1 から始める

虫食い問題は段階的に増えます：

```
段階1（簡単）：グローバル変数を追加
  ↓
段階2（中程度）：既存関数に処理を追加
  ↓
段階3（難しい）：新しい関数を作成 or 関数を統合
```

### ステップ3：各段階を完成させる

1. 問題文を読む
2. ヒントを見る
3. 空いている部分を埋める
4. テスト方法で動作確認
5. 次の段階へ

### ステップ4：テスト方法を実行

各段階の最後に「テスト方法」があります。

```
例（OPTION A）：
□ ゲーム開始
□ 敵が 2 種類に分かれているか確認
□ 小さい敵の方が速いか確認
```

すべてにチェック ✓ が付いたら、次の段階へ！

## ✅ 実装中のチェック

各段階でチェック：

### グローバル変数追加後

```javascript
console.log("OPTION_A_ENABLED:", OPTION_A_ENABLED);
// true が表示される？
```

### 関数修正後

```javascript
// ゲームを実行してみる
// エラーが出ていないか確認
```

### 関数統合後

```
1. Ctrl + S で保存
2. F5 でリロード
3. ゲーム開始
4. 機能が動いているか確認
```

## 📊 各オプション別・実装内容

### OPTION A：敵の多様化

```
段階1：敵に type プロパティを追加
段階2：敵の再生成時に type を更新
段階3：敵のタイプに応じて移動・見た目を変更
```

**完成後：** 敵が 2 種類に分かれ、種類によって動きが異なる

---

### OPTION B：射撃機能

```
段階1：bullets 配列を作成、スペースキーで発射
段階2：弾の更新と敵への当たり判定
段階3：playGame() に統合
```

**完成後：** スペースキーで敵を撃ち落とせる

---

### OPTION G：BGM のカスタマイズ

```
段階1：BGM 用の変数を追加
段階2：playGame() に音声再生処理を追加
段階3：startGame() で BGM を初期化
```

**完成後：** ゲーム中にドレミファソラシド のメロディが流れる

---

### OPTION H：ビジュアルカスタマイズ

```
段階1：敵を回転させて描く
段階2：プレイヤーに光の効果を追加
```

**完成後：** 敵が回転し、プレイヤーに光の効果が付く

---

### OPTION M：スコアシステムの工夫

```
段階1：敵に value プロパティを追加
段階2：グローバル変数にコンボ変数を追加
段階3：スコア計算ロジックを修正
段階4：playGame() にコンボ更新処理を追加
段階5：画面にコンボを表示
段階6：ゲーム開始時にコンボを初期化
```

**完成後：** 敵のタイプごとに異なる得点、コンボシステムが機能

---

## 🎓 各段階のコツ

### 段階1：グローバル変数追加

```
✓ 既存の変数定義の下に追加
✓ スペルを正確に（大文字小文字も）
✓ 初期値を正しく設定
```

### 段階2：既存関数の修正

```
✓ 「★ ここを埋めてください」の部分だけ追加
✓ 既存コードは変更しない
✓ if 文の条件式を正確に
```

### 段階3：新規関数・統合

```
✓ 完成コード を参考にして、一行ずつ写す
✓ {}, (), [] の数が合っているか確認
✓ 関数の呼び出し位置を正確に
```

---

## 🚨 よくあるミス

| ミス | 原因 | 対応 |
|------|------|------|
| スペルが違う | typo | コンソール（F12）のエラーメッセージを読む |
| {  }, ( ), [ ] が合わない | 括弧の数が違う | 完成コードと見比べる |
| 関数が呼ばれない | 関数呼び出しが追加されていない | playGame() 等に呼び出しが追加されているか確認 |
| 前のコードが壊れた | 既存コードを消してしまった | 段階1から作り直すか、別のゲームで試す |
