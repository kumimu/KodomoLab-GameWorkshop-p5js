1. 次の2か所には使用版の `p5.min.js` を同梱済みです。別の版で上書きせず、`licenses/` も含めて配布してください

   - `02_教材/02_完成版/`
2. [開催準備チェックリスト](00_当日用資料/04_事前準備/07_開催準備チェックリスト.md)を読む
3. 会場PCで動作確認
