# 中学生向けゲーム制作ワークショップ

p5.jsの避けゲームを使う90分のワークショップです。ゲームを試遊し、JavaScriptの基礎を練習し、ゲームの仕組みを知って色と速さを変更した後、自分の好きな機能を追加します。

## 開催前に

1. [開催準備チェックリスト](00_当日用資料/04_事前準備/07_開催準備チェックリスト.html)でPC・配布物・担当を確認します。
2. 配布テンプレートから、同じ初期内容の「オリジナル」と「ワーク用」を各PCへ用意します。授業中はワーク用を編集・実行します。
3. ワーク用のindex.htmlをブラウザで開き、VS Codeで保存した変更がブラウザ更新で反映されることを確認します。
4. 投影用まとめ・コード解説5画面の表示と切り替え、ノートの印刷、USBへの保存を確認します。

講師はまとめで全体像を示し、コード解説5画面で基本の仕組みを説明します。オプション内部は全体説明から外します。32～35分は好きな色とplayerSpeedの7→12を試し、35分から応用課題へ進みます。実演はVS CodeとChromeを使い、生徒用テキストで実習手順を確認します。

生徒のGitHubアカウント・Git・Node.js・Live Server・Web Editorの登録やログインは必須ではありません。

## 起動と使用版

各ゲームのindex.htmlを開くと、同じフォルダのp5.min.jsとsketch.jsが読み込まれます。基礎練習は配布テンプレート内のJS_15分入門/index.htmlを開きます。

- シンプル版・基礎練習：p5.js 1.11.13
- 発展版ゲーム（完成見本）：p5.js 1.11.13

使用版のライブラリは同梱済みです。別の版で上書きせず、各教材のREADMEを参照してください。

## 配布・持ち帰り

資料と教材のフォルダ構成を保って配布します。ゲームはp5.min.js・licensesを含む教材フォルダごと渡します。配布ZIPが必要な場合は、そのときの資料と教材から作成し、展開後の起動を確認してください。

開始前に「オリジナル」と「発展版ゲーム」を持ち帰り用USBへコピーします。終了時は、編集した「ワーク用」フォルダ全体を追加し、コピー先で起動を確認します。

第三者ライブラリの表示・同梱ソース・配布案内は[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)を参照してください。
