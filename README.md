# gameWS

中学生向け p5.js 避けゲームワークショップの教材・運営資料です。

## 当日用資料（90分）

[資料一覧をブラウザで開く](00_当日用資料/index.html) ／ [資料構成と既存資料の扱い](00_当日用資料/README.md)

生徒用3種類、講師用台本・投影資料、コーチ用ガイド、開催準備チェックリストをまとめました。

## 最初に行うこと

1. 次の2か所には使用版の `p5.min.js` を同梱済みです。別の版で上書きせず、`licenses/` も含めて配布してください
   - `02_教材/01_配布テンプレート/`
   - `02_教材/02_完成版/`
2. `01_運営資料/01_準備.md` を読む
3. 会場PCで動作確認
