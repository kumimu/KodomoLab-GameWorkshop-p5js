# gameWS

中学生向け p5.js 避けゲームワークショップの教材・運営資料です。

## 最初に行うこと

1. 次の2か所には使用版の `p5.min.js` を同梱済みです。別の版で上書きせず、`licenses/` も含めて配布してください
   - `02_教材/01_配布テンプレート/`
   - `02_教材/02_完成版/`
2. `01_運営資料/01_準備.md` を読む
3. 会場PCで動作確認
