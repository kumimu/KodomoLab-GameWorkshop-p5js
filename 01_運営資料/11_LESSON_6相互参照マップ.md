# LESSON_6 相互参照マップ

**目的：** 5つの詳細レッスン（A, B, G, H, M）間の関連性を体系的に整理

---

## 📊 レッスン間の関連図

```
敵の多様化 (A)
  ├─ 敵のプロパティ管理 → スコアシステム (M)
  ├─ 敵の見た目 → ビジュアルカスタマイズ (H)
  └─ 敵の撃破 → 射撃機能 (B)

射撃機能 (B)
  ├─ 敵撃破のタイミング → スコアシステム (M)
  ├─ 敵撃破演出 → ビジュアルカスタマイズ (H)
  └─ 射撃音 → BGMのカスタマイズ (G)

BGMのカスタマイズ (G)
  ├─ ゲームの雰囲気 → ビジュアルカスタマイズ (H) と統一
  └─ 敵撃破のタイミング音 ← 射撃機能 (B)

ビジュアルカスタマイズ (H)
  ├─ 敵の種類の見た目 ← 敵の多様化 (A)
  ├─ ゲーム全体の統一感 ← BGMのカスタマイズ (G)
  └─ 敵撃破時の演出 ← 射撃機能 (B)

スコアシステムの工夫 (M)
  ├─ 敵の type に基づく得点 ← 敵の多様化 (A)
  ├─ 敵撃破時の得点加算 ← 射撃機能 (B)
  └─ 敵撃破演出のタイミング ← ビジュアルカスタマイズ (H)
```

## 🔀 レッスン間の依存関係

### A（敵の多様化）が依存する他のレッスン

| レッスン | 依存度 | 理由 | 詳細 |
|---------|-------|------|------|
| B（射撃機能） | 中 | 敵の HP 設定時に参考 | 敵の種類ごとに異なる HP を設定すると、敵の強さが明確になる |
| M（スコアシステム） | 中 | 敵の value プロパティ | 敵の種類によって得点が異なる設定を学ぶ |
| H（ビジュアルカスタマイズ） | 低 | 敵の見た目（オプション） | 敵の種類を見た目で区別する際に参考 |
| G（BGMカスタマイズ） | 低 | 敵撃破時の音（オプション） | 敵の種類ごとに効果音を変える際に参考 |

### B（射撃機能）が依存する他のレッスン

| レッスン | 依存度 | 理由 | 詳細 |
|---------|-------|------|------|
| A（敵の多様化） | 中 | 敵の HP 管理 | `e.hp > 0` の判定で敵の死活判定を実装 |
| M（スコアシステム） | 中 | 敵撃破時の得点 | 敵を撃破したときのスコア加算ロジック |
| H（ビジュアルカスタマイズ） | 低 | 弾の見た目 | 弾の色や形をカスタマイズする際に参考 |
| G（BGMカスタマイズ） | 低 | 射撃音・敵撃破音 | 射撃時や敵撃破時の効果音を変える際に参考 |

### G（BGMのカスタマイズ）が依存する他のレッスン

| レッスン | 依存度 | 理由 | 詳細 |
|---------|-------|------|------|
| H（ビジュアルカスタマイズ） | 低 | ゲームの雰囲気統一 | 背景色や敵の色とBGMの雰囲気を統一 |
| 他のレッスン | 最小 | 独立性が高い | BGM はほぼ独立した機能として実装可能 |

### H（ビジュアルカスタマイズ）が依存する他のレッスン

| レッスン | 依存度 | 理由 | 詳細 |
|---------|-------|------|------|
| A（敵の多様化） | 中 | 敵の見た目の実装 | 敵の type ごとに異なる形・色を描画 |
| B（射撃機能） | 低 | 弾や敵撃破の演出 | 敵撃破時のパーティクルなど |
| G（BGMカスタマイズ） | 低 | ゲーム全体の雰囲気 | 背景色や敵の色とBGMを統一 |
| 他のレッスン | 最小 | 独立性が高い | 基本的に独立した描画機能 |

### M（スコアシステムの工夫）が依存する他のレッスン

| レッスン | 依存度 | 理由 | 詳細 |
|---------|-------|------|------|
| A（敵の多様化） | 強 | 敵の value プロパティ | 敵の type ごとに value を設定していることが前提 |
| B（射撃機能） | 強 | 敵撃破のトリガー | 敵を撃破した時点でスコアを加算する logic |
| H（ビジュアルカスタマイズ） | 低 | スコア表示の見た目 | スコア表示の色やフォント |
| G（BGMカスタマイズ） | 最小 | 敵撃破時の音 | 敵撃破の確認（オプション） |

## 🎯 推奨される学習順序

### パターン1：敵の工夫から始める（最も自然な流れ）

1. **A（敵の多様化）** ← スタート。敵を複数の種類に分ける
2. **M（スコアシステム）** ← 敵の種類ごとに異なる得点を設定
3. **H（ビジュアルカスタマイズ）** ← 敵の見た目を工夫
4. **B（射撃機能）** ← 敵を撃破する機能を追加
5. **G（BGMカスタマイズ）** ← ゲームの雰囲気を完成させる

**理由：** ゲーム内容（敵）→ スコア計算 → 見た目 → 機能 → 音 という自然な流れ

### パターン2：機能追加から始める（派手な変化を求める場合）

1. **B（射撃機能）** ← スタート。敵に反撃できるようにする
2. **A（敵の多様化）** ← 敵を複数の種類に分ける
3. **M（スコアシステム）** ← 敵の種類ごとに異なる得点を設定
4. **H（ビジュアルカスタマイズ）** ← 敵や弾の見た目を工夫
5. **G（BGMカスタマイズ）** ← ゲームの雰囲気を完成させる

**理由：** すぐにゲーム性の大きな変化が感じられる

### パターン3：見た目・音から始める（ビジュアル重視の場合）

1. **H（ビジュアルカスタマイズ）** ← スタート。色や形を工夫
2. **G（BGMカスタマイズ）** ← ゲームの雰囲気を統一
3. **A（敵の多様化）** ← 敵の見た目で種類を区別
4. **B（射撃機能）** ← 敵を撃破する機能を追加
5. **M（スコアシステム）** ← スコア計算を複雑化

**理由：** ビジュアルと音のインパクトで、ゲーム全体の雰囲気を先に完成させる

## 💡 重要な共有概念

### 敵オブジェクトの構造

すべてのレッスンが共通して使用する敵オブジェクト：

```javascript
{
  x: number,          // X座標（H, A で使用）
  y: number,          // Y座標（すべてで使用）
  r: number,          // 半径（H, A で使用）
  v: number,          // 速度（A で使用）
  type: string,       // 敵の種類（A, M で使用）
  hp: number,         // 現在のHP（B, M で使用）
  maxhp: number,      // 最大HP（B で使用）
  value: number       // 敵の得点（M, B で使用）
}
```

**学習のコツ：** 敵オブジェクトのプロパティが増えるにつれて、敵がより複雑な振る舞いをするようになることを理解

### グローバル変数の継承

レッスン間で共有される重要なグローバル変数：

| 変数 | 導入レッスン | 使用するレッスン | 説明 |
|-----|----------|------------|------|
| `enemies[]` | A | A, B, M, H | 敵の配列 |
| `score` | M | M, B | 現在のスコア |
| `combo` | M | M, B | 現在のコンボ数 |
| `elapsed` | （基本） | A, G, H | 経過時間 |
| `dt` | （基本） | A, B, M | フレーム時間 |
| `ctx` | （基本） | H, G（一部） | Canvas コンテキスト |

### プロパティの拡張パターン

レッスンを組み合わせるときのパターン：

**パターン1：敵にプロパティを追加**
```javascript
// A だけの場合
e.type

// A + M の場合
e.type + e.value

// A + B の場合
e.type + e.hp

// A + M + B の場合
e.type + e.value + e.hp
```

**パターン2：グローバル変数を追加**
```javascript
// A だけの場合
let enemies = []

// A + B の場合
let enemies = []
let bullets = []
let shotTimer = 0

// A + M の場合
let enemies = []
let score = 0
let combo = 0
```

## 🔄 相互参照の具体例

### 例1：敵の多様化 (A) + スコアシステム (M)

**LESSON_6A での敵の生成：**
```javascript
enemies.push({
  type: type,
  value: type === 'tank' ? 30 : 10
});
```

**LESSON_6M での得点加算：**
```javascript
score += e.value * (1 + floor(combo / 5));
```

**相互参照の説明：**
- LESSON_6A で敵に `value` プロパティを設定することが、LESSON_6M でのスコア計算の前提条件
- 逆に、LESSON_6M を実装することで、敵ごとに異なる得点設定の重要性が理解できる

### 例2：敵の多様化 (A) + 射撃機能 (B)

**LESSON_6A での敵の HP 設定：**
```javascript
hp: type === 'tank' ? 3 : 1
```

**LESSON_6B での当たり判定：**
```javascript
if (e.hp > 0 && circle(b, e)) {
  e.hp--;
  if (e.hp <= 0) destroyEnemy(e);
}
```

**相互参照の説明：**
- LESSON_6A で敵に `hp` プロパティを設定することが、LESSON_6B での当たり判定の基礎
- 敵の種類によって異なる HP を持つことで、敵の強さがゲームプレイに反映される

### 例3：ビジュアルカスタマイズ (H) + 敵の多様化 (A)

**LESSON_6A での敵のタイプ分け：**
```javascript
const type = Math.random() < 0.17 ? 'zig' : ...
```

**LESSON_6H での敵の描画：**
```javascript
if (e.type === 'tank') {
  ctx.fillStyle = '#ffb763';
} else {
  ctx.fillStyle = '#ff668e';
}
```

**相互参照の説明：**
- LESSON_6A で敵に `type` を設定することが、LESSON_6H での見た目の区別の基礎
- 敵の種類を見た目で区別することで、ゲームプレイが直感的になる
