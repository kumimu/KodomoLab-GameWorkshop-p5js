# 90分進行実装チェックリスト

詳細は「16_90分進行シミュレーション.md」。標準は事前学習不要のシンプル版改造。経験者の応用課題も同じ終了時刻を守る。

## 開始前（授業90分の外）

- [ ] 配布フォルダ・VS Code・ブラウザを各PCで開いた。
- [ ] 実際の配布物で起動・操作・保存・更新を確認した。
- [ ] 必要な教材とライブラリがある。古い配布ZIPだけで追加教材が揃うとは扱わない。
- [ ] 標準版をオフライン確認した。CDNを参照する応用版の通信条件と、通信断時の標準版への切替を確認した。
- [ ] 開始時の動くコピー、作品の持ち帰り先、予備PCを用意した。
- [ ] 初参加者と経験者を把握し、応用課題は開始コードとの組合せを事前に試した。
- [ ] 音を使う場合だけ、音量・再生環境を確認した。
- [ ] 講師・コーチの担当と時計を確認した。

### Web Editorの版合わせ

- [ ] 練習スケッチの「設定」→「Library Management」でp5.js **1.11.13**を選択した。
- [ ] p5.sound.js、互換用Preload／Shapes／Data & Eventsをすべてオフにした。
- [ ] 設定を閉じて版表示を確認し、▶で円・タイトルの表示と値の変更を試した。
- [ ] 「Not Maintained」は保守対象外の表示で、入力エラーではないと把握した。
- [ ] シンプル版とローカル練習版は1.11.13、応用版は現状1.7.0と区別し、使用する教材を事前確認した。

詳細は「18_JavaScript基礎15分_講師ガイド.md」のバージョン設定を参照。

## 共通タイムテーブル

| 時間 | 分数 | 内容 |
|---|---:|---|
| 0:00–0:05 | 5 | 導入・今日のゴール |
| 0:05–0:10 | 5 | 試遊・操作と画面の確認 |
| 0:10–0:25 | 15 | JavaScriptの基礎練習（講師主導） |
| 0:25–0:35 | 10 | コードの場所・最初の改造 |
| 0:35–0:55 | 20 | 選んだ改造に取り組む |
| 0:55–1:00 | 5 | 仕上げ・動く状態に戻す |
| 1:00–1:10 | 10 | 動作確認・修正 |
| 1:10–1:20 | 10 | ペア試遊・発表準備 |
| 1:20–1:25 | 5 | 共有・振り返り |
| 1:25–1:30 | 5 | 保存・持ち帰り確認・終了 |

**合計：90分。以下のチェックは実施時に記入する。**

## 0:00–0:05　導入

- [ ] 「1つ以上改造し、遊んで紹介し、保存する」と説明した。
- [ ] 標準／応用の作業範囲を案内した。全LESSONの完了は求めていない。

## 0:05–0:10　試遊

- [ ] 開始・移動・終了・再開を参加者が確認した。
- [ ] 変えたい箇所を1つ考えた。デモを含め5分で切り上げた。

## 0:10–0:25　基礎練習

- [ ] 「18_JavaScript基礎15分_講師ガイド.md」と参加者テキストを開いた。
- [ ] 開始コードは配布済みで、全員に全文を入力させていない。
- [ ] 数値5分・文字列5分・変数とゲームへの橋渡し5分で進めた。
- [ ] 練習では▶、ローカル版では保存・更新で反映した。
- [ ] Web Editorで足止めされた場合はローカル練習版へ切り替えた。
- [ ] 0:25で切り上げ、ゲーム本体の編集へ移った。

## 0:25–0:35　最初の改造

- [ ] 編集するsketch.jsとブラウザで開くフォルダが一致している。
- [ ] 色など1か所の変更・保存・更新を実演し、参加者も試した。
- [ ] 経験者は開始コードと課題を確認し、変更前の動くコピーを残した。

## 0:35–0:55　改造

- [ ] 0:35に全員の初回成功を確認し、未達の人を優先した。
- [ ] 標準は色・タイトル・速さ・サイズを中心に、1か所ずつ確認した。
- [ ] 応用は確認済みの課題1つに絞り、必要手順を飛ばしていない。
- [ ] 0:50に終了5分前を予告した。

## 0:55–1:00　仕上げ・遅延吸収

- [ ] 新機能追加を止めた。早い人は紹介文を考えた。
- [ ] 未完成の変更はコピーに保全し、必要に応じて動く版に戻した。
- [ ] 変更全体を本人の確認なくgit restoreで消していない。
- [ ] 遅い人も、色やタイトルなど確認できた変更を1つ持てた。

## 1:00–1:10　動作確認

- [ ] 起動・移動・終了・再開と、改造した箇所を確認した。
- [ ] エラーは直前の変更から調べた。応用の未完成部分を完成扱いしていない。
- [ ] 1:10で試遊に進める動く版を用意した。

## 1:10–1:20　ペア試遊

- [ ] 前半4分と次の4分で交代し、双方のゲームを遊んだ。
- [ ] 奇数人数は3人組で交代した。
- [ ] 感想を1つ返し、最後の2分で紹介文を考えた。

## 1:20–1:25　共有

- [ ] 希望者2～3名が各30～45秒で紹介した。全員の紹介はペア内で済ませた。
- [ ] 変更・保存・確認の流れを振り返った。

## 1:25–1:30　保存・終了

- [ ] 全員が最終保存した。
- [ ] 作品フォルダ全体を用意した持ち帰り先へコピーし、保存場所を本人と確認した。
- [ ] 短いアンケート・案内を含め1:30で終了した。

## 時間が押した場合

- [ ] 0:55以降は追加課題を止め、仕上げ枠で吸収した。
- [ ] 1:00以降の動作確認・試遊・共有・保存の30分を確保した。
- [ ] 故障PCは予備機またはペアへ切り替えた。
- [ ] 未完成の作品を保全し、できた変更・気づきを紹介できるよう支援した。

## 実施後

- [ ] 各区切りの実績時刻、人数、つまずきと対応を記録した。
- [ ] 改造・試遊・保存を達成できなかった場合は理由を記録した。
- [ ] 実測に基づき次回の課題量を調整した。計画を実証済みとは扱っていない。

基礎練習の準備・進行は「18_JavaScript基礎15分_講師ガイド.md」を参照。試遊を先に行い、ゲーム改造への期待を持ってから基礎練習へ進む。
