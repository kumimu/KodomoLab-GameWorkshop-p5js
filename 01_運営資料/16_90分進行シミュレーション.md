**つまずきシミュレーション（段階3の複雑性）：**

```
生徒C：「updateBullets() の『逆ループ』がわかりません」
コーチ：「配列から要素を削除する時に大事な仕組みです」

説明フロー：
1. 通常のループで削除するとどうなるか図示
   for (let i = 0; i < arr.length; i++) {
     if (condition) arr.splice(i, 1);  // ← これだと index がずれる
   }

2. 逆ループの利点を説明
   for (let i = arr.length - 1; i >= 0; i--) {
     if (condition) arr.splice(i, 1);  // ← 後ろから削除すればOK
   }

3. 具体例を見せる
   コーチ：「配列 [A, B, C, D, E] があります」
           「Cを消したいとします」
           「通常ループだと」
           「i=0→1→2（C削除）→ i=3 なのに arr[3]=D に」
           「でも Cを削除したから arr[3] は E に変わった」
           「だから index がずれます」
           
           「逆ループだと」
           「i=4→3→2（C削除）→ i=1→0」
           「後ろから消すから、前の index に影響なし」

生徒C：「あ、わかりました。だから逆ループなんですね」
コーチ：「そうです。虫食い問題の『解説』にも書いてあります」
生徒C：「あ、ここですね」
       「for (let i = bullets.length - 1; i >= 0; i--)」
```
