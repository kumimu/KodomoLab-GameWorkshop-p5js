# 環境構築手順

## 1台目で確認

1. 配布テンプレートをデスクトップなどへコピー
2. `p5.min.js` が同じフォルダにあることを確認
3. `index.html` をダブルクリック
4. ゲームを最後まで試す
5. VS Codeでフォルダを開く
6. Git初期化と初回コミットを行う
7. 色を変更して `git diff` を確認
8. `git restore sketch.js` で復旧を確認

## 全PCへ展開

動作確認済みフォルダを全PCへコピーします。

各PCで：

- [ ] 起動
- [ ] キー操作
- [ ] 保存と更新
- [ ] Git差分
- [ ] Git復旧

を確認します。
