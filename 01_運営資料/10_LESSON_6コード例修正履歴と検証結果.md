## 🚨 発見された根本的な問題

### 問題の本質

**LESSON_6の教材は p5.js ライブラリを前提に作成されていますが、NEON DODGE ゲーム本体は Canvas API + Vanilla JavaScript で実装されています。**

このため、教材に記載されたコード例の **約70%が実装不可能** です。

### 3. LESSON_6G：BGMのカスタマイズ

#### 🔴 重大な問題

**Web Audio API コンテキストの初期化と Suspended State の処理**

教材に記載されていない処理：
```javascript
function sound(freq=440, duration=.1, type='sine', vol=.035) {
  if(muted) return;
  try {
    audio ??= new (window.AudioContext||window.webkitAudioContext)();
    if(audio.state==='suspended') audio.resume();  // ← 重要！
    // ...
  } catch(e) {}
}
```

#### ⏳ 修正が必要な部分

- [ ] `sound()` 関数の正確な署名と動作を説明
- [ ] Web Audio API 初期化処理を追加説明
- [ ] `CONFIG.bgm` フラグと `muted` 変数を説明
- [ ] 周波数シーケンスのマッピング方法を正確に説明

## 💾 修正適用時の注意点

### 修正を適用する際の確認事項

1. **グローバル変数の確認**
   - `W`, `H`, `TAU` が定義されているか
   - `elapsed`, `dt` が最新値に更新されているか
   - `ctx` (canvas context) が利用可能か

2. **関数の確認**
   - `circle(a, b)` 関数が定義されているか
   - `sound()` 関数のシグネチャが正しいか
   - `burst()`, `drop()` 関数が定義されているか

3. **イベントハンドラーの確認**
   - `keyDown()` イベントが登録されているか
   - `keyPressed()` は使用すべきでない

4. **Canvas 状態管理**
   - 各描画の前後で `ctx.save()` / `ctx.restore()` を呼び出しているか
   - 描画順序（Z-order）が正しいか
