# 🎮 NEON DODGE ワークショップ 講師向けハンドブック 完全版

**「プログラミングの楽しさを学ぶ 90分ワークショップ」**

---

## 📖 はじめに

このハンドブックは、NEON DODGEワークショップを実施する講師（コーチ）向けの完全ガイドです。

**このハンドブックでできること：**
- ワークショップの全体像を理解
- 事前準備から当日実施、事後処理まで網羅
- つまずきやすいポイントと対応方法を理解
- 様々なトラブルに対応
- 生徒の技術レベルに応じた対応

**想定読者：** 中学校の教員、ワークショップの講師、プログラミング学習の支援者

---

## 🎯 ワークショップ全体像

### 開催概要

| 項目 | 内容 |
|------|------|
| **参加対象** | 中学1～3年生（プログラミング未経験者推奨） |
| **参加人数** | 1～20名（講師1名：生徒5～10名が理想） |
| **所要時間** | 90分（LESSON_1～6の短縮版）※LESSON_1～5は事前に実施 |
| **開催形式** | VS Code + p5.js によるブラウザゲーム開発 |
| **難易度** | ★★☆（初心者向け） |
| **達成目標** | 自分の手でゲームを改造・完成させる経験 |

### ワークショップの流れ

```
【セッション1】（事前実施推奨）
LESSON_1 ゲームの全体像を理解
LESSON_2 変数と設定値
LESSON_3 プレイヤーの移動
LESSON_4 敵と当たり判定
LESSON_5 改造ミッションの指導
        ↓
        （ここまで30～60分）

【セッション2】（今回のワークショップ）
LESSON_6 応用版への発展
  - OPTION_A 敵の多様化
  - OPTION_B 射撃機能
  - OPTION_G BGMのカスタマイズ
  - OPTION_H ビジュアルカスタマイズ
  - OPTION_M スコアシステム
        ↓
        （ここまで90分）

【成果】
オリジナルゲームの完成
プログラミングの基礎を習得
```

```

        『後ろから消す』が鉄則です」

図解：
通常ループ：[A, B, C, D, E] で C を消したい
  → i=0,1,2 で C 削除
  → 配列が変わって [A, B, D, E]
  → i=3 なのに arr[3]=E になってしまう（バグ）

逆ループ：[A, B, C, D, E] で C を消したい
  → i=4,3 で C 削除（i=2）
  → 後ろから消すから前の index は変わらない（OK）

虫食い問題の『解説』を見てください」
生徒：「あ、『逆ループ』ですね」

対応方法：
- 「他のオプションも見てみたい？」と提案
- 別のオプション（例：A から H へ）へ移行
- または、より高度な工夫例へ
- 発表で複数のオプション組み合わせを紹介

結果：
- 複数のスキルを学習
- 自信につながる
```

### つまずきが多発している場合

#### 複数生徒が同じつまずき

```
対応方法：
1. 全体に向けて説明（個別ではなく全体へ）
2. スクリーンを使ってコード例を投影
3. つまずきポイント表から対応方法を引用
4. 「これは多くの人がつまずくポイントです」と安心感を与える

結果：
- つまずきが一括解決
- 全体の進行速度が上がる
```

#### 特定の生徒だけが大幅に遅れている

```
対応方法：
- 別のコーチに割当（複数コーチ運用の場合）
- 段階を簡略化（段階2はスキップして段階3へ）
- または、段階1で完成させる
- 発表では「工夫例」部分を紹介

結果：
- その生徒も完成の達成感を得られる
- 他の生徒の進行に影響なし
```

### 環境トラブル

#### ブラウザがクラッシュした場合

```
対応：
1. 再度 VS Code を起動
2. ブラウザをリロード
3. ローカルストレージをクリア（問題が続く場合）
4. 再度アクセス

所要時間：3～5分
```

#### インターネット接続が切れた場合

```
対応：
1. p5.js がすでにロードされていれば動作継続可能
2. オフラインモードで実装継続
3. 音声機能（BGM）は使えない可能性があることを伝える

注意：
- 新しいタブでのアクセス不可
- LESSON_6 資料はオンラインで見られない可能性
```

#### コーチが説明に詰まった場合

```
対応：
1. 「いい質問ですね。一緒に確認しましょう」
2. 虫食い問題の「解説」セクションを読む
3. またはコーチガイドで対応方法を確認
4. わからないなら「次で調べます」と正直に

重要：
- 無理に説明しない
- 生徒の信頼を守る
- わかるまで調べるコーチの姿勢を見せる
```

## 🎓 コーチの心構え

### 大切なこと

1. **生徒のペースを尊重する**
   - 速い生徒を急かさない
   - 遅い生徒を責めない
   - 各生徒が完成の達成感を得られるように

2. **わかることは説明しすぎない**
   - 生徒に考える機会を与える
   - 「ここを見てみてください」と指導するだけ
   - 自分で解決できる喜びを大切に

3. **つまずきを受け入れる**
   - つまずきは学習の証
   - 「ここがわからない」は素晴らしい質問
   - 一緒に解決する喜びを共有

4. **生徒のオリジナリティを尊重する**
   - 「こうしてもいいですか」という質問に対して
   - 「いいアイデアですね」と承認
   - 工夫例以外のアイデアを否定しない

5. **進行状況より学習を優先する**
   - 時間配分は目安
   - 生徒が理解することが最優先
   - 「時間足りないので省略」より「しっかり理解」
