## 🔍 明確な「場所指定」の方法

### 効果的な場所指定

**❌ ダメな例：**
```
playGame() の最初に追加
```

**✅ 良い例：**
```
📍 ファイル：sketch.js
📍 場所：playGame() 関数の中
📍 具体的な場所：「if (remaining <= 0)」の下
（drawGameInfo() の上）

現在のコード：
function playGame() {
  // ... 前のコード ...
  if (remaining <= 0) {
    // ...
  }
  // ← ここに追加！
  drawGameInfo(remaining);
}
```
