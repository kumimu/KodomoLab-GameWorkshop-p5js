# 準備

## 目的

会館PCを、サインイン・Node.js・Webサーバーなしでワークショップに利用できる状態にします。

## 必要ソフト

- VS Code
- Git
- Chrome または Edge

## 不要

- Node.js
- npm
- Live Server
- p5.js Web Editorのアカウント

## 会場PCへの設定手順

1. VS Codeが起動できるか確認
2. Gitが利用できるか確認
3. ブラウザが起動できるか確認
4. `01_配布テンプレート` をPCへコピー
5. 手元でダウンロード済みの `p5.min.js` をテンプレート直下へ配置
6. `index.html` をダブルクリック
7. 開始画面が表示されることを確認
8. `1` を押してゲーム開始
9. 左右キーで操作できることを確認
10. `sketch.js` をVS Codeで開く
11. `playerColor` を変更して保存
12. ブラウザをF5で更新して反映を確認

## Gitの初期設定

各PCの配布テンプレート内で実行します。

```bash
git init
git add .
git commit -m "initial template"
```

名前・メール未設定でコミットできない場合：

```bash
git config user.name "KodomoLab"
git config user.email "workshop@example.invalid"
git add .
git commit -m "initial template"
```

## 最終確認

- [ ] オフラインでゲームが起動する
- [ ] 難易度選択が動く
- [ ] 左右操作が動く
- [ ] CLEARとGAME OVERが表示される
- [ ] 保存後、F5で変更が反映される
- [ ] `git diff` で変更点が表示される
