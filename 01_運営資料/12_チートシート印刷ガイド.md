## 🖨️ 印刷方法

### 推奨: HTMLファイルからPDF化

**最適な結果が得られます**

#### ステップ1: HTMLファイルをブラウザで開く

```bash
1. CHEAT_SHEET_A4_印刷版.html をダブルクリック
   または
2. ブラウザにドラッグ&ドロップ
```

#### ステップ2: PDFに保存

**Chrome / Edge の場合：**

```
1. Ctrl + P （または ⌘ + P）
2. 「保存」ボタン → 「PDFに保存」を選択
3. ファイル名：CHEAT_SHEET_A4.pdf
4. 場所：デスクトップ（印刷所用フォルダ）
5. 保存ボタンをクリック
```

**Safari の場合：**

```
1. ⌘ + P
2. PDF ドロップダウン → 「PDFとして保存」
3. ファイル名・場所を指定
4. 保存
```

#### ステップ3: 印刷所またはコンビニで印刷

```
持ち込みファイル：CHEAT_SHEET_A4.pdf
サイズ：A4（210 × 297 mm）
向き：横向き（ランドスケープ）
用紙：白紙
部数：参加者数分（+予備10%)
印刷品質：標準以上
両面印刷：推奨（コスト削減用）
```

## 🔍 よくある問題と対応

| 問題 | 原因 | 対応 |
|------|------|------|
| **印刷時に背景色が出ない** | 背景グラフィックス設定OFF | Chrome設定で「背景」にチェック |
| **フォントがおかしい** | フォント埋め込みなし | ブラウザ側でフォント表示確認 |
| **カラーが薄い** | 印刷品質設定が低い | 「標準以上」のプリント品質を選択 |
| **内容が2ページになる** | 余白設定が大きい | 「最小余白」または「なし」に設定 |
| **テーブルが欠ける** | ページサイズ不正 | A4 + 横向き を確認 |
| **PDF化できない** | ブラウザ側の問題 | 別ブラウザを試す（Edge, Firefox等） |

## 📞 トラブルシューティング

### Q: 「ページが収まりません」の場合

**A:** HTML版の設定を確認

```html
<!-- body の margin/padding を削減 -->
<style>
  body { margin: 0; padding: 0; }
  .page { padding: 5mm; }  /* 10mm → 5mm に削減 */
</style>
```

### Q: 「フォントが小さすぎます」の場合

**A:** フォントサイズを拡大

```html
<!-- 全体のフォントサイズを 1.2 倍に -->
<style>
  body { font-size: 12px; }  /* 10px → 12px */
  pre { font-size: 9.5px; }  /* 8px → 9.5px */
</style>
```

### Q: 「カラー印刷できません」の場合

**A:** グレースケール版を別途作成

```html
<!-- 色を白黒に統一 -->
<style>
  .important { background-color: #f0f0f0; }
  th { background-color: #e0e0e0; }
</style>
```
