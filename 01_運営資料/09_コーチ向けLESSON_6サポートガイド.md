# コーチ向け LESSON_6 サポートガイド

**対象：** ワークショップコーチ  
**目的：** 生徒が LESSON_6 のオプションを実装するときに、効率的にサポートするためのガイド

## 📋 概要：LESSON_6 の構成

### 生徒が選べるのは5つ

LESSON_1〜5で基礎版を完成させた生徒は、以下の5つから**1つを選んで**改造に挑戦します：

| オプション | 難易度 | 時間 | 説明 |
|-----------|--------|------|------|
| **A. 敵の多様化** | ★★☆ | 30-45分 | 敵を複数の種類に分ける |
| **B. 射撃機能** | ★★☆ | 30-45分 | プレイヤーが敵に反撃できる |
| **G. BGM のカスタマイズ** | ★☆☆ | 25-35分 | ゲーム音楽を変更 |
| **H. ビジュアルカスタマイズ** | ★☆☆ | 25-35分 | 色・形・サイズを変更 |
| **M. スコアシステムの工夫** | ★★★ | 35-50分 | 得点計算ルールを変更 |

## 🔧 各オプション別の対応ガイド

### A. 敵の多様化

#### 指導の流れ

1. **ファイルの指示**
   - 「`LESSON_6A_敵の多様化.md` を読んで、段階1から始めてください」

2. **段階1の確認**
   - 敵が2種類だけになっているか確認
   - コンソールで `console.log('敵の type:', e.type)` を出力させて、type が正しく設定されているか確認

3. **段階2への移行**
   - 「敵の種類によって色が異なるようにしましょう」
   - Canvas API での描画方法を確認（`ctx.fillStyle = '#rrggbb'` など）

4. **段階3への移行**
   - 「敵の動きを工夫してみましょう」
   - `Math.sin()` や `Math.cos()` で揺らす動きを説明

#### つまずきやすいポイント

| 問題 | 原因 | 対応方法 |
|-----|------|---------|
| 敵が表示されない | `ctx.fill()` が呼ばれていない、または Canvas 状態管理ミス | `ctx.save()` / `ctx.restore()` の対応を確認 |
| 敵の type が全て同じ | `Math.random()` の値域設定が間違っている | 確率の計算 `< 0.17` の意味を確認 |
| 敵の動きが反映されない | `e.y += e.v * dt;` が実行されていない、または `v` プロパティが存在しない | 敵生成時に `v` が設定されているか確認 |
| 色が見分けにくい | RGB 値の選択が悪い | より明るさが異なる色を提案：`#ff6464` vs `#6464ff` |
| 敵が一気に大量に出現 | `spawnTimer` の管理が間違っている | タイマー管理ロジックを確認 |

#### コーチからのアドバイス例

**「敵が表示されない」と言われた場合：**

```
1. 「敵の座標（e.x, e.y）は正しいですか？」
   → コンソールで確認させる
   
2. 「ctx.save() と ctx.restore() を使ってますか？」
   → 描画状態管理の確認
   
3. 「ctx.fillStyle を設定した後に、ctx.fill() を呼んでますか？」
   → 描画命令の順序確認
```

**「敵の速度が全て同じ」と言われた場合：**

```
「type に応じて速度を変えてますか？」
→ LESSON_6A の段階1 コード例を見直させる
```

#### 時間に余裕がある場合の発展課題

- 敵の種類を 5種類以上に増やす
- 敵の大きさも type ごとに異なるようにする
- `Math.random()` の確率をゲーム難易度に応じて変える

### B. 射撃機能

#### 指導の流れ

1. **ファイルの指示**
   - 「`LESSON_6B_射撃機能.md` を読んで、段階1から始めてください」

2. **段階1の確認**
   - スペースキーで弾が発射されるか確認
   - 弾が敵に当たると何か変わるか（敵が消えるなど）確認

3. **段階2への移行**
   - 「弾と敵の当たり判定を実装しましょう」
   - `circle()` 関数の説明：2つのオブジェクト間の距離を計算

4. **段階3・4への移行**
   - 「クールタイムを調整して、連続射撃できるようにしましょう」
   - 「複数の弾を発射するようにしましょう」

#### つまずきやすいポイント

| 問題 | 原因 | 対応方法 |
|-----|------|---------|
| 弾が表示されない | 弾の描画コードがない、または Canvas API の使用ミス | `ctx.fillRect()` で弾を描画する例を示す |
| スペースキーで弾が出ない | `keyDown()` イベントが実装されていない | キーイベントの実装例を示す |
| 当たり判定が機能しない | `circle()` 関数が定義されていない、または `e.hp` が存在しない | 関数定義とプロパティの確認 |
| 敵が消えない | `destroyEnemy()` 関数が呼ばれていない | 敵の `hp` 管理と削除ロジックの確認 |
| 弾が画面に残り続ける | 弾の削除ロジックがない | `filter()` で画面外の弾を削除する例を示す |

#### コーチからのアドバイス例

**「弾が見えない」と言われた場合：**

```
1. 「弾を描画しているコードはありますか？」
   → 描画コードがなければ、LESSON_6B の描画例を示す
   
2. 「ctx.fillStyle と ctx.fillRect() を使ってますか？」
   → Canvas API での描画方法を確認
```

**「当たり判定が動かない」と言われた場合：**

```
1. 「circle() 関数はどこにありますか？」
   → game.js に提供されている circle() 関数を確認
   
2. 「敵に e.hp プロパティがありますか？」
   → LESSON_6A で敵を生成しているコードを確認
```

#### 時間に余裕がある場合の発展課題

- 複数の種類の弾を実装（通常弾、ボム、貫通弾など）
- プレイヤーの位置に応じた斜め射撃
- 連続射撃数に応じた威力変化

### G. BGM のカスタマイズ

#### 指導の流れ

1. **ファイルの指示**
   - 「`LESSON_6G_BGMのカスタマイズ.md` を読んで、段階1から始めてください」

2. **段階1の確認**
   - ゲーム中に音楽が流れているか確認
   - 周波数シーケンス配列が正しく定義されているか確認

3. **段階2への移行**
   - 「複数の BGM パターンを作ってみましょう」
   - 周波数表を参照させて、異なるメロディを作成

4. **段階3への移行**
   - 「キー入力で BGM パターンを切り替えてみましょう」

#### つまずきやすいポイント

| 問題 | 原因 | 対応方法 |
|-----|------|---------|
| 音が出ない | ブラウザの音量が OFF、または `sound()` 関数の実装ミス | ブラウザ設定と `sound()` 関数の確認 |
| BGM がループしない | `bgmIndex % currentBGM.length` の計算が間違っている | モジロ演算子（`%`）の意味を確認 |
| BGM が途切れ途切れ | `bgmTimer` の管理が間違っている | タイマー管理ロジックを確認 |
| キーで BGM が切り替わらない | `currentBGM` の変更後に `bgmIndex` をリセットしていない | `bgmIndex = 0` を追加 |

#### コーチからのアドバイス例

**「音が出ない」と言われた場合：**

```
1. 「ブラウザの音量は ON ですか？」
   → 環境設定の確認
   
2. 「sound() 関数は呼ばれていますか？」
   → コンソールに console.log() を入れて確認
   
3. 「Web Audio API は初期化されていますか？」
   → game.js の sound() 関数の実装を説明
```

**「BGM がループしない」と言われた場合：**

```
「bgmIndex % currentBGM.length の計算で、配列をループさせます。
例えば、配列の長さが 8 で、bgmIndex が 8 のときは：
8 % 8 = 0 → 最初の要素に戻る」
```

#### 時間に余裕がある場合の発展課題

- 8 パターン以上のオリジナル BGM を作成
- ゲーム難易度に応じて BGM の周波数を変更
- コンボ数に応じて BGM の速度を変更

```
例：polygon(0, 0, 25, 6) → 6角形」
```

## 🔍 デバッグ・トラブルシューティング

### よくあるエラーと対応

#### ケース1：「敵が画面に表示されない」

**確認項目：**
1. 敵が生成されているか（`enemies` 配列の長さ）
2. Canvas 状態管理（`ctx.save()` / `ctx.restore()`）
3. 描画コマンド（`ctx.fill()` が呼ばれているか）

**対応例：**
```javascript
// コンソールで確認
console.log('敵の数：', enemies.length);
console.log('最初の敵：', enemies[0]);

// 敵の座標がおかしくないか確認
console.log('敵の座標：', e.x, e.y);
```

---

#### ケース2：「スペースキーで弾が出ない」

**確認項目：**
1. `keyDown()` イベントが登録されているか
2. キーコード（`e.code === 'Space'`）が正しいか
3. `shoot()` 関数が定義されているか

**対応例：**
```javascript
// keyDown イベントに console.log() を追加
function keyDown(e) {
  console.log('キーが押された：', e.code);
  if (e.code === 'Space') {
    console.log('スペースキー detected');
    shoot();
  }
}
```

---

#### ケース3：「スコアが加算されない」

**確認項目：**
1. 敵に `value` プロパティがあるか
2. `destroyEnemy()` が呼ばれているか
3. スコア計算式が正しいか

**対応例：**
```javascript
function destroyEnemy(e) {
  console.log('敵撃破：value =', e.value);
  score += e.value;
  console.log('現在のスコア：', score);
}
```
