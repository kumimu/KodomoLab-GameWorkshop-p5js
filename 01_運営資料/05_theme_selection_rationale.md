# 題材選定経緯

## 要件

- 中学生向け
- Windows PC
- 2時間
- ゲーム制作
- カスタム要素
- サインイン不要
- 初心者と経験者が混在可能

## 言語・環境比較

|候補|長所|課題|
|---|---|---|
|Scratch / TurboWarp|完成率が高い|ブロック方式で、今回求めるコード入力体験と異なる|
|p5.js|ブラウザで動作し、描画・入力が簡単|タイプミス対策が必要|
|Python + Pyxel|Python学習につながる|環境構築負荷が高い|
|Unity|本格的|2時間では重い|
|Minecraft系|人気が高い|ライセンス・脱線・端末性能の課題|

## p5.jsを採用した理由

- JavaScriptを直接入力できる
- Node.jsやコンパイルが不要
- 図形、アニメーション、キー入力が簡単
- ローカルファイルとしてオフライン動作できる
- テンプレート改造型に向く

## p5.jsの利点

### 学習面
- JavaScriptは Web 標準言語で、高校情報科の学習内容と連携
- ブラウザ開発者ツール (F12) でデバッグスキルを習得できる
- 関数、変数、制御文など基礎的なプログラミング概念をビジュアルで理解できる

### 運用面
- インストール不要（p5.min.js をダウンロードするだけ）
- USB 配布で全 PC に展開可能
- ネットワーク接続不要（完全オフライン動作）
- エディタは VS Code のみで統一可能

### 拡張性
- 画像・音声の追加が容易
- ゲーム以外の表現（アート、シミュレーション）も可能
- 将来の Web 開発につながる基礎

### ビジュアルフィードバック
- コード変更がリアルタイムで画面に反映
- 初心者のモチベーション維持に効果的
