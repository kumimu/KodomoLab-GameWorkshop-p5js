実施時刻はワークショップ開始から0:10–0:25。先にゲームを試遊し、改造への期待を持ってから取り組む。参加者教材は「02_教材/01_配布テンプレート/JS_15分入門/参加者テキスト.md」。

## 開始前の準備（15分に含めない）

- p5.js Web Editorを各PCで開き、practice.jsの内容を練習用sketch.jsへ入れる。▶で水色の円と白いタイトルが出ることを確認する。
- 当日使うブラウザ・ログイン状態で編集・実行できるか事前に確認。クラウド保存を授業の必須にせず、登録・ログインで足止めされる場合はローカル版へ切り替える。
- 全員に長いコードを入力させず、開始コードを配布済みにする。Auto-refreshはオフにし、変更→予想→▶で確認の操作を揃える。
- ローカル代替はJS_15分入門/index.htmlとpractice.js。親フォルダのp5.min.jsが必要。実際の配布構成で通信を切って起動確認する。
- テキストはローカルで開けるよう配布する。既存配布ZIPには今回の教材が入っていないため、フォルダを直接配るか、後日配布物を更新する。
- ゲーム本体のsketch.jsを練習コードで上書きしないよう、練習とゲームを別ウィンドウで区別する。

## p5.jsのバージョン設定（開始前に全PCで確認）

今回のWeb Editor練習は **p5.js 1.11.13** に揃える。Web Editorのデフォルトに任せず、実際に使う練習スケッチで確認する。

1. 右上の歯車から「設定」を開く。
2. 「Library Management」タブを選ぶ。
3. 「p5.js Version」で **1.11.13** を選ぶ。
4. 以下の追加ライブラリをすべて **オフ** にする。この15分の練習には不要。
   - p5.sound.js
   - p5.js 1.x Compatibility — Preload
   - p5.js 1.x Compatibility — Shapes
   - p5.js 1.x Compatibility — Data & Events
5. 設定を閉じ、画面右上の版表示が1.11.13であることを確認する。
6. 練習コードを▶で実行し、円・タイトルの表示と、大きさ・色・文字の変更を試す。

「1.11.13 (Not Maintained)」は保守対象外の表示であり、実行不可の意味ではない。今回は既存教材との版合わせのために使用する。v2への移行は別途動作確認して判断し、当日の授業中には切り替えない。

## 0:10–0:15　数値

声掛け：「さっきのゲームの大きさや色は、コードで決まっています。まず、小さな練習で変え方を試しましょう。」

1. 初期画面を見せ、playerSizeの40を指す。
2. 「80にしたら何が起きる？」と予想を聞く。
3. 参加者は40→80→20と変更し、その都度▶で確認。
4. 「数値を変えると大きさが変わる。ゲームのplayerSizeも同じ考え方」とつなぐ。

到達目安：円の大きさを1回変えられる。letの説明は最後にまとめ、まず変化を体験させる。

## 0:15–0:20　文字列

声掛け：「数はそのまま書きました。色の名前やタイトルは、引用符で囲みます。」

1. playerColorの"cyan"を"yellow"に変える。
2. 引用符を残し、gameTitleの文字を自分のタイトルにする。
3. ▶で確かめる。日本語入力後は記号・英字の入力を半角に戻す。

到達目安：色かタイトルを1つ変えられる。色の自由検索や長いタイトル作りに時間を使いすぎない。

## 0:20–0:25　変数とゲームへの橋渡し

声掛け：「playerSizeは値に付けた名前です。下のcircleの命令が、その名前を使って大きさを決めています。」

1. let playerSize = 80;を指し、名前と値を説明。=は右側の値を入れる操作と伝える。
2. circle(200, 150, playerSize);を指し、同じ名前を使っていることを示す。
3. 確認クイズ「大きくして青くするには？」。100と"blue"に変えて確認。
4. 「ゲームにも同じ名前がある。次は本物のゲームのCUSTOM AREAを変えよう」と締める。

到達目安：数値と文字列の違い、および値を変える場所がわかる。すべての用語の暗記は求めない。

## つまずき・時間超過への対応

| 状況 | 対応 |
|---|---|
| Web Editorを開けない・準備に時間がかかる | 1分を目安にローカル版へ。通信やアカウント設定を授業内で続けない |
| 全角の引用符・記号になった | 元の行を見せ、値だけ変更し直す。日本語タイトルは引用符の内側だけ |
| 練習コードを全部消してしまった | 配布済みpractice.jsから戻す。ゲーム本体には貼らない |
| 進度が遅い | 大きさ1回と色1回の変更を優先。クイズは講師の実演を見てもよい |
| 早く終わった | 「どの行がどの表示に対応するか」を隣の人に説明。別サイトや追加機能へ進ませない |

0:25で終了し、ゲームの改造へ進む。続きの練習は持ち帰り用。ブラウザの描画や講師による所要時間のリハーサルは別途実施する。

## ゲームへ戻った直後（0:25–0:35）

- 正しいゲーム本体のsketch.jsでCUSTOM AREAを開く。
- playerColorを1か所変え、保存→ブラウザ更新を全員で実施する。
- 「練習サイトでは▶、ローカルのゲームでは保存と更新」と操作の違いを明示する。
- 練習では円、本体では三角形であることを伝える。playerSpeedは本体の改造時間で扱う。
